## 一、系统整体架构：基于 SmartPilot 的多 Agent 体系

论文依托已有的 **SmartPilot** 工业 CoPilot 平台。该平台原生包含三个 Agent，本文新增第四个 Agent **CausalTrace**，构成四 Agent 协同架构。论文的增量贡献仅为 CausalTrace，其余三个为 SmartPilot 原有组件（算法细节见 Shyalika et al. 2025a,b,c）。

### 1.1 四 Agent 架构图

│                                   ┌──────────▼───────────┐       │
│                                   │  ForeSight（产量预测）│◄── 时序
│                                   │  · KIL-LSTM          │       │

### 1.2 四个 Agent 的功能与技术

| Agent | 功能 | 技术实现 | 归属 |
|-------|------|---------|------|
| **PredictX** | 异常预测，多模态传感器数据（时序+图像） | 决策级融合 + 迁移学习 + 知识融合学习 | 已有 |
| **ForeSight** | 产量预测，跨周期预估产能 | KIL-LSTM（知识注入 LSTM） | 已有 |
| **InfoGuide** | 运维问答，统一对话接口 | RAG + LLaMA3-70B-8192 | 已有 |
| **CausalTrace** | 因果分析：解释、归因、模拟 | 神经符号因果推理 | **本文新增** |

原有三 Agent 只覆盖"预测"和"问答"，缺乏因果分析能力——PredictX 能说"会异常"，但说不出"为什么"。CausalTrace 补上了"解释、归因、模拟"能力。

## 二、CausalTrace Agent 核心：神经符号因果推理流水线

CausalTrace 内部由七个组件构成，核心逻辑是**数据驱动因果挖掘 + 符号知识约束验证**的神经符号融合。论文的三个核心算法分别嵌入在因果发现引擎、RCA 模块和因果评估器中。

## 三、神经符号融合机制（专章）

神经符号（Neurosymbolic）是 CausalTrace 的核心设计理念，也是 C3AN 框架四大原则之一。

### 3.1 为什么需要神经符号

- **神经网络**：擅长从数据学复杂模式、处理非结构化数据，但黑箱、可能学到虚假关联。
- **符号推理**：基于显式规则，可解释、逻辑严密、小样本可用，但规则需人工编写、难扩展。
- **神经符号 = 两者结合**：神经网络负责"从数据学习/生成"，符号系统负责"用知识约束/验证/增强"。C3AN 要求每个模块内部都有神经+符号整合，而非简单串联。

### 3.2 三层知识注入

| 层 | 实现 | 作用 |
|----|------|------|
| 知识图谱 | RDF 编码，rdflib 查询 | 提供实体关系（传感器、机器、异常） |
| 过程本体 | Neo4j 图数据库，Cypher 查询 | 提供过程语义、公差范围、传感器功能映射 |
| 因果图提示注入 | 序列化总因果效应矩阵传入 LLM prompt | 让解释基于因果事实，防止幻觉 |

**核心机制：causal graph prompt injection**——把 Algorithm 2 算出的总因果效应矩阵序列化成文本，连同知识图谱提取的实体描述、类型、单位一起作为 prompt 上下文传给 LLM，使解释有因果结构事实依据。

### 3.3 三环节落地

| 环节 | 数据驱动部分 | 符号约束部分 |
|------|------------|-------------|
| 因果发现 | LiNGAM/DiffAN 从数据学因果图 | 本体验证边的语义合理性 |
| RCA | 总因果效应矩阵计算路径强度 | 专家定义的 cycle-aware 传感器公差范围筛选异常变量 |
| 解释生成 | LLM 生成自然语言解释 | 知识图谱提供实体关系，约束解释内容防止幻觉 |

统一模式：神经网络负责"从数据中学习/生成"，符号系统负责"用知识约束/验证/增强"。

## 四、三大核心算法：筛选 → 量化 → 验证

### 4.1 Algorithm 1：Bootstrap 边缘稳定性分析

**目的**：因果发现算法对数据敏感，换批数据学出的图可能不同。通过有放回重采样 N 次，统计每条边强度波动，过滤不稳定的边。

**定位**：质量控制环节，不创造新因果关系，只过滤噪声边。

**核心公式**：
- 对每条边 A→B，记录 N 次抽样中的因果强度 w₁…w_N
- 标准差 σ = √[ (1/N) Σ (wᵢ − w̄)² ]
- **稳定性分数 s = 1 / (1 + σ)**，保留 s ≥ 0.6

**直觉**：σ 越小（每次强度差不多）→ s 越接近 1 → 边越稳定。

> **原文口径不一致**：正文说稳定性分数按"出现频率"算，但伪代码实际用因果强度的标准差 σ。本文按伪代码理解。

### 4.2 Algorithm 2：总因果效应计算

**目的**：把因果图从"有没有关系"升级为"关系有多大"，算出任意两变量间直接+间接的总影响。

**定位**：核心计算环节。

**推导**（结构方程模型 X = BX + ε）：
```
(I − B)X = ε  ⟹  X = (I − B)⁻¹ ε
```
定义**总因果效应矩阵 T = (I − B)⁻¹**，Tᵢⱼ 表示变量 j 对变量 i 的总影响。

**Neumann 级数展开**：
```
T = (I − B)⁻¹ = I + B + B² + B³ + ...
```
- I：自身效应；B：直接效应（1跳）；Bᵏ：k 跳间接效应。
- DAG 保证 B 为严格三角矩阵，谱半径为 0，级数必然收敛。

### 4.3 Algorithm 3：反事实验证

**目的**：用未参与学图的**留出数据**检验因果效应是否可靠。

**定位**：自验证环节，用准实验（观测数据自然分组）近似干预检验。

**步骤**：
1. 对边 A→B（|τ_A→B| > δ），取 a₁ = Q₁(A)（基线）、a₂ = Q₃(A)（干预）
2. 预测变化：**ΔB_pred = (a₂ − a₁) × τ_A→B**
3. 从留出数据取基线组（A≈a₁）和干预组（A≈a₂），观测变化：**ΔB_obs = E[B|A≈a₂] − E[B|A≈a₁]**
4. 误差：**Error = |ΔB_pred − ΔB_obs|**，误差越小越可信。

### 4.4 串联关系

```
LiNGAM/DiffAN 产出初步因果图
  → Algorithm 1 筛选稳定边（s≥0.6）
  → Algorithm 2 计算总因果效应 T
  → RCA 模块结合公差范围排序根因
  → Algorithm 3 反事实验证
```

口诀：Algorithm 1 = 筛选，Algorithm 2 = 量化，Algorithm 3 = 验证。

## 五、评估方法与指标体系

评估分三组核心证据：**RCA 任务指标**、**C3AN 框架评估**、**消融实验与基线对比**。

### 5.1 数据集

- 来源：Future Factories Lab 火箭装配产线
- 规模：166K 条记录，1.95 Hz，285 个周期，30 小时，21 个操作状态
- 异常：6 种"缺零件"类异常（NoNose、NoBody2 等），有明确 ground truth
- 因果发现：XGBoost+专家验证选 8 个变量；LiNGAM 产出 20 条边，DiffAN 产出 15 条

### 5.2 RCA 任务指标

| 指标 | 含义 | 结果 |
|------|------|:----:|
| MAP@3 | 前 3 个预测的平均精度均值（排序质量） | 94% |
| PR@2 | 前 2 个预测中正确的比例 | 97% |
| MRR | 第一个正确结果排名的倒数均值 | 0.92 |
| Jaccard | 预测根因集合与真实集合的相似度 | 0.92 |

### 5.3 C3AN 框架评估

**C3AN**（Custom, Compact, Composite AI with Neurosymbolic Integration）是作者团队**先前工作**（Sheth et al. 2025）提出的 AI 范式框架，本文用它评估 CausalTrace，非本文首创。

- **四原则**：Custom（定制化）、Compact（紧凑性）、Composite（组合式）、Neurosymbolic（神经符号）
- **三维度（RIT）**：Robustness（鲁棒性）、Intelligence（智能性）、Trustworthiness（可信度）
- **评估方式**：14 条原则选 10 条，每条 10 题，由 GPT-4o-mini、LLaMA3-70B、6 位人类专家（3制造+3CS）打分（1-5分）

**关键结果**：

| 原则 | 类别 | GPT-4o-mini | LLaMA3-70B | 人类 |
|------|:----:|:-----------:|:----------:|:----:|
| Reliability 可靠性 | R | 4.0 | 4.5 | 4.2 |
| Consistency 一致性 | R | **3.5** | 4.5 | 4.4 |
| Causality 因果性 | I | **4.9** | 4.4 | 4.7 |
| Explainability 可说明性 | T | **5.0** | **5.0** | **5.0** |

- 人类平均 **4.59/5**
- **Explainability 三项全 5 分**（最强项），**Causality GPT-4o-mini 4.9**（核心卖点）
- 最弱项：**Consistency（GPT-4o-mini 3.5）**，改写问题后回答不稳定

### 5.4 消融实验与基线对比

| 方法 | ROUGE-1 | Jaccard | MAP@3 | PR@2 | MRR |
|------|:-------:|:-------:|:-----:|:----:|:---:|
| 相关性基线（Pearson，不判断方向） | – | 0.33 | 44% | 51% | 0.50 |
| CausalTrace（无 KG/本体） | 0.56 | – | – | – | – |
| CausalTrace（完整） | **0.91** | **0.92** | **94%** | **97%** | **0.92** |

**结论**：
1. **ROUGE-1=0.91 评估的是本体 QA 回答质量**（与专家参考答案的词级重叠），非通用解释质量。
2. 去掉知识图谱/本体后 ROUGE-1 从 0.91 降至 0.56，**证明知识注入对解释质量不可或缺**。
3. 相关性基线 Jaccard 仅 0.33，**判断因果方向是 RCA 有效的前提**。

## 七、迁移思考：适配核工业故障溯源场景

> 以下为基于现阶段粗浅理解的初步思考，无充分工程调研支撑，不做最终定论。

### 7.1 PredictX 异常预测模块：具备保留价值

可作为上游前置筛选组件，从海量时序数据中识别微弱早期异常、过滤噪声，为 CausalTrace 提供高质量输入。该模块为平台已有组件，上游告警筛选有助于提升后续 RCA 准确度。

### 7.2 ForeSight 产量预测模块：核电场景必要性较低

核电站额定功率为设计定值，运行目标为稳态维持，功率调控与工况预测已有独立成熟的堆控系统、仿真系统与安全分析体系支撑。在仅聚焦故障根因溯源的课题目标下，该模块与核心任务解耦，纳入收益较低、合规负担更高。

### 7.3 多 Agent 架构的取舍：需核算边际收益

核心增益来自 CausalTrace 神经符号溯源模块，其余 Agent 仅做上游辅助输入。全套多 Agent 会提升系统复杂度、调试成本与安全审计成本，是否完全保留需结合现场运维流程评估。

### 7.4 轻量化适配思路

以 CausalTrace 为核心，仅保留 PredictX 做上游告警预处理，剥离产量预测模块，依托"数据因果学习 + 核电领域符号规则（如 FMEA/故障树先验知识）"实现轻量化、高可信、可审计的核电故障根因分析系统。

## 一、问题背景与核心思想

### 1.1 要解决什么

**因果特征选择（causal feature selection）**：给定一个目标时序 $Y:=(Y_t)_{t\in\mathbb Z}$ 和一组候选时序 $X:=((X^1_t,\dots,X^n_t))_{t\in\mathbb Z}$，从中找出**真正对 $Y$ 有因果影响**的候选变量——而且允许存在未观测的多元时序 $U:=((U^1_t,\dots,U^m_t))$ 作为**潜在共同原因**（即**不假设因果充分性**）。

注意问题的目标很窄：**不是恢复整张因果图**，只回答"某个候选是不是 $Y$ 的原因"。这个窄目标正是它能做到"每个候选只需两次检验"的前提。

### 1.2 和 Granger 因果、普通特征选择的区别

| 路线 | 做法 | 在隐混杂下的表现 |
|---|---|---|
| 普通特征选择（相关性/互信息/lasso） | 选"预测力强"的变量 | 混杂变量与被选变量一样"预测力强"，**无法区分原因和共同结果** |
| Granger 因果 | 加不加 $X^i$ 的过去，看 $Y$ 的预测是否变好 | 需要**因果充分性**（无隐藏混杂）+ 无瞬时效应；混杂会造出伪边 |
| 图发现类（tsFCI、SVAR-FCI） | 恢复整张图（到 Markov 等价类） | 不假设充分性，但**条件集要穷举搜索**，CI 检验次数爆炸 |
| PCMCI / PCMCI+ | 先 PC 选父节点再 Momentary CI | FPR 比 Granger 低，但**仍依赖因果充分性** |
| seqICP | 用干预/环境不变性 | 需要**充分干预**且干预只作用于输入；只有观测数据时不可用；有隐混杂时只能找到祖先的**子集** |
| **SyPI（本文）** | 对每个候选**构造**一个条件集，做**两次** CI 检验 | 不做充分性假设；不搜索条件集；给出**充分（直接+间接原因）+ 必要（直接且 sg-unconfounded）**的保证 |

一句话对比：**别人是"先学图再读边"，SyPI 是"绕过整张图，直接对候选做两次判决"。**

### 1.3 潜在共同原因为什么让问题变难

时序列上的隐变量有两个额外麻烦，比 i.i.d. 情形更狠：

1. **它把过去也变成混杂源**。即使汇总图上 $X^i\to Y$ 是无混杂的，全时间图里 $X^i_t$ 与 $Y_{t+1}$ 仍可能被 $X^i_{t-1}$ 混杂（自己的过去同时决定 $X^i_t$ 和 $Y_{t+1}$）。原文 Fig. 2 就是在讲这一点，并明确指出：**目标序列直接受某个隐变量影响、或隐变量有记忆（multi-lag）时，"能 d-分离目标未来与其他变量过去"的条件集可能根本不存在**（原文脚注 †，第 3 页底）。
2. **隐变量有记忆 → 诱导出无穷阶关联**。这是 Malinsky & Spirtes (2018) 也没解决的已知问题；本文用图约束 A8/A9（限制滞后与"记忆"）把它挡掉。

### 1.4 三点贡献

1. 给出**充分条件**（Thm 1a/1b：直接 + 间接原因，单/多滞后图均 sound）与**必要条件**（Thm 2：单滞后图下"直接且 sg-unconfounded"的原因必满足），合起来即为该类原因的**充要条件**；
2. 每个候选**只需两次 CI 检验**，且条件集是**构造**出来的而非搜索出来的 → $O(n)$ 次检验，避免多重检验爆炸；
3. 条件集的选取方式**提高信噪比**（只条件化"进入结果节点的变量"，不条件化"候选自己的父节点"），并给出几乎零假阳的实验结果。方法名 SyPI = **Sy**stematic **P**ath **I**solation（系统性路径隔离）。

## 二、预备知识

### 2.1 两种图：全时间图 vs 汇总图

- **全时间图（full time graph, T1）**：以每个 $X^i_t, Y_t, U^j_t$ 为节点的**无限 DAG**（时间展开后的图）。
- **汇总图（summary graph, T2）**：把每个序列压成一个节点，若**存在**某个 $t\le s$ 使 $Q^j_t\to Q^k_s$，则画 $Q^j\to Q^k$。

关键区别：**汇总图上无混杂 ≠ 全时间图上无混杂**。全时间图才能表达"自回归造成的时序混杂"。

### 2.2 术语（原文 T3–T9，按需压缩）

| 记号 | 含义 | 为什么重要 |
|---|---|---|
| $Q^i_t\to Q^j_s$（T3） | 从 $Q^i_t$ 到 $Q^j_s$ 的**不经过任何中间观测节点**的有向路径 | 这是本文"直接原因"的定义：**可以为隐节点，只要没有中间观测变量** |
| $Q^i_t\rightsquigarrow Q^j_s$（T4） | 任意有向路径 | "间接原因"就是有中间观测节点 |
| 混杂路径（T5） | $Q^i_t \leftarrow\!\!* Q^k_{t'}\rightsquigarrow Q^j_s$ 形式，$t'\le t,s$ | 潜在共同原因 $L$ 造成的路径 |
| **sg-unconfounded**（T7） | 全时间图里的因果路径，在汇总图里**不呈现为混杂路径** | 充要条件只对"直接且 sg-unconfounded"的原因成立 |
| **lag $w$**（T8） | 从 $X^i_t$ 到 $Y_{t+v}$ 存在一条**无 collider、不含 $Q^r_{t'}\to Q^r_{t'+1}$ 这种"跨时刻"链接、且中间节点不属于 $X^i$ 或 $Y$** 的路径，则 $v$ 是一个 lag | 这是全文的"锚"：条件集完全由 lag 决定 |
| 单/多滞后（T9） | 每个 $(X^i,Y)$ 只有一个 lag $w_i$ → 单滞后；否则多滞后 | **Thm 2（必要性）只在单滞后下成立** |

> 讲解点：T8 那个"不含 $Q^r_{t'}\to Q^r_{t'+1}$"的排除项，是为了防止把"中间某个序列自己往前走了一步"误当成一条跨序列的滞后关系。原文 Fig. 1 (c) 的例子：若中间链路含 $X^r_{t+1}\to X^r_{t+2}$，整数 3 就**不是** lag。

### 2.3 潜在共同原因 $L$ 与条件独立性检验

论文假设（A1/A2）：全时间图上**因果马尔可夫条件 + 因果忠实性**成立。于是"条件独立"成为唯一可用的经验信息，而 d-分离是它的图论对应物。

可操作性：检验 $A \perp\!\!\!\perp B \mid C$。
- 线性高斯/线性加噪 → **偏相关检验**（论文模拟里就这么用）；
- 非线性 → **KCI / KCIPT / FCIT**（原文 5.2 节点名）；
- 时序特有麻烦：**自相关**使检验统计量的零分布发生偏移（§5 只提"可换非线性检验"，没讨论校准，见第五节思考 6）。

### 2.4 A1–A9 的分组与三点提醒

论文正文声明：A1–A5 是时序因果发现的标准假设，**A6–A9 是对图连通性的额外限制**（原文第 3 页）。其中：
- **A6：$Y$ 是 sink 节点**（无出边）。这不是装饰：它是"只做一个方向的检验就能处理瞬时效应"的代价（5.3 节明确说可用更轻的假设替换：$Y$ 的后代不在候选集中）；
- **A9** 只被 Theorem 2（完备性）需要，原文脚注 † 明确："违反 A9 不影响 Thm 1a/1b"；
- **A4 平稳性**：全时间图对全体变量做联合时间平移不变 → 条件集在不同 $t$ 上形状相同，这是"构造条件集"能成立的根本。

## 三、理论核心：两次 CI 检验为什么是充要的

> 这一节是全篇重点。建议按 3.1 → 3.6 的顺序读，先接受"三元组"的几何图像，再看条件集，最后看判定表。

### 3.1 要选的"目标量"到底是什么

不是"影响 $Y$ 的所有变量"，而是分三个层次（这也是"充要"必须分层表述的原因）：

| 目标 | 定义 | 本文能保证 |
|---|---|---|
| **直接原因** | $X^i_t \to Y_{t+w_i}$：全时间图上不经过任何中间**观测**节点（可有隐节点） | **充要**（单滞后图 + A6/A9） |
| **间接原因** | $X^i_t \rightsquigarrow Y_{t+w_i}$：有中间观测节点 | 只有**充分性**（Thm 1a/1b） |
| **sg-unconfounded 原因** | 该因果路径在汇总图上不被混杂路径"遮蔽" | 直接类可判充要；间接类只保证"检出的是真因果路径" |

所以严格表述是：**"对直接且 sg-unconfounded 的原因，条件 (1)(2) 是充要的；对间接原因，只是充分的。"** 原文明说 Thm 2 是"necessary conditions for a direct sg-unconfounded cause"，不能笼统说"本文给出所有原因的充要条件"。

### 3.2 关键几何观察：把"是不是原因"变成"路径能不能被隔离"

对每个候选 $X^i$，盯住一个**三元组**：

$$
\big(\underbrace{X^i_{t-1}}_{\text{候选的已知原因}},\ \underbrace{X^i_t}_{\text{候选本身}},\ \underbrace{Y_{t+w_i}}_{\text{目标的未来}}\big)
$$

- $X^i_{t-1}\to X^i_t$ 这条边**由 A7 保证存在**（每个序列都有一阶自环）。这一步至关重要：它让"候选的原因"变成**已知的**，于是不需要知道整张图就能构造三元组；
- 如果 $X^i_t$ 是 $Y$ 的原因，那么 $X^i_{t-1}$ 到 $Y_{t+w_i}$ 的依赖**必然经过** $X^i_t$（链式结构被 $X^i_t$ 中介）；
- 如果 $X^i_t$ 不是原因，只是与 $Y$ 有共同原因 $L$，那么 $X^i_{t-1}\to X^i_t \leftarrow L \rightsquigarrow Y_{t+w_i}$ 让 $X^i_t$ 成为 **collider**——**条件化 $X^i_t$ 会打开**这条路径，依赖反而保留。

**两条检验就是对这个几何结构的两问**：

1. **有没有值得一提的依赖？**（先确认 $X^i_t$ 与 $Y$ 的未来不是独立的）
2. **这份依赖是否被 $X^i_t$ 完全中介/吸收？**（条件化 $X^i_t$ 后，$X^i_{t-1}$ 与 $Y$ 的未来应当独立）

结合**时间顺序**（$X^i_t$ 严格早于 $Y_{t+w_i}$）与**忠实性**，"被中介"就只能是"存在有向路径"。所以两问合起来 = 因果陈述。**任何第三个检验都不能再提供信息**——必要性证明（Thm 2）做的是反方向：若真有直接 sg-unconfounded 因果路径，则 (1)(2) 必成立，故不存在"漏判"的空间。

> 与作者前作的关系：Mastakouri et al. (NeurIPS 2019) 在**静态 DAG** 里用"每个特征一次 CI 检验"，前提是**已知某变量是候选的原因**。本文的贡献正是用 A7 把"候选的原因"在时序里变成免费赠品，从而把 1 次检验升级为 2 次、并把结论从"充分"推到"充要"。

### 3.3 条件集 $S_i$ 怎么构造（论文最巧的一步）

设 $w_i$ 是 $X^i$ 与 $Y$ 之间的 lag（最小 lag，T8），令 $w_{ij}:=w_i-w_j$。对候选 $X^i$：

$$
S_i=\Big\{\,X^1_{\,t+w_{i1}-1},\ X^2_{\,t+w_{i2}-1},\ \dots,\ X^n_{\,t+w_{in}-1}\,\Big\}\setminus\{X^i\}
$$

即：**对其他每个时序 $X^j$，只取一个节点**，且这个节点恰好是"进入 $Y_{t+w_i-1}$ 的那个节点"（时间 $t+w_i-w_j-1$）。

构造逻辑（原文 3.1 节的直观解释，第 3–4 页）：

1. 先必须条件化 $Y_{t+w_i-1}$——否则 $X^i_t$ 与 $Y_{t+w_i}$ 的依赖会被"各自的过去"带进来（那是时序混杂，不是因果）；
2. 但条件化 $Y_{t+w_i-1}$ 又把它变成一个 **collider**（所有指向 $Y$ 的序列都在这里汇合），于是**打开了**经由 $X^j$ 的旁路；
3. 所以要从每个 $X^j$ 里condition一个节点，把它挡住；而"进入 $Y_{t+w_i-1}$ 的那个节点"正是应该挡的位置；
4. 只挡一个就够：若 $X^j$ 与 $Y$ 的路径是混杂的，条件化这个节点"不必要但**无害**"——因为 $X^j_{t+w_i-w_j}$ 按构造不在条件集里，它是 collider，路径仍被挡住（原文这段论证用平稳性 + "collider 不在条件集"两件事）。

最终条件集大小：$|S_i|+2=(n-1)+2=n+1$，**每个候选只做一个固定形状的集合，不需要搜索**。

### 3.4 Theorem 1a：充分性（单滞后）

> **Thm 1a（直接或间接 sg-unconfounded 原因的充分条件）**：假设 A1–A5、A7、A8 成立，且为单滞后依赖图。设 $w_i$ 为 $X^i$ 与 $Y$ 的最小 lag，$w_{ij}:=w_i-w_j$，$S_i$ 如 3.3 定义。若
>
> $$\text{(1)}\quad X^i_t \not\perp\!\!\!\perp Y_{t+w_i}\ \big|\ \{S_i,\ Y_{t+w_i-1}\}$$
>
> $$\text{(2)}\quad X^i_{t-1} \perp\!\!\!\perp Y_{t+w_i}\ \big|\ \{S_i,\ X^i_t,\ Y_{t+w_i-1}\}$$
>
> 同时成立，则 $X^i_t\rightsquigarrow Y_{t+w_i}$，且该路径 **sg-unconfounded**。

证明是**反证**（原文第 4 页）：
- 假设没有有向路径 $X^i_t\rightsquigarrow Y_{t+w_i}$，则由 lag 定义（路径无 collider）必存在一条**无 collider 的混杂路径** $X^i_t \leftarrow\!\!* Q^j_{t'}\rightsquigarrow Y_{t+w_i}$，$t'\le t$；
- 分两种情形：混杂节点 $Q^j_{t'}$ 落在 $\{S_i, Y_{t+w_i-1}\}$ 里 → 条件 (1) 被 d-分离 → **违反 (1)**；不在里面 → 用 $X^i_{t-1}\to X^i_t$ 这条边（A7）把 $X^i_t$ 变成 collider，条件化 $X^i_t$ 会**打开** $X^i_{t-1}$ 与 $Y_{t+w_i}$ → **违反 (2)**；
- 两种情形都矛盾 ⇒ 有向路径存在。sg-unconfounded 同理（若存在并行混杂路径，同样落到 (1) 或 (2) 被违反）。

### 3.5 Theorem 1b：多滞后下只剩充分性

> **Thm 1b**：假设同 Thm 1a，但**允许多滞后依赖图**。若条件 (1)(2) 成立，则 $X^i_t\rightsquigarrow Y_{t+w_i}$（**不保证** sg-unconfounded）。

**Remark 1**（原文）：Thm 1b 的条件对**任意** lag（按 T8）都成立，不只是最小 lag。

含义非常实用：**多滞后下不会产生假阳（sound），但可能漏（不完备）**。这解释了实验设计——主实验全部用单滞后图，多滞后只在附录验证 FPR 不升高（附录未包含，数字「未核实」）。

### 3.6 Theorem 2：必要性（单滞后 + 直接 + sg-unconfounded）

> **Thm 2（直接 sg-unconfounded 原因的必要条件）**：在 Thm 1a 的假设与定义之上，再加 **A6（$Y$ 为 sink）** 与 **A9**。若 $X^i_t$ 是 $Y_{t+w_i}$ 的**直接、sg-unconfounded** 原因（即 $X^i_t\to Y_{t+w_i}$），则条件 (1)(2) 必成立。

证明仍是反证：若 (2) 不成立，则 $\{S_i,X^i_t,Y_{t+w_i-1}\}$ 没有 d-分离 $X^i_{t-1}$ 与 $Y_{t+w_i}$，意味着存在 collider 型路径或无关链路径。原文把它拆成 (a) collider / collider 后代型与 (b) 无 collider 路径型，逐一排除：
- (a1) $Y_{t+w_i-1}$ 作 collider 但被其他直接原因 $Q^j$ 打开 → 若 $Q^j$ 观测则 $X^j_{t+w_{ij}-1}\in S_i$ 已挡住（这正是 $S_i$ 的构造）；若 $Q^j$ 隐藏则 A9 保证其 memoryless，打不开更远的路径；
- (a2) $X^i_t$ 作 collider → 等价于"$X^i_t$ 与 $Y$ 有共同原因"，与 sg-unconfounded 矛盾；
- (a3) 某 $X^j_{t'}\in S_i$ 作 collider → 由 $S_i$ 构造，$Y_{t+w_i-1}$ 一定是路径上的非 collider 且已在条件集中，矛盾；
- (a4) collider 的后代在条件集里 → 由单滞后假设强制 $w_C\equiv w_i$，矛盾；
- (b) 无 collider 路径 → 只能是 $X_{t-1}$ 与 $Y$ 的隐藏混杂或 $X_{t-1}\to Y$ 的直接边，前者与 sg-unconfounded 冲突、后者与单滞后冲突。

**Thm 1a + Thm 2 合并**：对"单滞后图 + 直接 + sg-unconfounded"的原因，条件 (1)(2) 是**充要**的。这就是标题里 "Necessary and Sufficient" 的准确含义——**不是对所有原因、也不是对所有图**。

### 3.7 两次检验的判定表（实践中最该背的表）

| 条件 1（是否依赖） | 条件 2（是否被 $X^i_t$ 中介） | 结论 | 理由 |
|:---:|:---:|---|---|
| **依赖**（$p_1<\alpha_1$） | **独立**（$p_2>\alpha_2$） | ✅ **是原因**（直接或间接，sg-unconfounded） | 有依赖 + 被候选中介 + 时间在先 ⇒ 有向路径 |
| 独立 | — | ❌ 不是原因 | 依赖已被 $S_i,Y_{t+w_i-1}$ 完全解释 |
| 依赖 | **仍依赖** | ❌ 不是原因 | 依赖不经过 $X^i_t$：来自潜在共同原因（collider 被打开）或走了别的路径 |
| 独立 | 独立 | ❌ 不是原因 | 同上，无信号 |

**为什么恰好两次？**
1. 第一问筛掉"无关变量"，第二问筛掉"混杂相关"。两问分别对应因果判定的两个必要成分：**关联** + **方向（由中介+时间序给出）**；
2. 时间序提供了方向信息，忠实性排除了"巧合抵消"，所以不需要第三问；
3. 必要性（Thm 2）证明了这个"筛子"不遗漏——任何真直接原因都会过筛。**充分性保证不误判、必要性保证不漏判，两者合起来才有"充要"**。

### 3.8 为什么这样选条件集能提高信噪比（SNR）

原文 5.1 节给的理由，加上我自己的整理：

| 做法 | 效果 | 来源 |
|---|---|---|
| 只条件化**进入结果节点**的变量（$Y_{t+w_i-1}$、$S_i$） | 解释掉 $Y$ 的方差 → 残差方差变小 → **同样强度的依赖在检验里更显著**（信号不变、噪声变小） | 原文 5.1 |
| **不**条件化候选 $X^i_t$ 的父节点 | 避免压缩候选自身方差；Henckel et al. (2019) 指出包含 exposure 父节点的调整集在渐近方差上**低效**，与 exposure 强相关时会削弱信号 | 原文引 Henckel et al. 2019 |
| 条件集**构造**而非搜索 | 避免"挑一个让 p 值最小的集合"这种选择偏差，也避免多重检验膨胀 | 原文 1 节末 |
| 只从每个序列取**一个**节点 | 条件维度 = $n$，而非 $n\times$滞后数；维度越低检验功效越高 | 原文 5.2 |

> 注意这是"统计效率"论证，不是"无偏"论证：SNR 高意味着在同样样本量下更容易过检验，等价于**降低假阴**。

### 3.9 图约束 A1–A9 一览（违反会怎样）

| 假设 | 内容 | 作用 | 违反的后果（我的推断，原文未逐条给） |
|---|---|---|---|
| A1 | 全时间图上的因果马尔可夫条件 | CI ⇔ d-分离，检验才有意义 | 检验结论不映射到图 |

| A4 | 平稳性（联合时间平移不变） | 条件集在所有 $t$ 同形；$S_i$ 可复用 | 分段/非平稳场景需重算 |

 时 间 :      t-1            t             t+1            t+2
                 ┌───────────────┐
 Y (sink):    Y_{t-1}  ──→    Y_t    ──→   Y_{t+1}  ──→  Y_{t+2}      ← A6: 无出边
                                 ↑             ↑
 X^i :   X^i_{t-2} ──→ X^i_{t-1} ──→ X^i_t ──→ X^i_{t+1}                ← A7: 自环
                              │        │  │

                              │        │
 L (hidden):   L_{t-1} ──→  L_t  ─────┘        ──→  Y_{t+2}
                              ↑                  （混杂路径：L → X^i_t，L ⇝ Y_{t+2}）
 X^j :   X^j_{t-1} ──→ X^j_t ──→ X^j_{t+1}
                           │
                           └────────────────→ Y_{t+1}                    (w_j = 1)
 若 w_i = 2, w_j = 1，则候选 X^i 的条件集：
   S_i = { X^j_{t + w_i - w_j - 1} } = { X^j_{t} }

## 四、算法与实验

### 4.1 SyPI 算法（原文 Algorithm 1，逐行对照）

```
输入: 候选 X (2D), 目标 Y
输出: causes_of_R
w = min_lags(X, Y)                      # Lemma 1：用 lasso 双变量回归求最小 lag
for i = 1 to nvars:
    S_i = ⋃_{j ≠ i} { X^j_{t + w[i] - w[j] - 1} }
    p1 = CI_test(X^i_t, Y_{t+w[i]}, [S_i, Y_{t+w[i]-1}])       # 条件 1
    if p1 < threshold1:                  # 拒绝"独立" ⇒ 存在依赖
        p2 = CI_test(X^i_{t-1}, Y_{t+w[i]}, [S_i, X^i_t, Y_{t+w[i]-1}])   # 条件 2
        if p2 > threshold2:              # 接受"独立" ⇒ 依赖被 X^i_t 中介
            causes_of_R.append(X^i_t)
```

要点：
- **复杂度 $O(n)$**（原文声明，假设单次 CI 检验为常数时间）；总共 $2n$ 次检验，且**短路**（条件 1 不过就不做条件 2）→ 实际更少；
- **阈值不对称**：$p_1<\alpha_1$ 要"强依赖"，$p_2>\alpha_2$ 要"独立"，且实验取 $\alpha_1=0.01,\ \alpha_2=0.2$。这是**偏保守的设计**：宁可漏（假阴）也不误报（假阳）——与实验结果（FPR<1%、FNR 12~45%）完全一致；
- **lag 用 Lemma 1 求**：若路径都是有向的，最小 lag $w_j$ 等于使 $X^j_t \not\perp\!\!\!\perp Y_{t+w'_j}\mid X^j_{\text{past}(t)}$ 的最小非负整数 $w'_j$。**唯一例外**：混杂路径里含"有记忆的第三序列"时 $w'_j=0$。
  - **Lemma 2**：把定理里的 $w_j$ 换成 $w'_j$ 后，Thm 1a/1b/2 仍成立。
  - 实现上：每个候选对 $Y$ 做**双变量 lasso 回归**（滞后截断），取系数非零的最小滞后作为 $w$；$\lambda=0.001$、系数截断 0.1，**整个实验固定不调**。

## 五、论文未展开的细节与个人思考

> 标注规则：**[原文未说明]** = 论文正文没写；**[我的判断]** = 我的推断或经验判断，无原文支撑。

1. **CI 检验的功效选择 [原文未说明具体选型依据]**：线性用偏相关没问题，但真实 CPS 的传感器关系（阀门开度→流量）是非线性的，必须换 KCI/FCIT。而 KCI 的复杂度随样本量约 $O(n^2)\sim O(n^3)$，$2n$ 次检验在 $n=50$ 候选时计算量可观。**[我的判断]** 论文的"低 FPR"在相当程度上是**线性高斯 + 忠实性 + 大样本**三重加持的结果，换成非线性检验后 FPR 很可能上升，作者没有给出非线性模拟实验（正文只提到"可以换"，附录未包含）。

2. **小样本的实证 [原文承认]**：真实数据样本 <180 时作者自己说"particularly hard"，只能放宽阈值。**[我的判断]** 这说明该方法的理论保证（充要）是**渐近/总体层面**的，有限样本下退化为"两次统计检验"，保证强度取决于检验功效。不要把它当"定理即结论"来用。

3. **平稳性（A4）在真实场景几乎不成立 [原文未讨论]**：事故时序必然非平稳（事故演化有趋势、有阶段切换）。恒定的 $S_i$ 形状依赖平稳性。**[我的判断]** 可行补救是把轨迹按阶段切段、段内做局部平稳假设；但这会进一步减少每段样本量，与第 2 点冲突。

4. **多重检验与误差累积 [原文未讨论]**：$n$ 个候选 × 2 次检验 = $2n$ 次，论文**没有**做 Bonferroni/FDR 校正（正文未提及；附录未包含，未核实）。$\alpha_1=0.01,\alpha_2=0.2$ 的选取是经验性的，也没有敏感性分析。**[我的判断]** 在 $n$ 较大时，即便单次 FPR 很低，整体家族错误率仍会抬升；这是它能报出"<1% FPR"的部分原因（FPR 按图/按候选平均的定义也影响解读）。

5. **单滞后 vs 多滞后 [原文明确]**：Thm 2 只在单滞后图成立；多滞后下只有 sound（Thm 1b），完备性丢失。原文 5.2 说若要多滞后需要"每序列多于一个条件节点"，但会"显著影响统计结果"，故放弃。**[我的判断]** 核工业过程里，同一对变量的影响常跨多个滞后（瞬态+稳态），这会系统性造成假阴。

6. **自相关对 CI 检验校准的影响 [原文未讨论]**：时序 CI 检验的经典问题是零分布不准（简单 permutation 会低估方差 → 假阳膨胀）。论文用偏相关（在线性高斯 VAR 下算是有理论依据的），但没有讨论残差自相关是否已被 VAR 结构吸收。**[我的判断]** 若真做工程实现，应先用 VAR 预白化残差再做偏相关，或用 block/循环置换（cyclic shift）做检验，这是比换非线性检验更优先的修正。

7. **A6（$Y$ 是 sink）是"回避"瞬时效应而非"处理" [原文明确]**：5.3 节说 A6 是为了"只用两次检验就能处理瞬时效应"，并给出替代：若 $Y$ 的后代不在候选集中可换更轻的假设；或对两个方向各测一遍（检验次数翻倍）。**[我的判断]** 在 RCA 场景里"目标变量是 sink"通常不成立（压力影响水位、水位影响压力），这是该方法迁移的最大结构性障碍。

8. **A7 的作用被低估 [我的判断]**：条件 2 的参照点 $X^i_{t-1}$ 完全依赖"A7 保证存在自环"。若某个传感器是纯白噪声或采样过粗导致一阶自相关≈0，条件 2 就退化成"检验两个几乎无关的量"，功效骤降。原文未讨论 A7 的检验/弱化方式。

9. **附录缺失导致的核对缺口 [本笔记的限制]**：定理证明细节（App. Sec. 2 的 Lemma 证明）、多滞后实验（App. Sec. 6.5.4）、ROC 曲线（App. Sec. 6.6）、以及定义 3（Granger，App. Sec. 3）都无法核对。本笔记对 Lemma 1/2 的表述取自正文，证明过程标注为「未核实」。

10. **"必要性"的实用价值被表述得偏弱 [我的判断]**：必要性意味着"真原因不会被漏掉"，但实验里直接原因 FNR 仍达 12–45%——说明真实瓶颈在**统计功效**而非**条件集的图论正确性**。这个区分很重要：理论上的充要 ≠ 实践上的可靠检出。

## 六、迁移思考：与我的"变量选取机制"及 CausalTrace 的关系

> 背景：CausalTrace（AAAI-26）用 NPPAD 核电站事故多变量时序做 RCA（当前聚焦 LOCA），主线是"固定 LiNGAM 因果发现 → 轨迹级 Bootstrap 四指标 → 总因果效应 $T=(I-B)^{-1}$ → 反事实验证"，结论按"实现正确性 / 统计稳定性 / 物理一致性"三类分开报告。v2.3 正在做"12 类事故全适配 + **变量选取机制**"，目前选取是**启发式**（按事故类型手工筛 + 相关性/稳定性阈值），**缺理论保证**。

### 6.1 能力对比

| 维度 | 我现在的启发式 | SyPI（本文） | 现有 LiNGAM + Bootstrap |
|---|---|---|---|
| 输出 | 变量白名单（人工+阈值） | 每个候选：是/否原因（直接可区分间接） | 结构 $B$ + 总效应排序 |
| 隐混杂 | 靠"物理上不可能"人工排除 | **显式支持**（不假设充分性） | LiNGAM 假设无隐混杂（或用 RCD/ bottoms-up 扩展） |
| 理论保证 | 无 | 单滞后 + A6/A9 下**充要**（直接类） | LiNGAM 可识别性依赖非高斯 + 无隐混杂 |
| 计算量 | 人天级手工 + 相关性矩阵 | $2n$ 次 CI 检验（可短路） | 全图 + Bootstrap（数百次重采样） |
| 目标 sink 要求 | 无 | **A6 强制** | 无 |
| 时刻/路径信息 | 无 | 只给 lag $w_i$（可粗定位滞后） | 无反事实时刻粒度 |

### 6.2 它能给什么保证（在 NPPAD 这种大量潜在混杂的场景）

NPPAD 的潜在混杂来源很具体：**未测传感器**（温度/流量测点缺失）、**控制回路**（PID 把多个变量锁在设定值附近，制造共同原因）。这两种都符合"潜在共同原因"的图像。

- **能给的**：在不假设因果充分性的前提下，对每个候选变量给出**"直接且 sg-unconfounded 原因"的充要判定**，且假阳极低（<1%）。这正好补上你"变量选取无理论保证"的缺口——**它能把"手工筛"替换成"可陈述前提的判决"**，论文里可以直接写"变量选取基于 SyPI 的充要条件（ICML 2021）"，比"按经验阈值"强得多。
- **不能给的**：① 它不恢复结构、不给强度/效应量，$T=(I-B)^{-1}$ 仍需 LiNGAM；② 它只回答"$X^i$ 是否 $Y$ 的原因"，不能直接产出多变量联合根因排序；③ 它不处理瞬时效应（A6 是回避），而你 LOCA 场景里 WLR↔P 恰恰是快速耦合。

### 6.3 可落地的最小改法（不动主线，只加一层剪枝）

建议做成 **"SyPI 预剪枝 + LiNGAM 精修"** 的两段式，v2.3 里作为变量选取的**第一段**：

1. **定义目标与候选池**：目标 $Y$ 取 LOCA 的主指标（如 RCS 压力或稳压器水位，按你现有定义）；候选池只放**物理上游**变量，并排除报警类/下游变量——不是为了别的，就是为了让 **A6（$Y$ 近似 sink）** 尽量成立，这是唯一能低成本满足的假设。
2. **求 lag**：对每个候选做双变量 lasso/岭回归（滞后截断），按 Lemma 1 取最小非零滞后 $w_i$；顺带记录 $w_i=0$ 的候选（**[我的判断]** 这很可能是"只有混杂、没有因果"的嫌疑对象，可作为人工复核的优先队列）。
3. **构造 $S_i$ 并做两次检验**：$S_i$ 里每个其他候选取一个节点（时间 $t+w_i-w_j-1$）；先做 VAR 预白化再做偏相关（非线性段可换 KCI），$\alpha_1=0.01$、$\alpha_2=0.2$（照抄论文的保守设定）。
4. **输出三类标签**：`direct`（过两检验且 $w_i$ 小）/ `indirect`（过两检验但被其他直接原因中介）/ `rejected`。在 v2.3 的变量表里加一列 `sypi_status`，与现有"手工筛 + 稳定性"结果并列，**做一致性对照而不是直接替换**。
5. **对照实验（这是能写进论文的部分）**：比较三种候选池——① 现行启发式；② SyPI 剪枝后；③ 全集——在相同 LiNGAM + Bootstrap 流程下比较四指标与 $T$ 排序的稳定性。若 ② 在稳定性指标上不劣于 ① 且候选数显著减少，即证明"理论剪枝"有效。**成本可控：SyPI 层是纯 Python + scipy/statsmodels，不需要训练。**

### 6.4 不适合直接照搬的理由（必须在论文里写清）

| 障碍 | 具体表现 | 应对 |
|---|---|---|
| **A6（$Y$ sink）** | NPPAD 里压力/水位双向耦合，目标必有出边 | 只对"物理上游子集 + 单向下游目标"应用；或按 5.3 节建议做双向各测一遍（检验数 ×2） |
| **A7/A8（一阶自环、无跨步自环）** | 控制回路变量（积分项、滞后执行器）有长记忆 | 预白化/差分后检验；论文 A8 违反时需多节点条件集，维度上升 |
| **A9（隐变量 memoryless）** | 未测传感器漂移、控制器积分项都有记忆 | 无法保证 → **Thm 2 完备性失效**，只能当"充分条件"用（宁可漏不可误） |
| **A4（平稳性）** | 事故轨迹非平稳、12 类事故机制不同 | 按事故阶段分段；跨事故不要共用一个 $S_i$ |
| **单滞后假设** | 同一对变量常跨多个滞后 | 已知会漏；作为剪枝手段可接受（剪枝允许保守） |
| **输出二值** | 不给效应量/结构 | 只作第一段，效应排序仍交给 LiNGAM 的 $T$ |
| **样本量** | 单类事故轨迹段可能不足 500 | 论文的经验门槛是"样本 > 500 时 FPR < 1%"；不足时只能放宽阈值并降级为"弱证据" |

### 6.5 结论

**能加固，不能替换。** 具体定位：

- **替换**：把"相关性/稳定性阈值"这一层换成"两次 CI 检验 + 明确前提"的判决 → 变量选取从经验变成可陈述、可复现、可引用的规则；
- **保留**：手工筛不废弃，但角色变了——从"选变量"变成"构造满足 A6 的候选池"（这时手工知识是在**保证假设**，而不是在**替代方法**）；
- **边界**：SyPI 的充要性只覆盖"单滞后 + 直接 + sg-unconfounded + A6/A9 成立"的情形；NPPAD 大概率不满足全部，因此**在论文里必须写成"在若干图约束下的保守剪枝"，而不是"证明了根因"**——这与你现有的"三类结论分开报告"（实现正确性 / 统计稳定性 / 物理一致性）口径一致，不要混。

风险提醒：**[我的判断]** 如果直接声称"采用 SyPI 的充要条件保证了变量选取正确"，审稿人会立刻问 A6/A9 是否成立。更稳的写法是：把 SyPI 定义为"在显式图约束下的充分条件剪枝"，并给出违反假设时的实证（例如：把 $w_i=0$ 的候选单独标记、做一次 A6 违反的消融），让"保证"变成"有条件的保证 + 边界实验"。

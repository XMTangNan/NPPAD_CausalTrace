## 一、问题背景与核心思想

### 1.1 问题定义

多变量时序的**根因分析（Root Cause Analysis, RCA）**要回答：当系统出现异常时，**哪个变量在什么时刻**是异常的源头？

以水处理厂为例：pH、水位、电导率等传感器构成多变量时序。攻击者投加过量氢氧化钠 → pH、电导率异常，并通过因果链波及其他指标。RCA 要从"涟漪"中找到最初被干预的变量。

### 1.2 现有方法的两类局限

| 路线 | 代表工作 | 局限 |
|------|---------|------|
| 假设因果结构已知 | Budhathoki et al. 2022, Assaad et al. 2023b | 真实场景中因果图不是先验 |
| 从数据学因果图 | Yang et al. 2022, Meng et al. 2020 | 直接套用通用因果发现算法，**未显式建模外生变量**，无法定位根因 |

关键矛盾：现有因果发现只关心**内生变量（endogenous）之间的结构**，忽略了**外生变量（exogenous）**——而异常恰恰是对外生变量的干预。

### 1.3 核心思想：异常 = 外生变量上的干预

论文将异常建模为对结构因果模型（SCM）中外生变量的干预（**exogenous intervention**）：

- 正常状态下，外生变量服从稳定分布；
- 异常发生时，某个外生变量被干预，偏离其正常分布；
- 因此，**根因定位 = 找出显著偏离正常分布的外生变量**。

> 论文脚注 1 特别提醒：并非所有攻击都能视为外生干预，应用前需先判断异常性质。

### 1.4 三点贡献

1. 提出**编码器-解码器**结构做 Granger 因果发现，既能学因果关系，又能捕获外生变量分布；
2. 基于学到的 SCM，不仅定位根因变量，还能定位**根因时间步**；
3. 在合成与真实数据集上，因果发现和根因定位均达到 SOTA。

## 二、预备知识：Granger 因果性

### 2.1 定义

给定平稳时序 $X = (x_1, \dots, x_T)$，$x_t \in \mathbb{R}^d$。真实数据生成机制为：

$$
x_t^{(j)} := f^{(j)}(x_{\le t-1}^{(1)}, \dots, x_{\le t-1}^{(d)}) + u_t^{(j)}, \quad 1 \le j \le d \tag{1}
$$

其中 $u_t^{(j)}$ 是时序 $j$ 在时刻 $t$ 的**外生变量**，$f^{(j)}$ 刻画过去值对当前值的影响。

**时序 $i$ Granger 导致 $j$**，当且仅当 $f^{(j)}$ 依赖于 $x_{\le t-1}^{(i)}$，即改变 $i$ 的过去会改变 $j$ 的当前预测。

### 2.2 两条隐含假设（及其局限）

| 假设 | 含义 | 违反后果 |
|------|------|---------|
| 无隐藏混杂 | 所有相关变量都被观测到 | 可能出现虚假因果 |
| 无瞬时效应 | 影响必有时间滞后 | 同步变化的变量无法识别因果方向 |

> 这两条假设在 SWaT 真实数据集上被违反，是 AERCA 在 SWaT 上表现下降的主因（见 5.4 节）。

## 三、AERCA 方法论（核心）

### 3.1 问题建模：外生干预下的异常

基于式 (1)，异常 $\tilde{x}_t^{(j)}$ 被定义为外生变量被干预：

$$
\tilde{x}_t^{(j)} = f^{(j)}(x_{\le t-1}^{(1)}, \dots, x_{\le t-1}^{(d)}) + \hat{u}_t^{(j)} = f^{(j)}(\cdot) + u_t^{(j)} + \epsilon_t^{(j)} \tag{2}
$$

其中 $\hat{u}_t^{(j)} = u_t^{(j)} + \epsilon_t^{(j)}$，$\epsilon_t^{(j)}$ 是异常项。

**两类异常**：
- **点异常（point anomaly）**：某时刻对某变量的单次极端干预；
- **序列异常（sequential anomaly）**：干预通过因果结构随时间传播，或持续多步的干预。

> 由此引出本文的差异化定位：已有方法只能定位"根因变量"，AERCA 能定位"根因变量 + 根因时间步"。

**定义 1（根因识别）**：定位在特定时间步 $t$ 具有异常外生变量 $\hat{u}_t^{(j)}$ 的时序/变量 $j$。

### 3.2 整体框架：编码器（溯因）+ 解码器（演绎）

```
┌──────────────────────────────────────────────────────────────────────┐
│                         AERCA 框架                                    │
│                                                                       │
│  观测数据 x_{≤t-1}                                                    │
│       │                                                               │
│       ▼                                                               │
│  ┌─────────────────┐     溯因推理 (Abductive)                         │
│  │   Encoder ω_θ   │ ──► u_t = x_t - Σ ω_k(x_{t-k})·x_{t-k}  (Eq.6)  │
│  │  (K 个神经网络)  │     推断外生变量（"果→因"）                       │
│  └────────┬────────┘                                                  │
│           │ 外生变量 U_t                                               │
│           │ + 独立性约束 D_KL(P(U_t)‖N(0,I))  (Eq.7)                  │
│           ▼                                                           │
│  ┌─────────────────┐     演绎推理 (Deductive)                         │
│  │   Decoder ω̄_θ   │ ──► x̂_t = Σ ω̄_k(u_{t-k})·u_{t-k}               │
│  │  + ω̄'_θ' (观测) │     + Σ ω̄'_k(x_{t-K-k})·x_{t-K-k} + u_t  (Eq.9)│
│  └────────┬────────┘     从外生变量重构观测（"因→果"）                  │
│           │                                                           │
│           ▼                                                           │
│      重构 x̂_t  ──► 重建损失 ‖x̂_t - x_t‖²                              │
│                                                                       │
│  因果图聚合：S_{i,j} = max_k median_t |(ω_θ^k(x_{t-k}))_{i,j}|        │
│  阈值 τ → 邻接矩阵 A                                                   │
└──────────────────────────────────────────────────────────────────────┘
```

设计哲学：
- **编码器模拟溯因推理**：从观测数据反推最可能的外生变量（原因）；
- **解码器模拟演绎推理**：从外生变量（原因）重构观测数据（结果）。

### 3.3 编码器：参数化 Granger 因果

将式 (1) 参数化为窗口内自回归形式：

$$
x_t = \sum_{k=1}^{K} \omega_{\theta_k}(x_{t-k})\, x_{t-k} + u_t \tag{5}
$$

- $\omega_{\theta_k}$ 是第 $k$ 个神经网络，输出可 reshape 为 $d \times d$ 系数矩阵；
- 矩阵元素 $(i,j)$ 表示 $x_{t-k}^{(j)}$ 对 $x_t^{(i)}$ 的影响；
- $K$ 个网络覆盖 $K$ 个时间滞后，最终通过聚合得到总结因果图。

编码器由式 (5) 改写得到**外生变量**：

$$
u_t = x_t - \sum_{k=1}^{K} \omega_{\theta_k}(x_{t-k})\, x_{t-k} \tag{6}
$$

对一个窗口 $W_t = (x_{t-K+1}, \dots, x_t)$，编码器跑 $K$ 次得到窗口内外生变量 $U_t = (u_{t-K+1}, \dots, u_t)$。

### 3.4 独立性约束：外生变量必须相互独立

**核心假设**：不同时序的外生变量相互独立。为强制这一点，约束 $U_t$ 的分布趋近**各向同性标准高斯** $Q \sim \mathcal{N}(0, I)$，用 KL 散度度量：

$$
D_{KL}^t(P(U_t)\|Q) = \frac{1}{2}\left( \text{tr}(\Sigma_t) + \mu_t^T\mu_t - d - \log\det\Sigma_t \right) \tag{7}
$$

其中 $\mu_t, \Sigma_t$ 是 $U_t$ 的均值和协方差，$\mu_Q = 0, \Sigma_Q = I$。

> 这个约束是 AERCA 的关键设计。消融实验（见 5.5 节）证明：去掉它，因果发现性能大幅下降。直觉是：如果不强制外生变量独立，编码器可能把因果效应"藏"进外生变量的相关性里，导致学到的因果图失真。

### 3.5 解码器 + Proposition 1：为什么只需要有限窗口？

**挑战**：理论上 $x_t$ 依赖于 $t$ 之前**所有**外生变量（递归展开式 (1) 可得），但时序长度可能无穷，无法全用。

**Proposition 1**：对自回归模型 $x_t = \sum_{k=1}^K \omega_k x_{t-k} + u_t$，当前值 $x_t$ 可由**前一个窗口的外生变量** $[u_{t-1}, \dots, u_{t-K}]$ 和**再前一个窗口的观测值** $[x_{t-K-1}, \dots, x_{t-2K}]$ 表示：

$$
x_t = \sum_{m=1}^{K} \alpha_{K-m} u_{t-(K-m)} + \alpha_K x_{t-K} + \sum_{m=2}^{K+1} \alpha_{K+1-m} \sum_{k=m}^{K} \omega_k x_{t-k-(K+1-m)} \tag{8}
$$

其中 $\alpha_n = \sum_{i=1}^n \omega_n \alpha_{n-i}$（$\alpha_0 = 1$）是递归系数。

**证明思路**（附录 A.1）：反复将 $x_{t-1}, x_{t-2}, \dots$ 用其自回归方程代入，每代一步，系数按 $\alpha_n$ 递归聚合。代入 $K$ 次后，$x_t$ 被展开为 $K$ 个外生变量项 + 一个观测值项 + 一组更早观测值的加权和。详细推导见原文附录 A.1。

**解码器实现**（受 Proposition 1 启发）：

$$
\hat{x}_t = \sum_{k=1}^{K} \bar{\omega}_{\bar{\theta}_k}(u_{t-k})\, u_{t-k} + \sum_{k=1}^{K} \bar{\omega}'_{\bar{\theta}'_k}(x_{t-K-k})\, x_{t-K-k} + u_t \tag{9}
$$

- 第一部分：前一窗口外生变量对当前的影响（神经网络 $\bar{\omega}_{\bar{\theta}_k}$ 参数化）；
- 第二部分：再前一窗口观测值的影响（神经网络 $\bar{\omega}'_{\bar{\theta}'_k}$）；
- $u_t$：当前外生变量（直接来自编码器）。

### 3.6 目标函数

$$
\mathcal{L} = \sum_{t=K+1}^{T} \Big\{ \|\hat{x}_t - x_t\|^2 + \beta D_{KL}^t + \lambda_{en} R(\Omega_t) + \lambda_{de} R(\bar{\Omega}_t) + \lambda_{de} R(\bar{\Omega}'_t) \Big\} + \sum_{t=K+1}^{T-1} \Big\{ \gamma_{en} S(\Omega_{t+1}, \Omega_t) + \gamma_{de} S(\bar{\Omega}_{t+1}, \bar{\Omega}_t) + \gamma_{de} S(\bar{\Omega}'_{t+1}, \bar{\Omega}'_t) \Big\} \tag{10}
$$

| 项 | 含义 | 作用 |
|----|------|------|
| $\|\hat{x}_t - x_t\|^2$ | 重建损失 | 保证解码器能从外生变量重构观测 |
| $\beta D_{KL}^t$ | 独立性约束 | 强制外生变量相互独立（核心） |
| $R(\cdot)$ | L1+L2 稀疏惩罚 | 因果图稀疏化，鼓励少数强边 |
| $S(\cdot,\cdot) = \|\Omega_{t+1} - \Omega_t\|^2$ | 平滑惩罚 | 相邻时刻因果结构不应剧变 |

其中 $\Omega_t = [\omega_{\theta_K}(x_{t-K}) : \cdots : \omega_{\theta_1}(x_{t-1})]$ 是 $K$ 个系数矩阵的拼接；$\bar{\Omega}_t, \bar{\Omega}'_t$ 类似。

### 3.7 因果图聚合

编码器的 $K$ 个网络输出 $K$ 个系数矩阵，聚合为总结因果强度矩阵：

$$
S_{i,j} = \max_{1 \le k \le K} \Big\{ \text{median}_{K+1 \le t \le T} \big( |(\omega_{\theta_k}(x_{t-k}))_{i,j}| \big) \Big\}
$$

$S_{i,j}$ 表示 $x^{(i)} \to x^{(j)}$ 的 Granger 因果强度。设阈值 $\tau$（实验中取系数矩阵的分位数），$S_{i,j} > \tau$ 则 $A_{i,j} = 1$。

## 四、根因定位

训练完成后（仅用正常数据），部署时**流式**处理：

1. 新时刻 $t^*$ 到达，用编码器按式 (6) 算出 $u_{t^*}$；
2. 对每个时序 $j$，计算 **z-score** 作为根因得分：

$$
z_{t^*}^{(j)} = \frac{u_{t^*}^{(j)} - \mu^{(j)}}{\sigma^{(j)}}
$$

其中 $\mu^{(j)}, \sigma^{(j)}$ 是正常数据外生变量的均值和标准差。

3. 用 **SPOT（Streaming Peaks-Over-Threshold, Siffer et al. 2017）** 动态确定阈值，标记潜在根因。

> 关键优势：因为每个时刻都显式计算外生变量，即使异常通过因果链传播到下游变量，AERCA 也能区分"根因"和"下游影响"——根因的外生变量偏离正常，下游变量的外生变量仍正常。

## 五、实验与评估

### 5.1 数据集

| 数据集 | 维度 | 训练序列数 | 测试序列数 | 平均长度 | 平均根因变量数 | 类型 |
|--------|:----:|:---------:|:---------:|:--------:|:--------------:|------|
| Linear | 4 | 5,000 | 100 | 500 | 3.75 | 合成 |
| Nonlinear | 6 | 5,000 | 100 | 500 | 5.25 | 合成 |
| Lotka-Volterra | 40 | 40,000 | 100 | 2,000 | 30.75 | 合成 |
| Lorenz 96 | 20 | 200,000 | 100 | 2,000 | 15.75 | 合成 |
| SWaT | 51 | 49,500 | 20 | 51 | 13.35 | 真实（水处理） |
| MSDS | 10 | 29,268 | 4,255 | 21 | 3.05 | 真实（分布式系统） |

- 训练集仅含正常时序；
- 合成数据集在测试时随机注入 1 次或多次外生干预生成异常；
- SWaT 每 10 秒下采样，MSDS 每 5 步下采样。

**四个合成数据集的生成机制**（附录 A.2.1）：

| 数据集 | 机制 | 特点 |
|--------|------|------|
| Linear | $x_t^{(j)} = a x_{t-1} + u_t + \epsilon_t$，系数 $a_i \sim U([-0.8,-0.2]\cup[0.2,0.8])$ | 线性链状因果 |
| Nonlinear | $X_t = A^T \sum_{m=1}^t \beta_m \cos(X_{t-m}+1) + \epsilon$，邻接矩阵 Erdős–Rényi | 余弦非线性 |
| Lotka-Volterra | 捕食者-猎物生态系统微分方程，20 猎物 + 20 捕食者 | 高维非线性 |
| Lorenz 96 | $\frac{dx^{(i)}}{dt} = (x^{(i+1)}-x^{(i-2)})x^{(i-1)} - x^{(i)} + F$ | 混沌非线性 |

**异常注入方式**：
- 点异常：$\epsilon_t = [0, 2, 4, 0]$ 表示第 2、3 个时序在 $t$ 时刻取极端值；
- 序列异常：趋势型 $\epsilon_{t+i}^{(1)} = 0.1 \times i$、shapelet 型 $\epsilon_{t+i}^{(1)} \sim \mathcal{N}(0, 0.16)$、季节型等。

### 5.2 评估指标

**因果发现**：F1、AUC-PR、AUC-ROC、Hamming 距离（HD）。

**根因定位**：Recall@Top-K，记为 **AC@K**：

$$
\text{AC@K} = \frac{1}{|X|} \sum_{X \in \mathcal{X}} \frac{|V(RC)_X \cap \{R_X[k] | k=1,\dots,K\}|}{\min(K, |V(RC)_X|)}
$$

- $R_X[k]$：序列 $X$ 中排名第 $k$ 的时序；
- $V(RC)_X$：序列 $X$ 的真实根因变量集合（同一时序多次干预只算一个）。

综合指标 $\text{Avg@K} = \frac{1}{K}\sum_{k=1}^K \text{AC@k}$。

**更精细的指标 AC*@K**（附录 A.2.3）：把所有时间步的所有 $(变量, 时刻)$ 对作为候选，评估能否定位到**根因变量在根因时刻**。候选数达 $T \times d$ 量级（成千上万），难度远高于 AC@K。

### 5.3 因果发现结果（Table 2）

| 数据集 | 模型 | F1 | AUC-PR | AUC-ROC | HD |
|--------|------|:--:|:------:|:-------:|:--:|
| Linear | AERCA | **1.000** | **1.000** | **1.000** | **0.000** |
| Nonlinear | AERCA | **0.826** | **0.996** | **0.998** | **0.027** |
| Lotka-Volterra | AERCA | **0.857** | **1.000** | **1.000** | 0.026 |
| Lorenz 96 | AERCA | **0.800** | **0.998** | **0.999** | 0.105 |

**结论**：
- Linear 上完美（F1=1, HD=0）；
- 三个非线性数据集上，AERCA 在 F1、AUC-PR、AUC-ROC 全面领先，HD 极低；
- 没有任何基线能同时在 Nonlinear 和 Lorenz96 上取得满意结果。

### 5.4 根因定位结果（Table 3）

| 数据集 | AERCA AC@1 | AERCA Avg@10 | 最佳基线 AC@1 | 最佳基线 Avg@10 |
|--------|:----------:|:------------:|:-------------:|:---------------:|
| Linear | **1.000** | **1.000** | 0.900 (ε-Diagnosis) | 0.950 |
| Nonlinear | **1.000** | **1.000** | 0.700 (CIRCA) | 0.878 |
| Lotka-Volterra | **1.000** | **1.000** | 0.120 (CIRCA) | 0.158 |
| Lorenz 96 | **0.996** | **0.990** | 0.360 (CIRCA) | 0.421 |
| SWaT | **0.220** | **0.342** | 0.075 (ε-Diagnosis) | 0.180 |
| MSDS | 0.381 | **0.896** | 0.454 (CIRCA) | 0.821 |

**结论**：
- 四个合成数据集上 AERCA 近乎完美，大幅领先基线；
- SWaT 上所有方法性能下降，论文归因于**假设违反**（独立性不成立、存在隐藏混杂和瞬时效应），但 AERCA 仍显著优于基线；
- MSDS 上 AERCA AC@1 略低于 CIRCA（0.381 vs 0.454），但 Avg@10 最高（0.896），说明排序质量整体最好。

**特定时间步定位（Table 4, AC*@K）**：

AERCA 在 Lotka-Volterra 上 AC*@1 = 0.997，Lorenz96 上 0.842，Linear 上 0.763——在成千上万候选中精确锁定根因变量+时刻，而三个基线的 AC*@1 几乎全为 0，证明 AERCA 的核心优势。

### 5.5 消融实验：独立性约束的重要性

去掉式 (7) 的独立性约束后：
- Linear、Nonlinear、Lotka-Volterra 上因果发现性能**大幅下降**；
- Lorenz 96 上影响较小但仍下降。

**结论**：独立性约束是 AERCA 能正确学因果图的关键——它迫使编码器不把因果效应混进外生变量的相关性中。

## 六、论文未展开的细节与个人思考

1. **Granger 因果假设的现实约束**：论文承认无隐藏混杂、无瞬时效应两条假设在 SWaT 上不成立。核工业场景中传感器密集、控制回路闭合，瞬时效应和双向耦合普遍存在，这会直接限制 AERCA 的适用性——这是工程落地前必须正视的问题。

2. **外生变量分布假设过强**：独立性约束用各向同性高斯 $\mathcal{N}(0, I)$ 作为目标分布。真实系统外生变量未必高斯（如设备磨损的渐变量、间歇扰动的重尾分布），论文未讨论非高斯外生变量的处理。SWaT 性能下降可能部分源于此。

3. **窗口长度 K 的选择**：论文未系统讨论 K 的选取策略。Proposition 1 的推导依赖固定 K，实际因果滞后可能远超 K，此时截断会引入偏差。Lorenz 96 的高维混沌可能需要较大 K。

4. **阈值 τ 的确定**：因果图邻接矩阵的阈值 τ 基于系数矩阵 S 的分位数，但具体分位数未给出。这是因果发现的常见自由度，影响 F1 等指标。

5. **MSDS 上 AC@1 不及 CIRCA**：AERCA 在 MSDS 上 AC@1=0.381 < CIRCA=0.454，虽然 Avg@10 更高。说明 AERCA 排序的"头部准确度"在该数据集上略有不足，可能与 MSDS 的分布式系统特性（调用链拓扑更明确，CIRCA 用了领域知识）有关。

6. **异常类型覆盖**：论文注脚明确说并非所有异常都能视为外生干预。对于非外生干预型异常（如传感器本身漂移、测量噪声结构性变化），AERCA 可能失效。这是方法的适用边界。

7. **计算成本**：Lorenz 96 用了 200,000 条训练序列、8 层隐藏维 1000 的网络、最多 5000 epoch。高维真实系统（如核电站上百传感器）的训练成本可能成为瓶颈。

## 七、迁移思考：与核工业 RCA 及 CausalTrace 的对比

> 以下为基于现阶段理解的初步思考，无充分工程调研支撑，不做最终定论。

### 7.1 AERCA 与 CausalTrace 的方法论差异

| 维度 | AERCA (本文) | CausalTrace (AAAI-26) |
|------|-------------|----------------------|
| 因果框架 | Granger 因果（时序滞后） | 结构因果模型 + LiNGAM/DiffAN（非时序） |
| 根因定义 | 外生变量被干预的变量+时刻 | 因果图中路径强度高的上游变量 |
| 核心机制 | 自编码器显式建模外生变量分布 | 总因果效应矩阵 T=(I-B)⁻¹ + 公差筛选 |
| 知识注入 | 无（纯数据驱动） | 知识图谱 + 过程本体（神经符号） |
| 验证手段 | 无显式验证（间接靠因果发现指标） | Algorithm 3 反事实验证 |
| 根因粒度 | 变量 + 时间步（更精细） | 变量级别 |

**互补性**：AERCA 胜在**粒度精细**（定位到时刻）和**数据驱动**（无需先验因果图）；CausalTrace 胜在**知识增强**和**可解释性**（神经符号 + 反事实验证）。

### 7.2 AERCA 对核工业 RCA 的可迁移性

**有利因素**：
- 核工业传感器时序天然是多变量时序，AERCA 的建模对象直接匹配；
- 只需正常数据训练，符合核电"正常运行数据丰富、事故数据稀缺"的现实；
- 能定位根因时刻，有助于事故复盘的时间线重建。

**风险因素**：
- **瞬时效应**：核反应堆控制回路中变量耦合快，Granger 因果的"无瞬时效应"假设可能不成立；
- **外生变量独立性**：同一子系统的传感器共享工艺过程，外生变量未必独立；
- **异常类型**：设备降级、燃料燃耗等是缓慢漂移型异常，未必符合"外生干预"模型；
- **可解释性要求**：核安全监管要求可审计、可解释，纯神经的 AERCA 缺乏知识约束和验证机制，单独使用难以满足合规要求。

### 7.3 融合思路（初步构想）

AERCA 的"外生变量偏离"判据可作为 CausalTrace 神经符号流水线的**补充信号**：

1. 用 AERCA 在正常数据上学出因果图和外生变量分布，作为**因果发现的备选方法**（替代或补充 LiNGAM/DiffAN）；
2. AERCA 的 z-score 根因得分与 CausalTrace 的路径强度得分做**集成排序**；
3. CausalTrace 的知识图谱和反事实验证为 AERCA 的预测提供**可解释性背书和验证**，弥补纯数据驱动的合规短板；
4. 对 AERCA 的外生变量分布假设做核工业特化：如用非高斯分布（Gamma、重尾）建模设备异常，用领域知识（FMEA/故障树）约束独立性假设的放松范围。

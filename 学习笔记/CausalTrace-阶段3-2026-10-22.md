## 一、概述

CausalTrace 的因果分析能力由三个核心算法驱动，形成一条**"发现 → 量化 → 验证"**的完整流水线。本文档详细讲解这三个算法的原理、数学推导和计算例子。

- **Algorithm 1（Bootstrap 边缘稳定性）**：对因果发现算法学出的图做"可靠性体检"，过滤掉不稳定的边
- **Algorithm 2（总因果效应计算）**：把因果图从"有没有关系"升级到"关系有多大"，算出任意两变量间的总影响（直接 + 间接）
- **Algorithm 3（反事实验证）**：用数据反过来检验学出的因果效应对不对，给每条边一个"可信度评分"

学习目标：理解每个算法"为什么要做、怎么做、数学怎么推、举个例子怎么算"。

## 二、核心概念速览

| 概念 | 定义 |
|------|------|
| Bootstrap 重采样 | 有放回地从原数据中抽样，生成多个和原数据同大小的子集，用于估计统计量的稳定性 |
| 因果效应矩阵 B | n×n 矩阵，B_ij 表示变量 j 对变量 i 的**直接**因果效应 |
| 总因果效应矩阵 T | T = (I−B)⁻¹，T_ij 表示变量 j 对变量 i 的**总**效应（直接 + 所有间接路径） |
| SEM（结构方程模型） | X = B·X + ε，描述每个变量由其他变量的因果影响和噪声共同决定 |
| Neumann 级数展开 | (I−B)⁻¹ = I + B + B² + B³ + ...，分别对应自身、直接、间接效应 |
| 谱半径 | 矩阵所有特征值绝对值的最大值；DAG 中 B 是严格三角矩阵，谱半径为 0，级数必然收敛 |
| 分位数 Q₁/Q₃ | 第一四分位数（25% 分位）和第三四分位数（75% 分位），用于构造"低 A"和"高 A"两组样本 |
| 反事实验证 | 用数据中观测到的变化 ΔB_obs 检验模型预测的变化 ΔB_pred，误差越小越可信 |
| 准实验 | 用观测数据中的自然分组近似干预实验，而非真正随机干预 |

## 三、知识分类详解

### 3.1 Algorithm 1：Bootstrap 边缘稳定性分析

#### 3.1.1 是什么

Bootstrap 边缘稳定性分析是一种**因果图质量控制方法**。它通过反复重采样数据，统计每条有向边在多次抽样中出现的强度波动情况，计算稳定性分数，过滤掉不可靠的边。

#### 3.1.2 为什么

因果发现算法（LiNGAM、DiffAN）从数据学因果图，但有个问题：**换一批数据，学出的图可能不一样**。某条边这次出现、下次不出现，说明它不可靠。Algorithm 1 用 Bootstrap 反复抽样，检验每条边"出现得稳不稳定"。

**408 类比**：你在一份程序日志里发现"函数 A 经常调用函数 B"。但换一批日志重看，这个调用关系还在不在？Bootstrap 就是反复"抽不同的日志子集"来检验这条关系稳不稳。

#### 3.1.3 怎么做 / 工作原理

**输入**：数据集 D、bootstrap 样本数 N、因果发现方法 M
**输出**：每条有向边 A→B 的稳定性分数 s

**步骤 1：初始化**
为每条可能的边 A→B 准备空列表 W_A→B，收集每次抽样的因果强度。

**步骤 2：Bootstrap 重采样循环（i = 1 到 N）**

```
对第 i 次：
  ① 从 D 中有放回地重采样，得到 D^(i)
  ② 在 D^(i) 上跑因果发现方法 M，得到因果图 G^(i)
  ③ 对 G^(i) 中每条有向边 A→B：
       记录因果强度 w_i，追加到 W_A→B
```

> **有放回抽样**：就像从一个装了 100 个球的袋子里，每次摸一个看完放回去，摸 100 次。结果有的球被摸好几次，有的一次没摸到。

**步骤 3：计算每条边的稳定性分数**

对每条有样本的边 A→B：

```
平均强度：w̄ = (1/N) × Σ w_i      （i 从 1 到 N）

标准差：  σ = √[ (1/N) × Σ (w_i - w̄)² ]

稳定性分数：s = 1 / (1 + σ)
```

**关键直觉**：σ 越小（每次抽样强度差不多）→ s 越接近 1 → 边越稳定；σ 越大 → s 越接近 0 → 边越不稳定。

**步骤 4：边的稳定性分级**

| 稳定性分数 s | 含义 | 处理 |
|-------------|------|------|
| s ≥ 0.9 | 非常强且稳定 | 保留，高置信度 |
| 0.8 ≤ s < 0.9 | 可靠 | 保留 |
| 0.6 ≤ s < 0.8 | 中等稳定，谨慎使用 | 保留但标记 |
| s < 0.6 | 不稳定 | **排除** |

**步骤 5：最终因果图只保留 s ≥ 0.6 的边**

#### 3.1.4 公式与推导

核心公式只有一个：

```
s = 1 / (1 + σ)
```

其中 σ 是 bootstrap 样本中该边因果强度的标准差。这个函数的设计意图：
- 当 σ = 0（每次抽样强度完全相同），s = 1，最稳定
- 当 σ 很大，s → 0，最不稳定
- s 的取值范围是 (0, 1]，单调递减

选择 s ≥ 0.6 作为阈值，对应 σ ≤ 2/3 ≈ 0.667，意味着强度的相对波动不能太大。

> **原文口径不一致（读的时候注意）**：正文 Motivation 说稳定性分数是 "computed from their occurrence frequency"（按**出现频率**算），但 Algorithm 1 的伪代码实际用的是**因果强度的标准差 σ**（每次抽样只记录该次学出来的边的强度）。两者不是一回事：前者接近"出现次数 / N"，后者是强度波动。本笔记按**算法伪代码**理解。此外，某次没学出的边不进 W，所以"强度标准差"其实隐含地惩罚了"时有时无"的边。

#### 3.1.5 举例说明

**例 1：稳定的边 A→B**

5 次 bootstrap 抽样，边 A→B 的强度记录：

| 第 i 次 | 强度 w_i |
|--------|---------|
| 1 | 0.80 |
| 2 | 0.82 |
| 3 | 0.78 |
| 4 | 0.81 |
| 5 | 0.79 |

计算：

```
平均强度：
w̄ = (0.80 + 0.82 + 0.78 + 0.81 + 0.79) / 5 = 4.00 / 5 = 0.80

偏差平方：
(0.80−0.80)² = 0
(0.82−0.80)² = 0.0004
(0.78−0.80)² = 0.0004
(0.81−0.80)² = 0.0001
(0.79−0.80)² = 0.0001

方差 = (0 + 0.0004 + 0.0004 + 0.0001 + 0.0001) / 5 = 0.001 / 5 = 0.0002
标准差 σ = √0.0002 ≈ 0.0141

稳定性分数 s = 1 / (1 + 0.0141) ≈ 0.986
```

s ≈ 0.986 ≥ 0.9，说明 A→B **非常稳定**，保留。

**例 2：中等稳定的边 C→B**

5 次强度：0.5、0.1、0.9、0.2、0.7

```
平均 w̄ = (0.5 + 0.1 + 0.9 + 0.2 + 0.7) / 5 = 2.4 / 5 = 0.48

偏差平方：
(0.5−0.48)² = 0.0004
(0.1−0.48)² = 0.1444
(0.9−0.48)² = 0.1764
(0.2−0.48)² = 0.0784
(0.7−0.48)² = 0.0484

方差 = (0.0004 + 0.1444 + 0.1764 + 0.0784 + 0.0484) / 5 = 0.448 / 5 = 0.0896
标准差 σ = √0.0896 ≈ 0.299
稳定性分数 s = 1 / (1 + 0.299) ≈ 0.770
```

s ≈ 0.77，在 0.6~0.8 之间，**中等稳定**，保留但要谨慎。

#### 3.1.6 小结

Algorithm 1 的本质是：**用"反复抽样看一致性"来过滤噪声边**。它不创造新因果关系，只负责"筛选"，是整个流水线的**质量控制环节**。

### 3.2 Algorithm 2：总因果效应计算

#### 3.2.1 是什么

总因果效应计算是把因果图从"定性"升级为"定量"的关键步骤。它通过矩阵求逆，算出任意两个变量之间的**总因果效应**——不仅包括直接影响，还包括所有间接路径的影响之和。

#### 3.2.2 为什么

因果图只告诉你"A 导致 B"（定性），但实际决策需要知道"A 变 1 个单位，B 会变多少"（定量）。而且因果影响可能是**间接的**——A 影响 B，B 影响 C，那 A 对 C 也有影响，只是隔了一层。Algorithm 2 就是算出任意两个变量之间的总效应。

**408 类比**：你在分析一段调用链 `main → 加密函数 → 压缩函数`。你想知道"输入多 1 KB，最终输出多多少"——这就是总效应，要把每一层的放大倍数沿路径乘起来，再把多条路径的结果相加。

#### 3.2.3 数学基础：结构方程模型（SEM）

假设我们有 n 个观测变量，组成向量 X = [X₁, X₂, ..., Xₙ]ᵀ。

**结构方程模型（SEM）**：每个变量等于其他变量对它的因果影响之和，加上自身的噪声：

```
X = B·X + ε
```

其中：
- **B** 是 n×n 的**因果效应矩阵**，B_ij 表示变量 j 对变量 i 的**直接**因果效应
- **ε** 是噪声向量（外生冲击）

**例子**（3 个变量 A→B→C）：

```
A = ε_A
B = b_BA · A + ε_B
C = b_CB · B + ε_C
```

写成矩阵形式：

```
[A]   [0    0    0] [A]   [ε_A]
[B] = [b_BA 0    0] [B] + [ε_B]
[C]   [0    b_CB 0] [C]   [ε_C]
```

即 X = B·X + ε。

#### 3.2.4 公式与推导

从 SEM 出发：

```
X = B·X + ε
```

把 B·X 移到左边：

```
X − B·X = ε
(I − B)·X = ε
```

其中 I 是 n×n 单位矩阵。两边左乘 (I−B)⁻¹：

```
X = (I − B)⁻¹ · ε
```

这一步的含义：**噪声 ε 通过 (I−B)⁻¹ 这个"放大器"变成了观测变量 X**。定义**总因果效应矩阵**：

```
T = (I − B)⁻¹
```

T 的第 (i, j) 个元素 T_ij，表示**变量 j 的单位变化对变量 i 的总影响**（直接 + 所有间接路径）。

#### 3.2.5 Neumann 级数展开：拆解总效应

矩阵论结论：如果 B 的谱半径 < 1（对于无环图 DAG 天然成立），那么 (I−B)⁻¹ 可以展开成无穷级数：

```
T = (I − B)⁻¹ = I + B + B² + B³ + ...
```

每一项的因果含义：

| 项 | 含义 | 因果解释 |
|----|------|---------|
| **I** | 单位矩阵 | 自身效应（变量对自己的影响） |
| **B** | 一次方 | **直接效应**（1 跳，直接因果边） |
| **B²** | 二次方 | **2 跳间接效应**（经过 1 个中间变量） |
| **B³** | 三次方 | **3 跳间接效应**（经过 2 个中间变量） |
| ... | ... | 更长路径的间接效应 |

**为什么 B^k 对应 k 跳路径？**

矩阵乘法的本质是"路径求和"。B² 的第 (i, j) 个元素 = Σ_k B_ik · B_kj，正好是"i ← k ← j"这条 2 跳路径上的效应乘积，对所有中间节点 k 求和。同理 B³ 就是 3 跳路径的效应乘积之和。

> **收敛条件**：级数展开要求 B 的谱半径 < 1。对于**无环图（DAG）**，B 是严格上/下三角矩阵，特征值全为 0，所以必然收敛。这也是因果图必须是 DAG 的数学原因之一。

#### 3.2.6 举例说明：3 变量链式 A→B→C

设直接效应矩阵（B_ij 表示 j 对 i 的效应）：

```
    A  B  C
B = 0  0  0   (A 行：没有变量影响 A)
    2  0  0   (B 行：A 对 B 的直接效应是 2)
    0  3  0   (C 行：B 对 C 的直接效应是 3)
```

**计算 I−B**：

```
I − B = 1  0  0
       −2  1  0
        0 −3  1
```

**求逆 (I−B)⁻¹**：

```
T = (I−B)⁻¹ = 1  0  0
             2  1  0
             6  3  1
```

**解读 T 的每个元素**：

| T_ij | 变量 j 对 i 的总效应 | 含义 |
|------|-------------------|------|
| T_AA = 1 | A 对自身 | 自身效应 |
| T_BA = 2 | A 对 B | 直接效应（A→B，系数 2） |
| T_CB = 3 | B 对 C | 直接效应（B→C，系数 3） |
| **T_CA = 6** | **A 对 C** | **间接效应**：A→B→C，2 × 3 = 6 |
| T_BB = 1, T_CC = 1 | 自身 | 自身效应 |

用 Neumann 展开验证：

```
T = I + B + B² + B³ + ...

I = 1 0 0     B = 0 0 0     B² = 0 0 0
    0 1 0         2 0 0          0 0 0
    0 0 1         0 3 0          6 0 0

B³ 及更高次 = 0（本图中 B 是严格下三角——A→B 记在 B 行 A 列，3 次后全零）

T = I + B + B² = 1 0 0
                2 1 0
                6 3 1
```

结果完全一致。**T_CA = 6 就是 A 对 C 的总效应**，等于直接路径 A→B→C 上各边效应的乘积 2×3=6。

**直观理解**：A 增加 1 个单位 → B 增加 2 个单位 → C 增加 2×3 = 6 个单位。所以 A 对 C 的总效应是 6。

#### 3.2.7 小结

Algorithm 2 的本质是：**用矩阵代数把"直接效应"聚合为"总效应"**。T = (I−B)⁻¹ 是核心公式，Neumann 展开 I + B + B² + ... 让我们看清总效应是怎么由一条条路径叠加出来的。

### 3.3 Algorithm 3：反事实验证

#### 3.3.1 是什么

反事实验证是用**留出数据（held-out data）**检验学出的因果效应是否可信的方法。核心逻辑是：如果 A 真的以强度 τ 影响 B，那么当 A 变化时，B 的实际变化应该和模型预测的差不多；差很多就说明这条因果边可能是错的。

#### 3.3.2 为什么

前面两个算法给出了因果图和因果效应，但这些是**模型算出来的**，对不对需要在**没参与学图的数据**上检验。Algorithm 3 就是做这个检验。

**408 类比**：你用训练集拟合出一个模型，说"输入从 25 分位升到 75 分位，输出应该涨 6"。那你就去**测试集**里找输入接近这两个值的样本，看输出实际涨了多少。如果也是 ~6，模型可信；如果实际是 0 或 100，模型有问题。——关键在"必须用测试集"，不能拿训练集自己给自己打分。

#### 3.3.3 怎么做 / 工作原理

**输入**：**留出数据集 D_held**（未参与图结构与效应估计）、总效应矩阵 τ（Algorithm 2 算出的 T）、容忍度 ϵ、效应阈值 δ
**输出**：对每条有效因果边 A→B，输出验证表 (A, B, τ_A→B, ΔB_pred, ΔB_obs, Error)

**步骤 1：筛选要验证的边**
对每对变量 (A, B)，A ≠ B，且 |τ_A→B| > δ（效应太小的边不值得验证）。

**步骤 2：选定基线值和干预值**

```
基线值 a₁ = Q₁(A)    （A 的第一四分位数，即 25% 分位数）
干预值 a₂ = Q₃(A)    （A 的第三四分位数，即 75% 分位数）
```

> 为什么用四分位数？因为要在数据里找到"A 比较小"和"A 比较大"的两组样本，分别代表"低 A"和"高 A"的情况。用 Q₁ 和 Q₃ 保证每组有足够样本，同时两组间 A 的差异足够大。

**步骤 3：计算预测的 B 变化量**

根据总因果效应 τ_A→B，预测当 A 从 a₁ 变到 a₂ 时，B 应该变多少：

```
ΔB_pred = (a₂ − a₁) × τ_A→B
```

**步骤 4：从数据中提取两组样本**

```
基线组：D 中 A ≈ a₁ 的样本（|A − a₁| ≤ ϵ）
干预组：D 中 A ≈ a₂ 的样本（|A − a₂| ≤ ϵ）
```

**步骤 5：计算观测到的 B 变化量**

```
ΔB_obs = E[B | A ≈ a₂] − E[B | A ≈ a₁]
       = (干预组中 B 的平均值) − (基线组中 B 的平均值)
```

**步骤 6：计算误差**

```
Error = |ΔB_pred − ΔB_obs|
```

**步骤 7：解释结果**

| 误差大小 | 含义 |
|---------|------|
| 小 | A→B 的因果效应得到数据的良好支持，可信 |
| 大 | 可能存在模型误设或未观测的混杂，这条边存疑 |

#### 3.3.4 公式与推导

核心公式：

```
ΔB_pred = (Q₃(A) − Q₁(A)) × τ_A→B

ΔB_obs = mean(B | A ≈ Q₃(A)) − mean(B | A ≈ Q₁(A))

Error = |ΔB_pred − ΔB_obs|
```

这里用的是**观测数据中的自然分组**（A 恰好处于 Q₁ 附近 vs Q₃ 附近），而不是真正的随机干预实验，这叫**准实验（quasi-experiment）**。

#### 3.3.5 举例说明

延续 A→B→C 的例子，总效应 τ_CA = 6（A 对 C 的总效应）。验证这条边。

假设数据集中变量 A 的取值分布：
- Q₁(A) = 10（25% 的样本 A ≤ 10）
- Q₃(A) = 20（75% 的样本 A ≤ 20）

**预测变化**：

```
ΔC_pred = (Q₃ − Q₁) × τ_CA = (20 − 10) × 6 = 60
```

**从数据提取两组**（ϵ = 1）：
- 基线组：A 在 [9, 11] 范围内的样本，C 的平均值 = 50
- 干预组：A 在 [19, 21] 范围内的样本，C 的平均值 = 108

**观测变化**：

```
ΔC_obs = 108 − 50 = 58
```

**误差**：

```
Error = |ΔC_pred − ΔC_obs| = |60 − 58| = 2
```

误差很小（2，相对于预测值 60 来说只有 ~3%），说明 A→C 的因果效应 **τ_CA = 6 得到了数据的良好支持**，这条边可信。

**反例**：如果 ΔC_obs = 10（观测变化远小于预测），Error = |60 − 10| = 50，很大。说明模型预测 A 对 C 有强影响，但数据里 A 变化时 C 几乎没变，这条因果边可能是假的（可能有未观测的混杂变量）。

#### 3.3.6 注意事项

Algorithm 3 用的是**准实验**而非真正的干预实验。局限：
- 如果 A 的高低分组本身就和某个混杂变量相关，ΔB_obs 可能不是 A 导致的
- 但在无法做真实干预（不能故意让工厂出故障）的情况下，这是可行的验证方法

#### 3.3.7 小结

Algorithm 3 的本质是：**用数据中的自然分组近似干预实验，检验因果效应的可信度**。误差越小，说明模型预测和实际观测越吻合，因果边越可信。

### 3.4 三个算法的串联关系

```
原始传感器数据
      │
      ▼
[因果发现算法：LiNGAM / DiffAN]
      │  产出：初步因果图（可能有噪声边）
      ▼
┌─────────────────────────────┐
│  Algorithm 1：Bootstrap 稳定性  │  ← 筛选：去掉不稳定的边
│  输出：s ≥ 0.6 的因果图        │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│  Algorithm 2：总因果效应计算    │  ← 量化：每条边的效应有多大
│  输出：总效应矩阵 T = (I−B)⁻¹  │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│  Algorithm 3：反事实验证        │  ← 验证：效应和数据是否吻合
│  输出：每条边的误差 Error       │
└─────────────────────────────┘
```

**记忆口诀**：
- Algorithm 1 = **筛选**（哪些边靠谱）
- Algorithm 2 = **量化**（每条边影响多大）
- Algorithm 3 = **验证**（数据支不支持这个效应）

## 五、关键总结

1. **Algorithm 1 的核心公式**：s = 1/(1+σ)，σ 是 bootstrap 强度的标准差。σ 越小越稳定，保留 s ≥ 0.6 的边。这个公式的设计意图是把标准差映射到 (0,1] 区间，方便设阈值。

2. **Algorithm 2 的核心公式**：T = (I−B)⁻¹，从 SEM（X = B·X + ε）推导而来。Neumann 展开 T = I + B + B² + ... 中，I 是自身效应，B 是直接效应，B^k 是 k 跳间接效应。DAG 保证 B 是严格三角矩阵，谱半径为 0，级数必然收敛。

3. **Algorithm 3 的核心逻辑**：用 Q₁/Q₃ 分组做准实验，比较模型预测 ΔB_pred = (a₂−a₁)×τ 和数据观测 ΔB_obs，误差越小因果效应越可信。这是"用数据检验模型"的自验证机制。

4. **数学依赖关系**：Algorithm 1 需要统计学（Bootstrap、标准差）；Algorithm 2 需要线性代数（矩阵求逆、特征值、Neumann 级数）；Algorithm 3 需要因果推断（干预、反事实、准实验）。三者难度递增。

5. **三者的角色分工**：Algorithm 1 是质量控制（筛选边），Algorithm 2 是核心计算（算效应），Algorithm 3 是自验证（验效应）。缺了任何一个，因果分析都不完整——只有筛选没有量化就不知道影响多大，只有量化没有验证就不知道对不对。

6. **DAG 的数学意义**：因果图必须是 DAG 不只是直觉要求，更是数学要求——只有 DAG 的 B 矩阵是严格三角的，才能保证 Neumann 级数收敛，总因果效应 T = (I−B)⁻¹ 才有意义。

7. **间接效应的计算**：总效应 T 把所有间接路径的效应自动加总。比如 A→B→C 中 A 对 C 的总效应就是 A→B 和 B→C 两条边效应的乘积，这由 B² 自动算出，不需要手动遍历路径。

8. **反事实验证的局限**：Algorithm 3 用的是准实验（观测数据自然分组），不是真正的随机干预，所以不能完全排除混杂。但在工业场景（不能故意让机器出故障）下，这是最可行的验证方法。

9. **阈值的经验性**：Algorithm 1 的 s ≥ 0.6、Algorithm 3 的 |τ| > δ 等阈值都是经验设定，实际应用中需要根据数据特点和领域需求调整。

10. **三个算法的记忆口诀**：Algorithm 1 = 筛选，Algorithm 2 = 量化，Algorithm 3 = 验证。对应"发现 → 量化 → 验证"的因果分析流水线。

## 六、延伸阅读

### 因果发现算法进阶
- **LiNGAM 原理**：基于独立成分分析（ICA）的因果发现，利用非高斯性识别因果方向
- **DiffAN 原理**：基于可微学习和注意力机制的因果发现，适合高维数据
- **PC 算法**：基于条件独立性检验的经典因果发现算法（论文未使用，但值得了解）

### 矩阵论与因果推断
- **Neumann 级数的严格证明**：(I−B)⁻¹ = Σ B^k 的收敛条件和证明
- **结构方程模型（SEM）**：线性 SEM、非线性 SEM、含潜变量的 SEM
- **do 演算**：Judea Pearl 的因果推理演算，如何从观测数据估计干预效应

### 反事实与准实验
- **随机对照试验（RCT）**：因果推断的黄金标准
- **准实验方法**：断点回归、双重差分、倾向得分匹配
- **反事实推理的形式化**：结构因果模型（SCM）中的反事实定义

### 与核工业 RCA 方向的结合思考
- 因果发现能否用于"反应堆功率—冷却剂流量—堆芯温度"之间的因果建模？
- 反事实验证能否用来检验"某条事故因果链是否真的成立"（用留出的运行数据比对）？
- 总因果效应能否用来量化"某个阀门故障沿系统传播的影响范围与量级"？
- 稳定性分数 s 能否作为"核安全关键因果链可信度"的量化门槛？

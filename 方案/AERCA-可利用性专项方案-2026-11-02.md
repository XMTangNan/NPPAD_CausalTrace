## 0. 执行摘要与决策请求

### 0.1 一句话结论

AERCA **不适合整体引入**，但它的三个构件可以**直接补强** v3 方案中明确标注为"P2-3 后补"的 `temporal` 证据维度与动态因果 pilot，且改造成本可控。

### 0.2 核心判断

| 维度 | 判断 |
|------|------|
| **是否替代 LiNGAM/GAM-ANM** | 否。AERCA 是时序方法，v3 的静态因果发现仍由 LiNGAM/GAM-ANM 承担，二者互补不互替 |
| **最高价值落点** | P0-6c（`temporal` 滞后筛查）+ P2-3（WLR↔P 动态因果 pilot） |
| **次要价值落点** | L2 根因起始时刻定位（外生变量 z-score） |
| **是否影响 P0/P1** | 不影响。AERCA 属 P2 范畴，P0/P1 按原方案执行 |
| **最大风险** | Granger 假设（无瞬时效应、无隐藏混杂）在核电闭环控制回路中可能不成立；数据量不足（每类仅 100 条轨迹） |
| **建议投入** | 1.5–2 人日做 PoC，与 P2-3 的 VAR-LiNGAM/PCMCI 并列对比 |

### 0.3 需要拍板的三件事

1. **是否在 P2-3 中加入 AERCA 作为第三种动态因果方法**（与 VAR-LiNGAM、PCMCI 并列）？
2. **是否将 AERCA 的外生变量 z-score 作为 L2"异常起始时间"的候选证据**接入证据向量？
3. **PoC 的优先级**：若 G1-RQ2 显示静态结构不足，是否优先启动 AERCA PoC？

## 1. AERCA 核心构件速览

| 构件 | 论文位置 | 一句话描述 | 本项目相关性 |
|------|---------|-----------|------------|
| **编码器（溯因）** | §3.3 | $u_t = x_t - \sum_{k=1}^K \omega_{\theta_k}(x_{t-k}) x_{t-k}$，从观测反推外生变量 | 高：显式建模残差（外生变量），与 LiNGAM 的 $e = Bx$ 残差思路一致 |
| **独立性约束** | §3.4 | $D_{KL}(P(U_t) \| \mathcal{N}(0,I))$，强制外生变量相互独立 | 中：可作为因果图质量门控，但高斯假设在核电数据上可能过强 |
| **解码器（演绎）+ Prop 1** | §3.5 | 从有限窗口外生变量 + 更早观测值重构当前值 | 中：窗口化处理长轨迹的工程结论可直接用 |
| **根因定位** | §4 | 外生变量 z-score + SPOT 阈值，定位变量+时刻 | 高：可补 L2 起始时刻，但 SPOT 不采用 |
| **因果图聚合** | §3.7 | $S_{i,j} = \max_k \text{median}_t \|(\omega_{\theta_k})_{i,j}\|$ | 高：直接产出带滞后的因果强度矩阵 |
| **训练目标（式 10）** | §3.6 | 重建损失 + KL + L1/L2 + 平滑四项 | 低：超参多，与 v3 评价口径不兼容 |

## 3. 三个可直接利用的构件

### 3.1 构件一：带滞后的 Granger 因果强度矩阵（→ `temporal` 证据）

**AERCA 做法**：编码器有 $K$ 个神经网络，每个输出 $d \times d$ 系数矩阵，聚合为 $S_{i,j} = \max_k \text{median}_t |(\omega_{\theta_k})_{i,j}|$。

**对接 v3 的方式**：
- 在 P0-6c 的滞后筛查中，AERCA 产出的 $(i, j, k)$ 三元组（变量 $i \to j$，滞后 $k$ 步）直接写入 `temporal_lag.csv`；
- 与滞后互相关、VAR 的结果做三角验证：若三者对同一条边的方向和滞后一致，则 `temporal` 证据可信度高；
- 在 P2-3 的 WLR↔P pilot 中，AERCA 与 VAR-LiNGAM、PCMCI 并列，比较三者学出的 WLR↔P 方向和滞后。

**为什么直接可用**：
- 不改变 v3 的证据框架，只是往 `temporal` 维度加一个来源；
- 不触碰分类/定位的评价协议（risk-coverage 不变）；
- 产物是边级三元组，与 `edge_audit.csv` 的证据向量格式兼容。

**已知限制**：
- AERCA 的 Granger 假设"无瞬时效应"。核电控制回路中 WLR 与 P 可能存在近瞬时反馈，此时 AERCA 可能判错方向——这正是 P2-3 pilot 要检验的。

### 3.2 构件二：外生变量 z-score（→ L2 异常起始时间）

**AERCA 做法**：对每个时刻 $t$ 计算外生变量 $u_t$，根因得分 = $(u_t^{(j)} - \mu^{(j)})/\sigma^{(j)}$，其中 $\mu, \sigma$ 来自正常数据。

**对接 v3 的方式**：
- 对每条测试轨迹，在主窗 $t \in [300, 1500]$ 内逐时刻计算 AERCA 外生变量 z-score；
- 首次越限的 $(变量, 时刻)$ 作为 L2"异常起始时间"的候选；
- 与现有 marker 阶跃时刻（$t \approx 110$s 注入）做配对：若 AERCA 检测到的起始变量 ≠ marker 且时刻晚于注入时刻，说明存在"非 marker 变量先响应"的诊断信号；
- 接入 L3 传播时序：AERCA 的 z-score 时序可以刻画"根因变量先偏离 → 下游变量后偏离"的传播序列。

**为什么直接可用**：
- 不依赖 AERCA 的因果图是否正确，只依赖外生变量是否偏离正常——即使因果图学错，残差偏离仍有信息量；
- 与 v3 的弃权机制不冲突，只是新增一个 L2 证据源。

**已知限制**：
- 外生变量偏离不一定是根因（可能是测量噪声、未建模的物理过程）；
- v3 的正常基线只有 sev-1 一条轨迹（$t \in [520, 2030]$），$\mu/\sigma$ 估计不稳——需用双通道尺度修复后的基线。

### 3.3 构件三：窗口化因果结构（Prop 1 的工程结论）

**AERCA 做法**：Prop 1 证明 $x_t$ 可由前一窗口外生变量 + 再前一窗口观测值表示，无需递归展开全部历史。

**对接 v3 的方式**：
- P0-6a 时间依赖审计中，用固定窗口 $K$ 替代"vstack 全部时间点"，是处理长轨迹自相关的一种工程方案；
- v22/dependence.py 的时间块 Bootstrap 可借鉴此窗口设计。

**为什么直接可用**：
- 这是一个**理论结论**，不是方法本身，可移植到任何时序因果方法。

## 4. 两个需改造后利用的构件

### 4.1 构件四：编解码架构（轻量版）

**AERCA 原设**：8 层隐藏 1000、5000 epoch、20 万序列训练。

**v3 实际约束**：
- 每类仅 100 条轨迹 × ~150 时间点 = 15000 个时间点（且非 iid）；
- v3 计算预算 P1 总共 20–40 h，不能让一个 pilot 吃掉全部预算。

**改造方案**：

| 超参 | AERCA 原设 | 轻量版建议 | 理由 |
|------|-----------|-----------|------|
| 隐藏层数 | 8 | 2 | 数据量不足以支撑深网络 |
| 隐藏维 | 1000 | 64–128 | NPPAD 仅 ~17 个 V_thr 变量，1000 维过参 |
| 窗口 K | 论文未详 | 3–5（对应 30–50 s） | 10 s/步，主窗 1200 s，K=5 已覆盖 50 s 滞后 |
| Epoch | 5000 | 200–500 + 早停 | 防过拟合 |
| 外生变量分布 | $\mathcal{N}(0, I)$ | 稳健化：先用高斯，失败则核密度估计 | 核电外生项未必高斯 |

**接入位置**：v3 附录 C 已规划 `Code/rca/v3/dynamic.py`（VAR-LiNGAM/PCMCI），AERCA 轻量版作为该模块的第三个类。

### 4.2 构件五：外生变量独立性约束（作为质量门控）

**AERCA 做法**：训练时用 KL 散度强制 $U_t \sim \mathcal{N}(0, I)$。

**v3 的问题**：
- 不直接用 AERCA 的训练目标（超参多、与 v3 评价口径不兼容）；
- 但"外生变量是否独立"是因果图质量的一个**后验指标**。

**改造方案**：
- 对 LiNGAM 学出的静态图，计算残差 $e = x - Bx$ 的协方差矩阵与单位阵的 KL 散度；
- 作为 `struct` 证据的质量门控：若残差间存在强相关，说明图有未解释结构，该边的 `struct` 可信度降级；
- 接入 v22/evidence.py 的主张-证据矩阵校验。

## 5. 明确不采用的构件与理由

| AERCA 构件 | 不采用理由 |
|-----------|-----------|
| **SPOT 动态阈值** | v3 已有弃权机制（gCF 门控 + τ/δ 标定），SPOT 引入额外超参且与 risk-coverage 评价口径不兼容 |
| **整体训练目标（式 10）** | 含重建损失 + KL + L1/L2 稀疏 + 平滑四项，超参 β/λ/γ 多，与 v3"先修尺度与评价"的 P0 优先级冲突 |
| **AC@K 评估指标** | v3 用 risk-coverage + LORO + 配对差，AERCA 的 AC@K 假设 iid 测试样本，与设计点统计协议矛盾 |
| **因果图作为 `struct` 证据** | AERCA 是时序方法，其因果图标注为 `temporal` 而非 `struct`，避免与 LiNGAM 的 `struct` 证据混淆 |
| **整体替换静态因果发现** | v3 明确"不全面替换 LiNGAM/GAM-ANM"（§1.5 负面清单），AERCA 只做 `temporal` 补充 |

## 6. 最小可行集成路径（PoC）

### 6.1 启动条件

- G1-RQ2 显示静态结构不足（v3 §10.2）；**或**
- P0-6c 滞后筛查发现关键边的方向/滞后在多种方法间不一致，需要 AERCA 做第三方仲裁。

### 6.2 PoC 步骤（约 1.5–2 人日）

| 步骤 | 内容 | 产物 | 验收 |
|------|------|------|------|
| ① 数据准备 | 用 v22 的双通道尺度处理 LOCA 的 WLR、P、VOL 三个变量，截取主窗 | 规范化时序 | 尺度修复通过 |
| ② 训练轻量 AERCA | 2 层 MLP，K=4，epoch=300，外生变量高斯约束 | 模型权重 + 系数矩阵 | 训练收敛（重建损失下降） |
| ③ 提取 `temporal` 证据 | 输出 WLR↔P、WLR↔VOL、P↔VOL 的方向 + 滞后 | `temporal_aerca.csv` | 与 P0-6c 的滞后互相关结果可比 |
| ④ 起始时刻检测 | 对 10 条测试轨迹计算外生变量 z-score，找出首次越限 | `onset_aerca.csv` | 起始时刻与注入时刻（110s）的偏差可解释 |
| ⑤ 对比报告 | AERCA vs VAR-LiNGAM vs PCMCI（若已实现）vs 滞后互相关，在 WLR↔P 上的方向/滞后一致性 | `aerca_poc_report.md` | 结论清楚：AERCA 是否提供独立信息 |

### 6.3 PoC 的三结局判定（参照 v3 §3.2.1）

| 结局 | 条件 | 后续动作 |
|------|------|---------|
| **AERCA 有增量** | AERCA 检出的滞后/方向与物理预期一致，且与滞后互相关/VAR 不一致（提供独立信息） | 纳入 P2-3 正式对比 |
| **AERCA 无增量但一致** | AERCA 结果与已有方法高度一致 | 作为 `temporal` 证据的交叉验证源，不单独投入 |
| **AERCA 失效** | AERCA 结果与物理预期明显矛盾（如判 P→WLR 但物理上 WLR 驱动 P） | 记录失效原因（瞬时效应？数据不足？），不纳入 |

## 8. 风险与放弃条件

### 8.1 风险清单

| 风险 | 触发条件 | 影响 | 缓解 |
|------|---------|------|------|
| **Granger 假设不成立** | 核电闭环控制存在瞬时双向反馈 | AERCA 判错方向 | P2-3 pilot 先验证 WLR↔P，失效则放弃 |
| **数据量不足** | 每类仅 100 条轨迹 | 过拟合，因果图不稳定 | 轻量网络 + 早停 + 设计点 Bootstrap |
| **外生变量非高斯** | 设备漂移、重尾扰动 | KL 约束失效，残差分布估计偏 | 用核密度估计替代高斯，或放宽为"近似独立" |
| **与现有方法冗余** | AERCA 结果与 VAR-LiNGAM/PCMCI 高度一致 | 投入无回报 | PoC 阶段即判定，无增量则不投入 |

### 8.2 放弃条件

出现以下任一情况，**立即放弃 AERCA 的进一步投入**：

1. P2-3 pilot 中 AERCA 对 WLR↔P 的方向判定与物理预期矛盾，且无法用"瞬时效应"解释；
2. PoC 中 AERCA 与滞后互相关/VAR 的结果 Jaccard > 0.9（无独立信息）；
3. 轻量网络在 500 epoch 内不收敛（重建损失不下降）；
4. 外生变量 z-score 在正常轨迹（sev-1）上频繁误报（>20% 时间步越限）。

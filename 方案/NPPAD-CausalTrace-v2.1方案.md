# NPPAD-CausalTrace v2.1 方案：神经符号正演-反演因果签名 RCA

> **本节是 v2.1 正式方案，当前唯一执行版本。** 第 1~12 节（v2.0）保留作设计溯源；冲突以本节为准。实现缺陷对照清单见 [Code/error_tracking.md](../Code/error_tracking.md) RCA-012~RCA-031，实现时必须逐条核销。

## 13.0 目标、决策记录与取代关系

### 13.0.1 本版目标

**目标：在 NPPAD 上忠实跑通参考论文 CausalTrace 的方法流水线——神经符号三层知识注入 + 三大算法（Alg1 边稳定性筛选 → Alg2 总因果效应 → Alg3 留出数据反事实验证），检验该方法在核电仿真数据上能否产出：正确的始发故障类型判断、可验证的类内变量传播链、以及信息不足时的合理弃权。**

边界（与导师确认为"解读 A"：单故障诊断=始发故障类型判断 + 事故内变量传播链；不做事故间演化链；本课题不投稿，目标是在 NPPAD 上复现论文方法的结果）：

- 根因粒度 = **始发故障模式假设 f_k**（LOCA/SGATR/FLB），marker（WLR/WTRA/WFLB）是故障指示器而非根因，报告措辞禁用"根因是 WLR"；
- 输出 = 故障类型 + marker→症状可验证传播链 + 反事实重演支持度 + 弃权；
- **不做事故间演化链**（NPPAD 每文件仅注入单一始发事件，README 明确无叠加事故；该问题留待第二阶段的知识驱动或补仿真路径）；
- 不以投稿指标规模为目标：3 类 pilot 即主体，20 条/类的结果按描述性统计 + CI 报告，不做功效宣称。

### 13.0.3 决策记录（5 决策点 + 2 边界确认）

1. **E3 双版本 + D0 门控：采纳。** E3-base 为 P0 预注册主证据；D0 门控实验后再冻结主证据归属（13.8.1，两级判据：强证据=点估计>0 且配对 Bootstrap 95%CI 下界>0；方向性=点估计>0 但 CI 跨 0）。**事前承认 n=18 下 CI 下界>0 极少达到，D0 的默认预期分支是 E3_path 升主证据**；D0 的核心价值是决策留痕与主证据归属的事前冻结，不是小样本统计区分两版本。
2. **9 模板分组签名 c_{k,g}：采纳。** 解除严重度混杂；匹配对 9 模板取 max，不读取测试轨迹严重度标签。
3. **Alg3 反事实环定位：质量门控 + 论文三算法闭环 + 解释证据。** Alg3 的原始一致率/量级相关**不作为独立证据分出现**；对分类的唯一影响是预注册的两档质量门控 gCF∈{1, 0.5}（边级调制 E3 权重 wL、模板级调制 max 聚合）——gCF 是签名质量门控，不是连续证据分。
4. **target 不参与分类。** LSGA/WFWA 等在 R0 审计冻结，仅作 R5 展示锚点。
5. **范围与排期：3 类 pilot 为主体、一周排期；D0 插 D1 末，全量签名放 D2。** 扩展事故类型/样本量列入 13.15 第二阶段（可选，非本版目标，因本版不以投稿为目的）。
6. 边界确认：**复现导向而非论文导向**——成功判据对齐论文自身验证口径（Alg3 留出反事实、物理一致性、神经符号消融），不追求 MAP@3 类指标规模。
7. 计算预算确认：**按用途分配**（13.5.2），不全量对称 Bootstrap。

| # | 判据 | 性质 |

## 13.3 Phase R0：数据冻结（看任何分类结果前完成）

### 13.3.1 轨迹划分

- 类别：LOCA / SGATR / FLB 三类（LOCAC 维持"当前聚合集未检出可区分差异"的排除结论）；
- **severity=1 轨迹全部固定入训练集**（它是过程本体基线的唯一合格来源）；
- 测试集 20 条/类，从 sev 2~100 按严重度配额分层抽取：低(2~33) 7 条、中(34~66) 7 条、高(67~100) 6 条；固定随机种子 42；其余轨迹入训练；
- 落盘 `split_manifest.json`（每轨迹：类别、sev、train/test、严重度组、基线是否使用）；
- **自动断言**：测试文件名 ∩ 共享基线源文件名 = ∅；marker 三列在训练/测试中的可用性分别记录；
- 轨迹级留一标定中若被留轨迹为 sev-1，过程本体基线改用其余两条 sev-1（本版三类；若补 LOCAC 为三条）重算。

### 13.3.2 时间窗

- **基线窗（过程本体用）**：t ∈ [520, 2030]s，152 点/条（sev-1 的 100% 功率恢复段；实测三类 PWNT 均值 100.3~100.8%）；
- **主分析窗（观测窗）**：t ∈ [300, 1500]s（注入 t≈110s 之后），10s/步共 121 点；测试观测 d_x/A(x)、组模式、E2/E3 观测、XGBoost 统计量一律用此窗；
- **学图窗（D1 修正，RCA-030）**：t ∈ [60, 1500]s，145 点/条，**仅用于 LiNGAM/GAM 学图池化**。实测 marker 是 t=110s 瞬时阶跃后在主窗内分段恒定的平台量（FLB/50 WFLB 主窗 std=0），主窗 vstack 学图使 DirectLiNGAM 系统性选择"症状→marker"伪方向（块内残差近零），本体删边后 marker 零出边、frontier 全空；学图窗纳入注入瞬态后 marker 方向恢复（LOCA 12.5 稳定出边/fit）。本修正发生在 D0 之前、由诊断证据驱动（非看分类结果调参）；
- 严禁再出现"取整条 sev-1"（RCA-012）。

### 13.3.3 三张变量表（一次冻结，落盘 `variable_sets.json`；核销 RCA-027）

以 v2.0 第 4.1 节 23 列候选并集为审计起点（22 物理列 + TIME），逐类做常量列审计后：

## 13.5 Phase R1：分组正演签名（Alg1 + Alg2 + 神经环节①）

### 13.5.1 标准化

学图与异常评分**共用过程本体层的跨类共享 μ/σ**（z=(x−μ)/σ），保证 T 与症状方向跨类可比（RCA-015 修复）。marker 列不参与 μ/σ 池化，单独标准化（保留非零信息），预注册公式：

```
z_marker,k(t) = marker_k(t) / median_platform_k
median_platform_k = median over 训练轨迹 of [主窗 marker 中位数]   # 按类 k 各算一个，落盘冻结
```

平台激活轨迹 z_marker≈1，未激活≈0；a1/a2（Q1/Q3）、dr 动态范围、E1 的 ε 都在此尺度上定义。

### 13.5.2 轨迹级 Bootstrap 与计算预算（按用途分配，已确认）

Bootstrap 单位 = **轨迹**（重采样组内训练轨迹编号，学图 vstack 其**学图窗 [60,1500]** 全部点；C^A 用主窗轨迹中位，见下），严禁时间点重采样。每个 (k,g) 模板（k∈3 类，g∈低/中/高）：

| 产物 | 次数 | 用途 | 预估耗时（16 变量量级，本机实测） |
|---|---|---|---|
| LiNGAM 全图（DirectLiNGAM） | **100 次/模板** | 稳定边、四指标、T 矩阵、π^L、**E3-path 拓扑分层**、Alg3 线性重演 | 9×100×1.29s ≈ 20 min |
| GAM marker→症状单变量拟合（每变量 1 个 GAM，无对向搜索） | **50 次/模板** | C^A 边际方向 π^A、E3-base 的 ANM 引擎、Alg3 非线性重演 | 9×50×约15×0.016s ≈ 2 min |
| GAM-ANM 全对向图（正/反两方向+HSIC 独立性） | **10 次/模板** | 仅供 LiNGAM∩GAM 共识边/冲突边标注与展示（GAM 图过密，不供 BFS 拓扑） | 9×10×240×0.49s ≈ 1.5 h |
| 留一标定签名（约 240 套） | 单拟合 | τ/δ/归一化标定 | 单 LiNGAM（约 5 min）+ marker 单变量 GAM（约 1 min），**不跑全对向图** |

合计约 2 小时；必须支持断点续跑（每个模板每引擎产物独立落盘），GAM 全图 10 次/模板的降配在报告中显式声明为复现预算适配。

**预算保护条款（预注册）**：0.016s/单 GAM、0.49s/对为方案定稿前实测估计，D2 启动时先跑 1 个模板计时验证；若 marker 列 50 次 Bootstrap 预估总耗时超预算 50%，降至 **20 次/模板**并在报告记录降配（π^A 口径相应标注）；LiNGAM 100 次不允许降。**留一重学范围**：每条被留训练轨迹只属于一个 (k,g)，因此该折仅重学它所属的那 1 个模板的标定签名，其余 8 模板不含该轨迹、原样复用（约 240 套 × 单模板单次，LiNGAM≈6 min）。

### 13.5.3 LiNGAM 产物（Alg1+Alg2 严格对齐论文）

- 每次 Bootstrap 独立拟合并独立求 T_b=(I−B_b)⁻¹，再汇总（不得用聚合 B 单次求逆）；
- 边统计四指标：出现率 f_e、方向一致率 dir_e、强度中位数/四分位距、**同号率 π^L_e**；
- 稳定边：f_e≥0.7 且 dir_e≥0.9（沿用方案一阈值）；
- marker→j 的 π^L_{m,j}=同号率；c^L_{k,g}[j]=median_b T_b[j,m]（保留符号）；
- **数值爆炸闸门（仅 R5 排序/展示层，不改变 E3 分数）**：|T| 的跨边比较必须带 π——π<0.7 或组间方向翻转的边（如 PSGA→P=+5855 型近奇异边）在 R5 的 |T| 排序中权重乘 π（单次）、打标 `unstable_magnitude`、禁止进入排序首位。**E3 的 wL 已含 π^L，闸门不得在 wL 上再乘一次 π（禁止 π² 重复降权）**；该闸门不改写 E1/E2/E3 任何分数；
- 严重度稳健性：边在 3 个组间翻转方向时打标 `severity_flipped`（可辨识性证据，不是删除理由）。

### 13.5.4 GAM-ANM 产物

- C^A：对每个症状 j 拟合 marker 列单变量 GAM（**每条训练轨迹一个稳态点**：x=主窗 z_marker 中位数、y=主窗症状 z 中位数；训练中位数处局部线性化方向，n_splines=6, lam=1），50 次轨迹 Bootstrap 给 π^A_{m,j} 与方向 c^A；显式标注"训练分布平均效应，非全局非线性总效应"；组内 x 的 IQR spread<0.05 时整列标 `not_estimable`（πA=0），GAM 失败回退 OLS；
- **marker→症状符号的引擎主从（D1 修正，RCA-031）**：扩展学图窗虽恢复 marker 出边存在性，但同期 SEM 对滞后响应变量（如 P/WHPI/功率类，阶跃即时而响应滞后）给出系统性符号反转（实测 LOCA：WLR→VOL 同期符号与跨轨迹稳态一致，而 WLR→P、WLR→WHPI 同期系数反号；DNBR 在本仿真器 LOCA/FLB 下相对恢复段基线大幅上升、SGATR 不响应，方向表一律以实测 C^A/跨轨迹稳态为准，不套用教科书先验）。故冻结分工：**边的存在性与拓扑分层只用 LiNGAM（稳定边/frontier）；marker→症状的符号与量级以轨迹级 C^A 为主证据**（πA≥0.70 取 cA），LiNGAM 总效应列 cL 在 πA 不达标时兜底（πL≥0.70），有效效应图 c_eff 逐边记录来源 A/L/A_unstable/L_unstable。E3-base 仍按 13.7.4 双引擎等权（E3_L 与 E3_A 各算各的 π 加权符号一致率后均值）；E3-path 的符号匹配用 c_eff；
- 全对向图 10 次仅用于与 LiNGAM 稳定边做共识三分类，写入 E^cons。**共识门槛（预注册）**：LiNGAM 稳定边且 GAM 10 次中同方向出现 **≥5 次**才记"共识边"；方向相反记"冲突边"；GAM 出现 <5 次（含未出现）记"单边（仅 LiNGAM）"，R5 忠实性校验对单边降一档展示。

### 13.5.5 本体约束接线（修复 RCA-021）

学图后统一调用本体约束函数：删除 forbidden 边（记录删边清单与删边前后物理一致率）；allowed 边只加标记；competitive 边保留。`−本体约束` 消融通过同一学图函数的 `use_ontology=False` 开关实现，禁止另写旁路。

### 13.5.6 签名数据结构（9 模板）

`signature_{k}_{g}.json` = {k, g, M_k（marker 正/负规则与 ε）, A_{k,g}（组中位有符号 z 异常模式 + 越限指示）, G^L（稳定边+四指标）, G^A（GAM 边+频次）, E^cons（共识三分类）, C^L（c^L+π^L）, C^A（c^A+π^A）, frontier（marker 出边 BFS 三层 S1/S2/S3）, flags（severity_flipped / unstable_magnitude / ontology_supported）}。取消 v2.0 实现里的"逐条签名再平均"伪聚合层（RCA-023）。

## 13.6 Phase R1.5：反事实验证环（Alg3，探索性降级口径）

对齐论文 Alg3 的 Q1/Q3 分组、留出数据、Δ_pred vs Δ_obs。marker 尺度用 13.5.1 的 z_marker（平台≈1、未激活≈0）：

0. **适用性门（预注册，防止低动态范围下假降权）**：模板级动态范围 dr_{k,g}=训练轨迹按 z_marker 排序后 Q3 组中位数−Q1 组中位数。仅当 dr≥0.10（即上下半组 marker 相差至少 0.1 个平台单位）且两组各≥5 条轨迹时执行重演；否则该模板标 `cf_not_applicable`，gCF 全取 1（不降权），报告中列出并说明（低严重度组 marker 平台接近时预期命中）。边级补充：适用模板内若 |Δobs|<0.1 且 |Δpred|<0.1（z 单位，双侧近零），该边标 `cf_inconclusive`，gCF=1，不进一致率分母。
1. 对适用模板 (k,g) 的每条 marker→j 边，在训练分布取 a1=Q1(marker)、a2=Q3(marker)；
2. **线性重演**：Δj_pred = (a2−a1)·c^L[j,m]（=论文 τ·Δa）；
3. **非线性重演**：Δj_pred^GAM = ĝ(a2)−ĝ(a1)（标注平均效应口径）；
4. 留出数据：训练轨迹级 K 折（K=5）留出，在留出轨迹中按 marker 取值分基线组（≈a1）与干预组（≈a2），Δj_obs=两组症状中位数之差；
5. 每模板每引擎报告：方向一致率（sign(Δpred)=sign(Δobs) 的边占比，分母排除 inconclusive 边）、量级 Spearman 相关、|Δpred−Δobs| 分布；
6. **质量门控（对分类的唯一影响通道，两档离散，不连续调参）**：边级双引擎方向一致率 <0.5 或量级相关为负 → 该边 gCF=0.5（即 E3 的 wL 减半）并打标 `cf_fail`；模板级（全部可判 marker→症状边汇总）一致率 <0.5 → 该模板在反演 max 聚合中权重乘 0.5 并在报告中专列。gCF∈{1, 0.5} 是签名质量门控，不是证据分；Alg3 的原始一致率/相关本身不作为分数出现；
7. 重演结果进 R5 传播链（每条链附重演支持度）；除第 6 条的两档门控外不进入 E1/E2/E3 连续分数，避免双重使用；
8. 边界：静态 SEM 单轨迹重演统计意义弱，本环是**签名相对自洽性的质量门控**，不声称反事实因果证明，不做参数反演。

## 13.7 Phase R2：反演匹配（神经环节②，测试侧零学图）

### 13.7.1 测试观测（修复 RCA-013）

对测试轨迹 x（仅主窗数据）：

- d_x[j] = median_t z_{x,j}(t)，**相对过程本体共享 μ/σ 的有符号偏离**（禁止自标准化）；全程不拟合任何因果模型、不引用真实标签 target；
- 激活集 A(x) = { j∈V_act : 主窗内 |z_j(t)|>3 的时间点占比 > 10% }；
- 系统动作标记：WHPI/WECS 是否阶跃，单独记录；
- **A(x)=∅ ⇒ 强制弃权**（不进入分数比较）。

### 13.7.2 E1：marker 非零规则（FULL 条件；核销 RCA-022）

判据回到 v2.0 冻结定义：|v|>ε。**ε 按类分别计算、不共用**：ε_k = 0.1 × min_{训练轨迹} [marker_k 主窗平台中位数]（在原始量纲上；量级由数据决定，不手写数值），三个 ε_k 一次性冻结落盘（marker 不进 μ±3σ；禁止沿用首跑实现的"共享基线异常分>3"判据）。E1=正 marker 激活比例 × 负 marker 未激活比例。MASKED 条件 marker 列在测试侧删除，E1 不可用（权重归零）。

### 13.7.3 E2：分组异常模式

对 9 模板各算 0.5×越限指示 Jaccard + 0.5×有符号中位 z 余弦（变量按 V_thr∩模板变量对齐）；E2(k)=max_g；全部基于过程本体阈值（−过程本体消融时改用"轨迹窗前 30% 点的均值±3MAD"经验阈值，其余流程不变）。

### 13.7.4 E3-base：π 加权符号一致率（v2.0 冻结定义，双引擎）

对模板 (k,g)，仅在 A(x) 上：

```
E3_L(k,g) = Σ_{j∈A(x)} wL_j · 1[sign(d_x[j])=sign(cL_{k,g}[j])] / Σ wL_j,   wL_j = πL_{m,j}·gCF_j
E3_A(k,g) 同理（cA/πA）；gCF_j = R1.5 反事实门控权重（1 或 0.5）
E3_base(k) = max_g 0.5·(E3_L + E3_A)
```

### 13.7.5 E3-path：传播前沿级联（图拓扑，独立信息通道）

仅用 LiNGAM 稳定边（GAM 密图不分层）。在模板 (k,g) 上从 marker 沿稳定有向边 BFS：S1=直接下游、S2=二跳、S3=三跳；R=S1∪S2∪S3（marker 因果可达域）。

```
reach(k,g) = |A(x) ∩ R| / |A(x)|                              # 异常是否落在 marker 因果下游
depth(k,g) = Σ_{j∈A(x)∩R} wL_j/depth(j) · 1[sign(d_x[j])=sign(cL[j])] / Σ wL_j/depth(j)   # 近邻层加权符号吻合
E3_path(k) = max_g [ 0.5·reach + 0.5·depth ]
```

另计算前沿诊断量：各层异常率 r1≥r2≥r3 的违例对数（三对 (r1,r2)/(r1,r3)/(r2,r3)，取值 ∈{0,1,2,3}，**仅诊断报告，不参与任何评分**）；r3>r1（前沿倒置）时该模板 E3_path 乘 0.8 并打标（这是唯一的评分影响，且已含在 E3_path 内）。reach/depth 使用图的可达性与拓扑层级，是 Pearson/余弦在构造上无法获得的信息；−拓扑消融 = E3_path 退化为无层级的 E3_base。

### 13.7.6 融合、归一化与弃权

- 归一化（沿用 v2.0 校准协议）：E2/E3 的训练分数由轨迹级留一预测产生（被留轨迹不进签名/模板/基线），每类独立 min-max，零极差恒取 0.5 并标记；参数冻结 `calibration_params.json`；
- 融合：FULL 用 s_k=0.3E1+0.35Ê2+0.35Ê3；MASKED 用 s_k=0.5Ê2+0.5Ê3；
- E3 分量：D0 前用 E3_base；D0 后按 13.8.1 冻结结果取 base 或 path；
- 弃权（三条件任一）：A(x)=∅；max s_k<τ；s(1)−s(2)<δ；
- τ/δ：训练轨迹级留一网格搜索最大化 U=正确弃权−错误弃权−λ1·高严重度错误分类−λ2·低严重度错误分类（λ1=1,λ2=2，λ2 做 {1,2,3} 敏感性）；Normal 不参与标定。

### 13.7.7 两级签名计算协议（RCA-026）

- **最终签名**（9 模板）：13.5.2 全量 Bootstrap；
- **标定签名**（约 240 套留一）：每折每类每组单次 DirectLiNGAM + marker 列单次 GAM，不做 GAM 全对向图，拓扑层用单图边（标定只决定阈值，不决定结论）；
- **标定稳定性诊断（G3）**：全部训练轨迹分别在标定签名与最终签名下算 E3_path，两组分值的 Spearman 相关 <0.5 时打标 `calib_topology_unstable`，τ/δ 标定结果必须带此注记报告（不自动否决，但若命中，S2/S3 结论需加"阈值受单图拓扑波动影响"限定）。

## 13.8 Phase R3：实验执行

### 13.8.1 D0 决策门控（D1 末，先于全量实验，半天内）

最小正确 MASKED 实验：修好的 R0/R0.5 + LiNGAM 单引擎 9 模板 100 次 Bootstrap（无 GAM）+ E2 + E3_base + E3_path（同一次学图顺带计算，仅落盘不进判据）+ B1；仅 MASKED-高严重度 18 条（6/类）。D0 时 τ/δ 尚未标定，按 argmax 原始正确性比较（不做弃权），A(x)=∅ 的轨迹移出配对子集并单独计数。

判据（配对设计）：在共同子集（A(x)≠∅，B1 恒有预测）上，逐轨迹 δ_i = 1[**纯 E3_base 通道** argmax 正确] − 1[B1 argmax 正确]（刻意不用融合分，以隔离 E3 通道相对 Pearson 的独立信息；MASKED 融合 0.5Ê2+0.5Ê3 的 argmax 正确性仅作附属数字落盘），Δ̄=mean δ_i，配对轨迹 Bootstrap（重采样轨迹，B=2000，种子 42）95% 百分位置信区间：

- **强证据**：Δ̄>0 且 CI 下界>0 → E3_base 为融合与主张句的主证据，E3_path 列 P2 机制增强；
- **方向性证据**：Δ̄>0 但 CI 跨 0 → 按预注册保守规则，**E3_path 仍升为主证据**（base 相对 Pearson 的独立性未被证明），结论注"base 方向性支持但证据不足"；
- **无证据**：Δ̄≤0 → E3_path 为主证据，E3_base 降为消融对照；
- **事前预期（统计事实，不是倾向）**：n=18 时 CI 下界>0 要求近全部 δ_i 同号，极少达到；**默认预期走 E3_path 分支**。D0 的核心价值是主证据归属的事前冻结与决策留痕，不是小样本统计区分。
- 无论哪个分支，E3_base/E3_path 两版本此后都照常计算，−base、−path 两个消融都做（13.11），D0 只决定融合分量与主张句用谁。
- 决策与当时全部数字（含子集大小 n′、逐轨迹 δ_i、Δ̄、CI、分支）落盘 `d0_decision.json`，主张句在此刻、看其余结果前写死；D0 之后不得再改 E3 选择。
- 顺延条款：若 R0 审计发现注入时刻/数据异常导致 D1 无法完成，D0 顺延至 D2 初（GAM 开跑前），**不压缩 D0 的决策与留痕时间，也不带入任何 D2 结果**。

### 13.8.2 正式实验

- 两条件：FULL（marker 可见，sanity）/ MASKED（测试侧删除 WLR/WTRA/WFLB 三列；**运行日志零访问断言**：测试特征矩阵列名集合与 marker 列表交集为空）；
- 三严重度组分别报告；指标：Overall Accuracy（弃权=错）、Selective Accuracy（接受样本）、Coverage、Abstention Rate、macro-F1（接受样本口径；**接受样本中某类为 0 时该组 macro-F1 报 N/A，并单独报告该类弃权率，禁止跨组合并填充**）、95% Wilson CI；
- **配对差值两口径分开，禁止合并**：① 共同子集口径（Full/MASKED 流水线接受且基线有预测的轨迹；B1/B2 恒有预测故=流水线接受子集），报告逐轨迹配对差值与轨迹 Bootstrap CI——这是 S2/D0 的主口径；② 全样本口径：Overall Accuracy（弃权=错）在全部 20 条/组上对照报告。两口径数字、子集大小同时呈现；
- 配对差值优先：E3 主版本 vs B1、vs B2 按轨迹配对，给差值 Bootstrap CI，不凭 CI 重叠下结论；
- B2 退化曲线（10%~90% 覆盖率）；
- Normal/1.csv：仅作弃权功能验证（不进训练/标定），三条件都报告预测与分数；
- MASKED-strict 结构消融沿用 v2.0（无 marker 重学 G_k′，只报边保留率/E2/E3 诊断量（base/path 分值分布），不比准确率；E3′ 已退役）。

## 13.9 Phase R4：基线（RCA-020 重写）

- **B0（规则上界）**：marker 非零规则，FULL only；MASKED 无定义，报告 N/A 而非 0；
- **B1（相关匹配）**：对测试窗 z 向量 d_x（V_thr，与 E2 同口径的有符号中位 z）与 9 模板组中位 z 向量 z_{k,g} 算 Pearson 相关，**B1(k)=max_g corr，再按 k 取 argmax**（与 E2/E3 的 max_g 对齐；不读测试严重度标签），无弃权；**这是检验 E3 因果增量的主要对照**（对齐论文相关性基线 Jaccard 0.33 的位置）；
- **B2（黑箱 ML）**：XGBoost，特征=窗口统计量（mean/std/min/max/mean−baseline 的 Δ、越限时间点占比），仅 V_thr，不含严重度/文件名/任何标记列；FULL 与 MASKED 各训练一版；**超参实验前冻结、禁止看结果调参**：max_depth=3、n_estimators=100、learning_rate=0.1、random_state=42（其余库默认）；报告训练集 CV；**B2 始终使用过程本体 μ±3σ 阈值构造"越限"特征，−过程本体消融只作用于 Full 流水线，B2 不随消融改口径**（否则消融差异混入基线变动）；
- 全部基线在同一 split_manifest 上运行。

## 13.10 Phase R5：两层输出与解释（神经环节③）

- 第一层：事故类型 + 三证据分 + 弃权状态（复用 v2.0 JSON 行格式）；
- 第二层（修复 RCA-019）：对接受轨迹，在判定类的 D0 指定模板上，**从 marker 出发**沿稳定边 BFS，对 A(x)∪中介变量做双引擎 RRF 排序拼链；链上每条边必须 ∈ 稳定边或 E^cons 共识边（忠实性校验，不满足则标 `ungrounded` 且不得出现在解释正文）；附 Alg3 重演支持度与本体子系统名；

## 13.14 判读纪律与局限

1. FULL 近满分是数据特性，只作 sanity；MASKED 高严重度配对差值是唯一识别增量证据；
2. E3 高相容不单独证实、低不单独证伪；物理真实性只通过 4.2 冻结关系与 Alg3 重演检验；
3. 仿真器近似确定性 + 单类 100 条是严重度扫描，20 条/类、组内 6~7 条只支持描述性结论与 CI，不做总体功效宣称；
4. 静态 DAG 不处理 WLR↔P 等反馈环，竞争边如实标注；时间点强自相关通过轨迹级 Bootstrap 缓解但未消除；
5. GAM 全对向图 10 次/模板是预算降配，E^cons 解释相应放宽，不影响 C^A（50 次）；
6. Normal 仅 1 条，弃权结论的外部效度有限；
7. 全部结论限定 LOCA/SGATR/FLB 三类、PCTRAN 仿真、主分析窗，不向真实电厂外推；
8. 本方案是借鉴论文神经符号因果分析流水线的**变体复现**（GAM-ANM 替代 DiffAN、过程本体用数据驱动 μ±3σ、代码本体替代 RDF/Neo4j），报告与标题禁用"严格复现论文"；
9. D0/S2 的配对 n=18 统计功效低：CI 下界>0 仅在极大效应下可达，未达强证据不构成"E3 无效"的证据（只能写方向性或无证据）；这是预注册时已知并接受的设计约束，不是事后放宽。

## 一、动机：第一版留下的问题与视角反转

### 1.1 第一版的结论边界

第一版在 LOCA 单类事故内部采用 **LiNGAM + GAM-ANM 双引擎**（借鉴论文 LiNGAM/DiffAN 并列思路的**变体**：用 GAM-ANM 替代 DiffAN，见 6.2）验证因果发现能力，并如实确认：

- NPPAD 的 96 个传感器中**没有"破口面积"等注入参数**，单事故内部不存在变量级根因标签；
- 因此任务只能定义为"给定目标变量 P 的上游因果定位"，不能计算根因准确率；
- WLR↔P 动态反馈环超出静态 DAG 的表达能力。

### 1.2 视角反转：跨事故时，根因标签一直存在

上述结论仅在**单一事故类型内部**成立。当把视角拉到**跨事故类型**，数据集结构发生根本变化：

> **文件夹名 = 事故类型 = 仿真注入的根因工况 = 可用于验证的 Ground Truth。**

每类事故还有一个**故障过程变量（marker，标记变量）**直接测量故障本身，正常工况下恒为 0：

| 事故 | 注入的根因工况 | 标记变量（README Table 2） |
|------|--------------|--------------------------|
| LOCA / LOCAC | 一回路热段/冷段破口 | WLR：一回路泄漏流量 |
| SGATR / SGBTR | 蒸汽发生器 A/B 传热管破裂 | WTRA / WTRB：SG 管泄漏流量 |
| FLB | 给水管道破裂 | WFLB：给水管道破口流量 |

于是"给定异常数据反推根因"在跨事故设定下**有答案、可验证**：根因粒度是**事故类型**，而不是连续的注入参数值。

### 1.3 但实测立刻给出一个警告（本方案最重要的事实）

2026-10-26 对下载到本地的轨迹实测发现（详见第二节）：**三类事故的标记变量彼此严格互斥、注入后一个采样步（10s）内即达稳定平台、严重度 1 时也清晰非零。** 这意味着"看哪个 marker 非零"的规则分类器预期接近 100% 准确。

因此本方案**不以识别准确率作为卖点**——那将是数据本身给出的平凡结果。本方案要回答的是三个有区分度的问题：

1. **解释问题**：识别出事故类型后，因果图能否给出与物理机制一致、经忠实性校验的传播链（间接根因）？
2. **退化问题**：当标记变量不可用（传感器缺失/故障/刻意隐藏，即真实现场常见情形）时，仅靠传播症状，因果签名在什么条件下仍可识别、在什么条件下必然失败？**失败边界本身就是结论。**
3. **对照问题**：相对黑箱分类器（XGBoost），因果流水线的增量价值不在准确率，而在可解释性、弃权能力与可迁移的物理结构。

### 1.4 两级 RCA 架构

```
未知异常轨迹
    │
    ▼
【第二版】跨事故根因识别：因果签名匹配 → 直接根因 = 事故类型（本方案）
    │
    ▼
【第一版】事故内上游定位：该类型的 LiNGAM 因果图 → 间接根因链 = marker→症状传播路径（已实施，复用）
    │
    ▼
自然语言解释（复用 Phase 5.5，因果图提示注入 + 忠实性校验）
```

## 三、任务定义与 RCA 粒度声明（继承第一版的诚实口径）

### 3.0 形式化：作为溯因诊断（Abductive Diagnosis）的事故级 RCA

为使本任务在形式上就是根因分析而非"分类+事后解释"，采用经典基于模型诊断（Reiter 1987；Poole 溯因诊断）的三元组建模：

- **SD（系统描述）**：从数据学到的结构化因果模型——逐类事故的结构方程 X = B_k X + e、总效应 T_k=(I−B_k)⁻¹、以及冻结物理关系（4.2）；
- **F（故障模式假设集）**：f_LOCA / f_SGATR / f_FLB，分别对应仿真注入的真实工况（一回路热段破口 / SG-A 传热管破裂 / 给水管道破裂）。**f_k 是潜变量**——96 个传感器中没有任何一列直接测量它；
- **OBS（观测）**：测试轨迹窗口内全部可用变量及其相对共享基线的异常模式。

**诊断定义**：对未知观测 OBS，求最小故障假设 f_k，使 ① SD ∪ {f_k} ∪ OBS **相容**（consistency 条件，对应 E3′），且 ② SD 中 f_k 的预测症状集能**解释** OBS 的异常方向（abduction 条件，对应 E3）。诊断输出两层：

| RCA 输出 | 本方案对应物 |
|---------|------------|
| **根因（root cause）** | 诊断出的故障模式假设 f_k（=事故类型，以文件夹标签为 GT 验证） |
| **根因证据链（causal explanation）** | 该假设下从故障最近可观测节点到各症状的稳定有向路径（双引擎：G_k^L/G_k^A + E_k^cons 共识边 + C_k^L/C_k^A） |

**marker 的严格定位（关键概念边界）**：WLR/WTRA/WFLB 是故障模式 f_k 的**指示器/表征变量（fault indicator / manifestation）**——离潜故障最近的可观测节点，**不是故障本身，也不是外生干预变量**。破口（f_k）导致泄漏流量（marker），marker 又受系统状态反作用（WLR↔P 反馈即为例证）。因此：
- 报告措辞统一为"**根因：LOCA 工况（热段破口，潜变量假设）；直接证据：WLR 激活；传播链自 WLR 起……**"，禁止写"根因是 WLR"；
- C_k^L[Y]=T_k[Y, marker_k]（LiNGAM 总效应）与 C_k^A[Y]=平均边际效应 sign(∂Y/∂marker_k)（GAM-ANM）共同读作"**自故障最近可观测代理节点出发的模型传播签名**"，是 f_k 效应的可观测代理，不等同于"真实破口的物理传播真值"；其与物理机制的一致性由 4.2 冻结关系统计检验，不预设为真。

这一区分不削弱 RCA 属性：经典诊断中故障本就是不可直接观测的假设（如医学诊断中"流感"是假设，"发热"是表征）；RCA 的形式要件是"假设—模型—观测"的相容/解释结构与可验证标签，二者本方案均具备。

### 3.1 任务

> 给定一段未标注的异常轨迹窗口 OBS，在故障模式假设集 F={f_LOCA, f_SGATR, f_FLB} 中求最能相容且解释 OBS 的最小假设（直接根因 = 事故类型），输出该假设下从故障指示器 marker 到系统症状的因果证据链（间接根因链）；以文件夹标签验证诊断正确性，以冻结物理关系统计检验证据链方向。

### 3.2 三级粒度与可声称范围（实验前冻结）

| 粒度 | 本方案定义 | 可验证性 | 是否声称 |
|------|-----------|---------|---------|
| **直接根因** | 故障模式假设 f_k（注入工况，潜变量；以事故类型标签验证） | 文件夹标签，可算准确率/F1 | ✅ |
| **间接根因链** | 自故障指示器 marker（最近可观测代理）到症状的稳定有向路径 | 与逐类冻结物理关系对照（方向一致率） | ✅ 候选关系口径 |
| 注入参数值（破口面积等连续量） | 不在 96 列中 | 不可验证 | ❌ |
| 破口空间位置（LOCA vs LOCAC） | 当前 96 变量聚合集与主窗口下未检出可区分差异（2.3） | — | ❌ 显式排除 |

措辞纪律沿用第一版：传播链统一表述为"模型在某类事故/某严重度组上**稳定识别出的有向关系**"，不称"已证实因果"。

### 3.3 候选类别

K=3 类事故（LOCA、SGATR、FLB）+ **Normal 作为"应弃权/非事故"对照类**。Normal 仅 1 条轨迹，不参与轨迹级 Bootstrap，只用于弃权机制的功能验证（统计效力不足，单独声明）。

LOCAC 排除理由见 2.3；SGBTR、LLB、SLBIC 等列入扩展路径（第十一节）。

### 3.4 为什么是这三类——"有关联"的精确含义（选取理由，实验前冻结）

这三类不是随机挑选，而是构成一条**以蒸汽发生器为界面的"装量丧失"故障谱系**：故障源头分处一回路/传热管/二回路三个不同位置，却在高严重度下产生部分重叠的症状。正是这种"源头不同、症状有交集"的结构，才使因果签名（区分传播方向与路径）比单纯的异常模式分类有意义；若三类症状完全正交，任何规则查表都能解决，便无需因果方法。

| 事故 | 故障家族 | 破口物理位置 | marker | 高严重度共享症状（t=1500s 实测） | 可分的症状结构（实测） |
|------|---------|------------|--------|------------------------------|---------------------|
| LOCA | 一回路装量丧失 | 一回路热段（压力边界） | WLR | P↓、VOL↓、TAVG↓、安全系统 WHPI/WECS 投入 | 失压最剧烈（P=44.4）、SG 二次侧 PSGA↓（29.6） |
| SGATR | 一回路→二回路泄漏 | SG 传热管（两个回路的界面） | WTRA | P 缓降、VOL 缓降、WHPI/WECS 投入 | 一回路中等受扰（P=115.2）、二次侧 PSGA 反升（74.5）、LSGA↑ |
| FLB | 二回路装量丧失 | SG 给水侧管道 | WFLB | 高严重度 P↓、WHPI/WECS 投入 | 一回路最后才受扰（P=164.2 近正常）、二次侧 PSGA=74.5、蒸汽/给水量塌陷 |

**预先承认的对照事实**：低严重度时三者除 marker 外几乎都无症状（2.4 实测），FULL 条件下区分它们完全靠 marker——这是数据设计使然，不夸大。本 pilot 的科学问题集中在**高严重度 MASKED**（因果结构能否把共享症状还原到不同源头）与**低严重度 MASKED 的弃权边界**。

## 四、因果签名的定义（实验前冻结）

每类事故 k 在训练集上学到一个签名 **Σ_k = (M_k, A_k, G_k^L, G_k^A, E_k^cons, C_k^L, C_k^A)**——沿用第一版的 **LiNGAM + GAM-ANM 双引擎**设计：

| 组件 | 内容 | 数据来源 |
|------|------|---------|
| **M_k（marker 模式）** | {WLR, WTRA, WFLB} 的激活二值模式 + 平台段中位幅值 | 直接读取 |
| **A_k（异常模式）** | 相对共享准 Normal 基线（2.5），各变量的越限占比向量与中位 z 偏离向量（含方向） | 异常阈值模块（复用第一版） |
| **G_k^L（LiNGAM 因果结构）** | 线性/非高斯引擎的稳定边集、四指标、稳定系数矩阵 B_k | 第一版 Phase 1~2 逐类重跑 |
| **G_k^A（GAM-ANM 因果结构）** | 非线性 ANM 引擎的方向判定、平均边际效应、稳定边集 | 第一版 Phase 1~2 逐类重跑（pygam 成对拟合） |
| **E_k^cons（双引擎边共识）** | 对 G_k^L 与 G_k^A 的稳定边做三分类：共识边（方向一致）/ 冲突边（方向相反）/ 单边（仅一方法） | 第一版 Phase 3.2 边方向融合 |
| **C_k^L（LiNGAM 传播签名）** | T_k=(I−B_k)⁻¹ 中 marker_k 列（有符号总效应） | 第一版 Algorithm 2 路径 A，逐次求逆 |
| **C_k^A（GAM-ANM 传播签名）** | marker_k 对各症状 Y 的平均边际效应 \|∂Y/∂marker_k\| 及方向（非线性效应） | 第一版 Algorithm 2 路径 B，GAM 边际效应 |

> 本方案"因果"二字的落点是双引擎的传播签名：C_k^L（线性总效应）与 C_k^A（非线性边际效应）共同构成"故障扰动沿什么方向、以多大效应传播"的结构化指纹。两引擎基于不同可辨识性假设（非高斯 vs 非线性 ANM），结果差异本身是关于假设敏感性的证据。
>
> **融合纪律（继承第一版 Phase 3.2）**：双引擎**不在矩阵层融合**（不存在统一的线性 B_fused，因为 GAM-ANM 不产出线性 B）。融合发生在两处：① 边方向层（E_k^cons 共识/冲突/单边分类）；② 排序层（RRF：`score(Y)=1/(k+rank_L(Y))+1/(k+rank_A(Y))`，k=60）。本方案的 E3 反演在两个引擎签名上分别打分后再融合（见 Phase R2）。

### Phase R2：匹配器（规则全部实验前冻结）

> **（v2.1 已由第 13 节 13.7 取代；E3 以 13.7.4/13.7.5 的 base/path 双版本为准，勿据此实现）**

对测试轨迹 x（121 点的窗口）：

**E1 marker 证据（确定性）**：marker 非零（\|v\|>ε，ε 取训练集中 marker 平台幅值最小值的 1/10，对极小信号保守）即激活对应类别；互斥激活直接给唯一类；零激活→进入 E2/E3 与弃权判定。

**E2 异常模式相似度**：对每个类 k，计算 x 的异常向量 a_x 与**训练集该类所有严重度组**异常向量的余弦相似度，取类内最大值作为 E2_k。**不使用测试轨迹的严重度标签**（按严重度组指训练集的分组模板，非测试轨迹分组）。

**E3 因果反演分（abduction，本方案的因果匹配核心，双引擎）**：

这是对论文"按总效应排序根因"逻辑的反向使用——论文是"给定目标异常，按 T 排上游变量"；这里是"**给定观察到的症状向量，问哪一类的 marker→症状传播签名最能解释它**"。双引擎各自打分后融合。

- 观察向量 d_x：测试窗口内各变量（共享标准化后）的中位偏离，方向取符号；
- 候选解释（双引擎）：
  - c_k^L：类别 k 的 T_k=(I−B_k)⁻¹ 中 marker_k 所在列（去掉 marker 行）——LiNGAM 总效应方向；
  - c_k^A：类别 k 的 marker_k→各症状 Y 的 GAM 平均边际效应方向（sign(∂Y/∂marker_k)）——非线性边际效应方向；
- 激活变量集 A(x)：越共享基线 μ±3σ 的点占比 >10% 的非 marker 变量（阈值沿用第一版异常口径，10% 为预注册值并做 5%/20% 敏感性）；
- 逐引擎打分（主指标，冻结）：在 A(x) 上计算**经 Bootstrap 稳定性加权的符号一致率**——

  E3_k^L = Σ_{j∈A(x)} π_kj^L · 1[sign(d_xj) == sign(c_kj^L)] / Σ_{j∈A(x)} π_kj^L
  E3_k^A = Σ_{j∈A(x)} π_kj^A · 1[sign(d_xj) == sign(c_kj^A)] / Σ_{j∈A(x)} π_kj^A

  其中 π_kj^L 是 LiNGAM 100 次 Bootstrap 中 marker→j 总效应同号比例；π_kj^A 是 GAM-ANM 50 次 Bootstrap 中边际效应方向同号比例；不稳定预测权重低，避免弱边决定结果；
- **双引擎融合（与第一版 RRF 融合纪律一致，在评分层而非矩阵层）**：

  Ê3_k = 0.5 · Ê3_k^L + 0.5 · Ê3_k^A

  归一化 min-max 在训练集 leave-one-out 上分别校准两个引擎（见校准协议），等权融合；不引入融合权重超参。等权的理由：两引擎可辨识性假设正交，无先验理由偏向其一；权重敏感性列入消融（0.3/0.7、0.7/0.3）。
- **A(x) 为空（没有非 marker 变量异常）→ E3 无定义 → 直接进入弃权**。这一条把 2.4 的实测预期固化进算法：低严重度掩蔽下没有症状就不应硬猜；
- E3′ 诊断量（**只报告、不融合**）：仅对 LiNGAM 引擎把 B_k 代入 x 求结构方程残差，残差协方差非对角能量（Frobenius）作为"该类结构能否生成 x"的健全性检查；GAM-ANM 无全局结构方程残差，不设对应量；
- 单条轨迹 121 点强自相关，**E3/E3′ 只作轨迹级排序证据，不解释为似然或概率**；稳定性在 20 条测试轨迹上汇总。

**E3 的解释边界（实验前冻结，报告必须照此口径）**：
1. E3 是观测与签名的**相容性匹配（compatibility）**，不是真实因果反演、不是根因后验概率、也不是对总效应的直接验证；d_x（单轨迹实际偏离）与 c_k^L/c_k^A（训练模型的结构关系）不是同类对象，符号化+激活集+π 加权是为使二者可比而专门设计的启发式，不声称统计最优；
2. **"c_k^L/c_k^A 中效应方向为正"不蕴含"该事故下该变量必然相对基线升高"**——实际症状还受严重度、控制系统动作、发展阶段影响（FLB 的 LSGA 实测反升即反例，故其方向冻结为 L3 不预设）；因此 E3 的符号不一致只计入相容性扣分，不单独作为证伪；
3. 多类同相容时系统**不得被迫给确定答案**（弃权规则处理）；G3 合成单测必须覆盖"三类得分接近 → 弃权"用例；
4. **E3 高不单独证实、低不单独证伪**：c_k^L 是拟合线性结构方程下的模型总效应，c_k^A 是 GAM 在训练分布上的平均边际效应，二者符号都不必然等于事故相对基线的异常符号（控制系统阶跃、严重度梯度、时间演化、非线性局部线性化都会造成系统性差距）；E3 高分只说明"在本定义下符号相容性高"，不能升级为"发现了真实因果传播规律"；E3 低分也不能单独否定某类物理机制——真实物理机制的验证只通过 4.2 冻结关系的方向一致率统计检验，不通过 E3 个案。

**融合与弃权（冻结，统一连续量口径，避免排名粒度过粗）**：

先做方向归一：E2 = 余弦相似度（∈[−1,1]，越大越相似）；E3 = 符号一致率（∈[0,1]，越大越相容）。两者都是**越大越好**。

**校准协议（实验前冻结，确保无歧义实现）**：
- 训练分数由**轨迹级留一预测**产生：对每个训练轨迹 i（**含 sev-1**），用**除 i 之外**的训练轨迹重学该类签名（G_k^L/G_k^A、C_k^L/C_k^A、异常模板 A_k、共享基线 μ/σ 均不含 i），再对 i 计算 E2_k(i)、E3_k^L(i)、E3_k^A(i)；这样训练分数本身就是严格留一的，归一化参数不接触被留轨迹。**当被留轨迹为 sev-1 时，共享基线 μ/σ 用其余三条 sev-1 的 520~2030s 段重算**，不接触被留轨迹；
- 每类 k 的 Ê2、Ê3^L、Ê3^A **各自独立**做 min-max 归一到 [0,1]，min/max 仅来自该类 k 的留一训练分数；不同类的 min/max 互不影响，归一后跨类可比；
- **Ê3_k = 0.5·Ê3_k^L + 0.5·Ê3_k^A**（双引擎等权，在归一后融合）；最终融合分 `s_k = 0.5·Ê2_k + 0.5·Ê3_k`；
- **零极差处理**：若某类某分量（Ê2/Ê3^L/Ê3^A）的极差 < 1e-6，则该分量对所有样本恒取 0.5，并在 `calibration_params.json` 中标记 `degenerate=true`；不允许除零；
- 全部归一化参数（每类 min/max/退化标记）写入 `calibration_params.json` 冻结，**测试轨迹只套用这些参数，不参与任何 min/max 估计**。

1. E1 唯一激活 → 输出该类（FULL 条件）；同时 E2/E3 仍计算并写入结果留痕，供 MASKED 同轨迹对照；
2. E1 零激活（MASKED 或本底）→ 连续融合分 `s_k = 0.5 · Ê2_k + 0.5 · Ê3_k`（等权预注册；权重敏感性列为 P2，不影响主实验）；
3. **弃权（两条同时明确，阈值均作用于连续融合分 s）**：
   - **置信度弃权**：max_k s_k < τ，τ 由训练集轨迹级留一法标定（见下）；
   - **歧义弃权**：s_(1) − s_(2) < δ（降序排列后第一与第二的差），δ 同样由留一法标定；
   - 触发任一即输出"无匹配/非事故"，**不返回预测类**；
   - ε（E1 的 marker 激活阈值）取训练集 marker 平台幅值最小值的 1/10，在 R1 阶段一次性算出并冻结，不逐轨迹调整。
4. **τ、δ 的留一标定（D3，测试集不可见）**：
   - 训练预测严格留一：对每个训练轨迹 i 的弃权决策，其签名、异常模板、归一化参数**全部由不含 i 的训练子集确定**（与校准协议同一套留一签名，复用而非重学）；
   - 每条留一预测归入三类计数之一：**正确分类**（预测类=真实类且未弃权）、**错误分类**（预测类≠真实类且未弃权）、**弃权**；
   - 样本性质预定义：低严重度（sev 2-33）= **可弃权样本**（弃权属正确行为，但**错误分类仍属错误**——"无症状时宁可弃权也不硬猜"）；高严重度（sev 67-100）= **可分类样本**（弃权属错误行为）；中严重度（sev 34-66）不参与标定目标函数，只用于报告弃权率。**Normal 不参与 τ/δ 标定**（仅 1 条、不进 Bootstrap），只作为测试样本报告弃权率/误警率；Normal 的 s_k 分数按三类签名取 max_k s_k 计算，仅用于功能验证。
   - 对候选 (τ, δ) 网格，净收益

     U = N(可弃权样本被弃权) − N(可分类样本被弃权)
         − λ₁·N(可分类样本被错误分类) − λ₂·N(可弃权样本被错误分类)

     其中 λ₁=1（高严重度错误分类与错误弃权同罚），λ₂=2 预注册（低严重度"不该猜却猜"的代价高于高严重度猜错，因为前者违反设计原则）；取 U 最大的 (τ, δ) 冻结入 `abstain_params.json`；λ₂ 做 {1, 2, 3} 敏感性分析，报告不同 λ₂ 下的弃权率与选择性风险变化；
   - 报告必须给出：**覆盖率**（未弃权样本占比）、**选择性风险**（被接受预测中的错误率 = 错误分类/(正确分类+错误分类)）、各严重度组的弃权率、低严重度弃权准确率、高严重度保留率；不允许只报总准确率。
5. 并列处理：Ê2/Ê3 浮点相等概率极低，若出现则取字典序靠前者且不计入 δ 比较（即视为 δ=0 触发歧义弃权），杜绝随机打破。
6. 不训练学习型元分类器作为主方法（避免因果归因被黑箱吞并）；学习型方法只以 XGBoost 基线身份出现。

### Phase R3：两条件 × 三严重度组

> **（v2.1 已由第 13 节 13.8 取代（含 D0 门控、配对两口径）；本节仅作设计溯源保留，勿据此实现）**

- **FULL**：全部 22 变量可用；

- **MASKED-strict（结构性消融，非同口径分类消融）**：在无 marker 节点的图上重学 G_k′（双引擎都重学：G_k^L′、G_k^A′）。此时 c_k^L（marker→症状总效应）与 c_k^A（marker→症状边际效应）均不可计算，**E3 全引擎失效**；该消融**只使用 E2 作为分类器**，E3′ 仅作为 LiNGAM 引擎的诊断量报告（残差能量分布、稳定边密度变化），**不把 E3′ 纳入分类融合**。其目的不是与 Full 比准确率，而是量化"移除根因→症状模板知识后，因果结构本身与异常模式各自还剩多少信息"，为解释 Full→MASKED 的退化提供结构证据。报告指标：G_k^L′/G_k^A′ 相对原签名的稳定边保留率、E2 单独的分类/弃权结果、E3′ 残差能量分布。
- 按真实严重度低/中/高分别报告；Normal 单独报告弃权/误警；
- 所有准确率的推断单位是**轨迹**（每类 20 条），报告 Wilson 95% 置信区间，禁止用 121 点膨胀 N。

### Phase R5：间接根因链解释（两层输出：类型识别 + 溯源排序，复用第一版 Phase 5.5）

> **（v2.1 已由第 13 节 13.10 取代：传播链从 marker 出发、忠实性校验、可达域外不硬排；本节仅作设计溯源保留，勿据此实现）**

识别类型 k 后，分两层产出：

**第一层（有准确率）**：直接根因 = 事故类型 k，证据 = E1/E2/Ê3^L/Ê3^A 各自贡献分 + 弃权状态。该层的准确率由 Phase R3 的类型识别评估给出。

**第二层（无准确率，有解释力）**：用类型 k 的签名对**当前测试轨迹实际异常变量 A(x)** 做传播链溯源排序——
1. 取测试轨迹的异常变量集 A(x)（Phase R2 已算）；
2. 对每个 Y ∈ A(x)，取 C_k^L[Y] = |T_k[Y, marker_k]|（LiNGAM 总效应强度）与 C_k^A[Y] = |avg_marginal_effect(marker_k→Y)|（GAM-ANM 边际效应强度）；
3. 用 RRF 融合排序：`score(Y) = 1/(60+rank_L(Y)) + 1/(60+rank_A(Y))`，降序得到 marker→症状传播链；
4. 沿 G_k^L/G_k^A 稳定边拼接路径，方向一致率 < 90% 标注"不确定"，E_k^cons 冲突边如实标注两引擎方向分歧；
5. 输出排序后的传播链（如 `WLR→VOL(0.91)→LVPZ(0.78)→P(0.65)`），这是"上游溯源"的具象化。

**报告**：直接根因（类型+证据）+ 间接根因链（排序后的传播路径+不确定性标注）+ 弃权时的证据说明。忠实性校验复用；失败降级模板驱动。每条测试轨迹的传播链排序落 `root_cause_chain_{trajectory}.json`。

### 6.2 双引擎设计说明（LiNGAM + GAM-ANM，P0 主线，借鉴论文 LiNGAM/DiffAN 并列思路的变体）

> **（v2.1 双引擎预算与产物以 13.5.2/13.5.4 为准——GAM 全对向图仅 10 次供共识标注；本小节仅作设计溯源）**

**引入动机（物理，非为凑对照）**：LiNGAM 假设线性加噪，但本数据中安全系统变量是**控制逻辑驱动的阈值/阶跃响应**——实测 WHPI 在 SGATR/25 整窗为 0、在高严重度突增为 93.8（12.5%→100% 间存在投入阈值），WECS 同类；PSGA 在高严重度还呈现饱和/平台。这些"阈值触发 + 饱和"形态线性边表达不了，非线性加噪模型是自然的最小升级（而非直接跳到深度模型）。第一版已留有 ANM 探索性产物（`output/results/anm_baseline_results.json`，LOCA 50 次重采样的稳定边，如 VOL→P f_e=1.0），第二版把该探索在多事故签名框架下**正式化为主线引擎 B**，与 LiNGAM 并列，不预设谁更优。

**选型（实验前冻结，P0 主线）**：首选 **GAM-ANM 成对判定**——对每对变量用 GAM（样条加性）回归两个方向，以 HSIC 检验残差独立性，取残差独立的方向；产出方向判定 + 平均边际效应 \|∂Y/∂X\|。**不进入 T=(I−B)⁻¹**（GAM-ANM 不产出线性 B），传播签名走路径 B（边际效应）。若 pygam 装不通/跑不动（Python 3.14 轮子风险），按第一版退出纪律如实记录，**不得看结果后临时换模型**；此时仅 LiNGAM 单引擎可交付，但需在报告中声明双引擎未完整执行。

**纪律与边界**：
- 两引擎在同一份训练 80 条轨迹、同一 121 点窗口、同一本体约束下并行运行，签名其余组件（M_k/A_k）共用——保证"线性 vs 非线性"是干净的引擎对照；
- Bootstrap 重数预注册为 LiNGAM 100 次、GAM-ANM 50 次（GAM 单轮拟合成本高一个数量级）；同为轨迹级重采样，n=80 轨迹；
- GAM-ANM 结果**主要用于**：① 阈值/饱和类关系（WHPI/WECS、PSGA 平台）的方向稳定性是否改善；② 作为 E3^A 与 LiNGAM E3^L 融合；③ 严重度三分组学图与 E_k^cons 共识分类。**不预设 ANM 全面优于 LiNGAM**——非线性模型在 n=80、p≈22 下方差更大，可能更不稳定；
- 非线性不解决两个根本问题：反馈环（WLR↔P 仍是竞争假设）与低严重度信息缺失（无症状照样触发弃权）；
- **GAM-ANM 的边际效应是训练分布上的平均效应**：GAM-ANM 的 \|∂Y/∂X\| 是在训练数据分布上对非线性函数 f 的边际效应平均，**不自动等价于非线性结构方程的全局总效应**——不同评估点、不同事故阶段的传播行为可能不同。C_k^A 仅用于与线性 C_k^L 在 E3 中融合提供非线性视角，不得解释为"非线性系统的真实全局传播规律"；报告中凡展示 ANM 传播链处必须标注"训练分布上的平均边际效应，非全局总效应"。
- **两引擎的冲突不判输赢**：E_k^cons 中的冲突边如实标注两引擎方向分歧，不强行选其一作为主结论；差异本身是关于"非高斯 vs 非线性 ANM"可辨识性假设的敏感性证据。
- **复现变体声明**：CausalTrace 原文的非线性引擎是 DiffAN，本方案用 GAM-ANM 替代。二者同属 ANM（加性噪声模型）可辨识性范式，但实现不同（GAM-ANM 用广义加性模型成对拟合，DiffAN 用去噪自编码器）。替代理由是数据规模（n=80 轨迹、p≈22）下 GAM-ANM 更稳定可解释，DiffAN 的深度模型在小样本上方差过大。因此本方案验证的是 **"LiNGAM + GAM-ANM"这一变体**在 NPPAD 上的可行性，**非对 CausalTrace 原文方法的严格复现**；标题与摘要中均不使用"复现"二字，而使用"借鉴"或"变体验证"。

### 6.3 预注册预测与成功判据（实验前冻结）

1. FULL：Full 与 B0 应一致地接近满分；**若 Full 显著低于 B0，说明融合/签名实现有 bug**（这是 sanity 标准而非成绩）；
2. MASKED-高严重度：症状可分（2.4 实测），Full/B2 均应显著优于 1/3 随机水平；报告具体数值与 CI；
3. MASKED-低严重度：**LOCA 低严重度因存在非 marker 症状（P/VOL/TAVG/PSGA 全面异常，2.4），预期可识别**；**SGATR/FLB 低严重度预期失败，成功标准是弃权机制正确触发**（弃权率高、硬猜错误率低）。两类分开报告；XGBoost 在 SGATR/FLB 低严重度同样失败才能把失败归因于信息缺失而非方法缺陷；
4. Normal：弃权为主，误警率单独报告（样本仅 1 条，只作功能验证）；
5. 传播链：LOCA 沿用第一版结果；SGATR/FLB 至少报告核心关系的方向一致率与 f_e，不预设必须成功（低严重度无症状传播时允许"证据不足"，按第一版三条冻结规则处理）；
6. GAM-ANM 引擎（主线）：唯一预先期待改善的位置是**阈值/阶跃类入边**（P→WHPI/WECS、PSGA 饱和段）的方向稳定性与 E3^A 的贡献；其余边及整体 MASKED 准确率允许持平或更差（n=80 下方差更大）。若 ANM 连阈值关系都无改善，如实报告线性假设在此数据规模下不是瓶颈；双引擎不强制优于单引擎。
7. **因果增量的判据与失败口径**：本 pilot 最有价值的单一证据是 **MASKED-高严重度下 E3 相对 B1（Pearson）的增量**。若 E3 不优于 B1/B2，实验不构成失败——仍产出了签名匹配的适用边界；但此时**不得声称因果方法带来识别增量**，只能声称"因果框架提供了可解释结构与弃权能力，识别精度与相关性方法相当"。
8. **小样本纪律**：20 条/类的 Wilson CI 会很宽，按严重度三分组后每组约 6~7 条；禁止基于个位数正确样本下强结论（如"某方法在低严重度有效"），组级结论必须与 CI 一起呈现，宽到跨随机水平时表述为"不确定/证据不足"。
9. **B2 的定位**：XGBoost 是黑箱**对照**而非预设性能上界——不假设它必然胜出；FULL 下它与 B0 同样平凡，MASKED 下它的退化曲线才是对照重点。

> 若结果与上述预测相反（如 MASKED 低严重度竟高分），首先排查泄漏（marker 残留、严重度信息入模、测试集污染），不得直接当作发现。

## 十、研究边界与局限（实验前声明）

1. **根因粒度仅到故障模式（事故类型）**：根因是注入工况这一潜变量假设（3.0），marker 只是其可观测指示器而非根因本身；连续注入参数（破口面积、破口位置）不可观测，不做参数反演；LOCAC 在当前 96 变量聚合集与主窗口下未检出可区分差异（2.3），显式排除而非遗漏。
2. **FULL 准确率无学术增量**：marker 互斥且即时达平台（2.2 实测），近满分是数据特性；贡献主张落在解释、掩蔽退化边界与弃权机制。
3. **静态因果发现的全部既有局限逐类继承**：时间点非 i.i.d.（轨迹级 Bootstrap 不消除自相关）、DAG 不能表达反馈环（SGATR/FLB 若发现双向耦合同样按竞争假设处理）、f_e 仍读作"对严重度构成变化的敏感度"。LiNGAM 的线性假设与 GAM-ANM 的非线性 ANM 假设各自带来可辨识性边界；两引擎的方向分歧不判输赢，只作为假设敏感性证据；GAM-ANM 的边际效应是训练分布上的平均效应，不解释为全局总效应（见 6.2）。
4. **E3 的统计口径**：单轨迹 121 个自相关点上算出的 d_x 与符号一致率只作轨迹级排序证据；E3 是观测与训练签名的**相容性匹配**，不是真实因果反演、不设概率解释、不验证总效应（见 E3 解释边界）；残差能量 E3′ 仅诊断用。
5. **基线效力有限**：共享准 Normal 基线来自 4 条 sev-1 恢复段（608 点、同仿真器、仍含小破口/小泄漏），μ±3σ 仍是探索性评分而非工程容差（沿用第一版声明）；Normal 仅 1 条且为降功率轨迹，弃权率结论统计效力不足。
6. **掩蔽≠真实传感器故障**：MASKED 是理想化信息移除实验，真实故障还伴随噪声与偏置；结论仅为"症状信息量边界"。
7. **严重度仍是已观测未控制的轨迹级协变量**：逐类学图同样存在组内梯度与单轨迹问题；分组报告口径沿用第一版，不宣称已调整。
8. **仿真到现实的鸿沟不在本方案处理范围**：PCTRAN 聚合输出的可辨识性边界（如 LOCA/LOCAC）不代表真实电厂不可辨识，只代表"本数据集 + 本变量集"不可辨识。
9. **Normal 功率不匹配问题依旧**：阈值基线不使用 Normal 轨迹（2.5），与第一版修订一致。
10. **小样本比较纪律**：20 条/类、分组后约 6~7 条/组，Wilson CI 宽。E3 与 B1/B2 的比较**优先报告同一测试轨迹上的配对差值与轨迹级 Bootstrap 不确定性**，不得仅凭 CI 是否重叠就断言显著差异或无差异；组级结论若 CI 跨随机水平，表述为"不确定/证据不足"。
11. **MASKED 不证明跨域可迁移**：模板仍在相同仿真器、相同事故类别的训练数据上学得，MASKED 只检验"特定变量被隐藏时当前签名是否仍有用"，不是跨仿真器、跨工况或真实电厂的迁移验证；最终结论保持"方法迁移与适配的 pilot"定位，不扩大为可推广的诊断系统。

1. **E1**：仅 WLR 越过激活阈值（ε 按训练集平台最小值标定，「待算」），WTRA/WFLB 严格为 0 → **直接根因 = LOCA**（此步 FULL 条件下平凡，如 1.3 声明）；
2. **E2/E3（仍计算并留痕，供 MASKED 同轨迹对照）**：d_x 的 P/VOL/TAVG/PSGA 全面负向、WFWA/WFWB 归零但 WSTA 亦为 0；与 4.3 中 LOCA 行相容，与 FLB 行（WFWA/WFWB 应 −− 但二次侧给水量在 LOCA 中是泵停而非破口分流，区分由 c_k 的训练分布承载）的判别「待算」；
3. **间接根因链（取自 LOCA 类双引擎签名 G_k^L/G_k^A/C_k^L/C_k^A，第一版已学）**：预期稳定路径为 WLR→VOL→LVPZ、P↓→WHPI↑→WECS↑；WLR↔P 按竞争假设呈现，方向一致率照实报告；双引擎冲突边如实标注；
4. **报告输出（示意模板）**：
   > 直接根因：LOCA（一回路热段失水），证据 E1 唯一激活（WLR=367，其余 marker=0）。
   > 间接根因链：泄漏致装量下降（VOL 202→124）→ 液位下降 → 失压（P 69→44）；低压力触发安注（WHPI/WECS=115→126）。WLR 与 P 的方向存在反馈竞争，不确定性已标注。

### 示例 B：MASKED 条件高严重度，未知轨迹 = FLB/100（症状反演，核心科学场景）

marker 全部掩蔽。**实测观察**：t=300s 时 P=124.3、VOL=272.0、TAVG=283.9、PSGA=66.3、LSGA=14.86、WFWA=205.2、WFWB=410.0；t=1500s 时 WFWA≈0、WSTA≈38.3、P 回升 164.2（控制动作后恢复）。

推断过程（**预测，待实验检验**）：
1. 激活集 A(x)：WFWA −−（205 vs 1916）、WFWB −、WSTA −（38 vs 1916）、P −（仅 t=300）、TAVG −；
2. **E3 反演**：
   - FLB 模板 c_FLB 预期 WFWA/WFWB/WSTA 强负 → 与观察**主项符号一致**；
   - LOCA 模板预期 PSGA −−（实测 66.3 接近基线）、VOL −−（272 远未到 LOCA/100 的 202）→ **量级与符号不匹配项更多**；
   - SGATR 模板预期 LSGA+、PSGA+，与观察部分相容但无 WFWA 塌陷 → 稳定性加权后 E3_SGATR 应低于 E3_FLB；
   - 预期排序 E3_FLB > E3_LOCA > E3_SGATR（具体值「待算」）；
3. 预期结论：**直接根因 = FLB**；间接链：WFLB→WFWA↓（破口分流给水）→ 蒸汽量 WSTA↓；WFWA→LSGA 因实测反升（L3）在链中标注"方向不稳定，不作为证据"；
4. 这个例子也预告一个**失败模式**：FLB/100 在 t=300 的 P↓/TAVG↓ 与 LOCA 早期相似，若 c_k 训练分布把"泵停零流量"与"破口分流"学得不可区分，E3 可能误投 LOCA——该混淆是 D5 失败案例分析的重点，不靠调参掩盖。

### 示例 C：MASKED 条件低严重度，未知轨迹 = SGATR/25（应弃权的边界场景）

marker 掩蔽。**实测观察**：P=154.0、VOL=287.8、TAVG=310.0、PSGA=67.0、LSGA=11.89（LSGB=11.84）、WHPI=0、WFWA/WSTA≈基线。

推断过程（**预测，待实验检验**）：
1. 严格 μ±3σ 下 P/VOL 的小偏离（−1.5/−1.8 个工程单位）可能被判激活（共享基线 σ 很小），也可能因越限占比不足 10% 而不进 A(x)——**这正是弃权阈值要在训练集留一标定、而非主观指定的原因**；
2. 若 A(x) 仅含 LSGA(+0.05)、P(微 −)：E3 中 LOCA 模板要求 PSGA −−（不成立，扣分）、SGATR 模板要求 LSGA+（成立）但 π 权重与 |z| 幅值都小 → 三类得分接近且全部处于低置信区；
3. **预期行为：触发弃权**（"检出弱异常但证据不足以判定事故类型；低幅度 SG-A 水位上升为唯一线索，建议复核 WTRA 传感器"），而不是硬投 SGATR；
4. 判据：在全部低严重度 MASKED 测试轨迹上，"正确弃权"的比例应显著高于"正确猜中"的比例；若结果反而是高分猜中，按 6.3 节末规则先查泄漏。

| 示例 | 条件 | 预期结局 | 支撑的主张 |

### 13.0.1 本版目标（复现导向，非投稿）

### 13.5.3 LiNGAM 产物（Alg1+Alg2 严格对齐论文）

- 每次 Bootstrap 独立拟合并独立求 T_b=(I−B_b)⁻¹，再汇总（不得用聚合 B 单次求逆）；
- 边统计四指标：出现率 f_e、方向一致率 dir_e、强度中位数/四分位距、**同号率 π^L_e**；
- 稳定边：f_e≥0.7 且 dir_e≥0.9（沿用方案一阈值）；
- marker→j 的 π^L_{m,j}=同号率；c^L_{k,g}[j]=median_b T_b[j,m]（保留符号）；
- **数值爆炸闸门（仅 R5 排序/展示层，不改变 E3 分数）**：|T| 的跨边比较必须带 π——π<0.7 或组间方向翻转的边（如 PSGA→P=+5855 型近奇异边）在 R5 的 |T| 排序中权重乘 π（单次）、打标 `unstable_magnitude`、禁止进入排序首位。**E3 的 wL 已含 π^L，闸门不得在 wL 上再乘一次 π（禁止 π² 重复降权）**；该闸门不改写 E1/E2/E3 任何分数；
- 严重度稳健性：边在 3 个组间翻转方向时打标 `severity_flipped`（可辨识性证据，不是删除理由）。

### 13.5.4 GAM-ANM 产物

- C^A：对每个症状 j 拟合 marker 列单变量 GAM（**每条训练轨迹一个稳态点**：x=主窗 z_marker 中位数、y=主窗症状 z 中位数；训练中位数处局部线性化方向，n_splines=6, lam=1），50 次轨迹 Bootstrap 给 π^A_{m,j} 与方向 c^A；显式标注"训练分布平均效应，非全局非线性总效应"；组内 x 的 IQR spread<0.05 时整列标 `not_estimable`（πA=0），GAM 失败回退 OLS；
- **marker→症状符号的引擎主从（D1 修正，RCA-031，2026-10-26）**：扩展学图窗虽恢复 marker 出边存在性，但同期 SEM 对滞后响应变量（如 P/WHPI/功率类，阶跃即时而响应滞后）给出系统性符号反转（实测 LOCA：WLR→VOL 同期符号与跨轨迹稳态一致，而 WLR→P、WLR→WHPI 同期系数反号；DNBR 在本仿真器 LOCA/FLB 下相对恢复段基线大幅上升、SGATR 不响应，方向表一律以实测 C^A/跨轨迹稳态为准，不套用教科书先验）。故冻结分工：**边的存在性与拓扑分层只用 LiNGAM（稳定边/frontier）；marker→症状的符号与量级以轨迹级 C^A 为主证据**（πA≥0.70 取 cA），LiNGAM 总效应列 cL 在 πA 不达标时兜底（πL≥0.70），有效效应图 c_eff 逐边记录来源 A/L/A_unstable/L_unstable。E3-base 仍按 13.7.4 双引擎等权（E3_L 与 E3_A 各算各的 π 加权符号一致率后均值）；E3-path 的符号匹配用 c_eff；
- 全对向图 10 次仅用于与 LiNGAM 稳定边做共识三分类，写入 E^cons。**共识门槛（预注册）**：LiNGAM 稳定边且 GAM 10 次中同方向出现 **≥5 次**才记"共识边"；方向相反记"冲突边"；GAM 出现 <5 次（含未出现）记"单边（仅 LiNGAM）"，R5 忠实性校验对单边降一档展示。

## 13.6 Phase R1.5：反事实验证环（Alg3，探索性降级口径）

对齐论文 Alg3 的 Q1/Q3 分组、留出数据、Δ_pred vs Δ_obs。marker 尺度用 13.5.1 的 z_marker（平台≈1、未激活≈0）：

0. **适用性门（预注册，防止低动态范围下假降权）**：模板级动态范围 dr_{k,g}=训练轨迹按 z_marker 排序后 Q3 组中位数−Q1 组中位数。仅当 dr≥0.10（即上下半组 marker 相差至少 0.1 个平台单位）且两组各≥5 条轨迹时执行重演；否则该模板标 `cf_not_applicable`，gCF 全取 1（不降权），报告中列出并说明（低严重度组 marker 平台接近时预期命中）。边级补充：适用模板内若 |Δobs|<0.1 且 |Δpred|<0.1（z 单位，双侧近零），该边标 `cf_inconclusive`，gCF=1，不进一致率分母。
1. 对适用模板 (k,g) 的每条 marker→j 边，在训练分布取 a1=Q1(marker)、a2=Q3(marker)；
2. **线性重演**：Δj_pred = (a2−a1)·c^L[j,m]（=论文 τ·Δa）；
3. **非线性重演**：Δj_pred^GAM = ĝ(a2)−ĝ(a1)（标注平均效应口径）；
4. 留出数据：训练轨迹级 K 折（K=5）留出，在留出轨迹中按 marker 取值分基线组（≈a1）与干预组（≈a2），Δj_obs=两组症状中位数之差；
5. 每模板每引擎报告：方向一致率（sign(Δpred)=sign(Δobs) 的边占比，分母排除 inconclusive 边）、量级 Spearman 相关、|Δpred−Δobs| 分布；
6. **质量门控（对分类的唯一影响通道，两档离散，不连续调参）**：边级双引擎方向一致率 <0.5 或量级相关为负 → 该边 gCF=0.5（即 E3 的 wL 减半）并打标 `cf_fail`；模板级（全部可判 marker→症状边汇总）一致率 <0.5 → 该模板在反演 max 聚合中权重乘 0.5 并在报告中专列。gCF∈{1, 0.5} 是签名质量门控，不是证据分；Alg3 的原始一致率/相关本身不作为分数出现；
7. 重演结果进 R5 传播链（每条链附重演支持度）；除第 6 条的两档门控外不进入 E1/E2/E3 连续分数，避免双重使用；
8. 边界：静态 SEM 单轨迹重演统计意义弱，本环是**签名相对自洽性的质量门控**，不声称反事实因果证明，不做参数反演。

## 13.7 Phase R2：反演匹配（神经环节②，测试侧零学图）

### 13.7.1 测试观测（修复 RCA-013）

对测试轨迹 x（仅主窗数据）：

- d_x[j] = median_t z_{x,j}(t)，**相对过程本体共享 μ/σ 的有符号偏离**（禁止自标准化）；全程不拟合任何因果模型、不引用真实标签 target；
- 激活集 A(x) = { j∈V_act : 主窗内 |z_j(t)|>3 的时间点占比 > 10% }；

- **A(x)=∅ ⇒ 强制弃权**（不进入分数比较）。

### 13.7.2 E1：marker 非零规则（FULL 条件；核销 RCA-022）

判据回到 v2.0 冻结定义：|v|>ε。**ε 按类分别计算、不共用**：ε_k = 0.1 × min_{训练轨迹} [marker_k 主窗平台中位数]（在原始量纲上；量级由数据决定，不手写数值），三个 ε_k 一次性冻结落盘（marker 不进 μ±3σ；禁止沿用首跑实现的"共享基线异常分>3"判据）。E1=正 marker 激活比例 × 负 marker 未激活比例。MASKED 条件 marker 列在测试侧删除，E1 不可用（权重归零）。

### 13.7.3 E2：分组异常模式

对 9 模板各算 0.5×越限指示 Jaccard + 0.5×有符号中位 z 余弦（变量按 V_thr∩模板变量对齐）；E2(k)=max_g；全部基于过程本体阈值（−过程本体消融时改用"轨迹窗前 30% 点的均值±3MAD"经验阈值，其余流程不变）。

### 13.7.4 E3-base：π 加权符号一致率（v2.0 冻结定义，双引擎）

对模板 (k,g)，仅在 A(x) 上：

```
E3_L(k,g) = Σ_{j∈A(x)} wL_j · 1[sign(d_x[j])=sign(cL_{k,g}[j])] / Σ wL_j,   wL_j = πL_{m,j}·gCF_j
E3_A(k,g) 同理（cA/πA）；gCF_j = R1.5 反事实门控权重（1 或 0.5）
E3_base(k) = max_g 0.5·(E3_L + E3_A)
```

### 13.7.5 E3-path：传播前沿级联（图拓扑，独立信息通道）

仅用 LiNGAM 稳定边（GAM 密图不分层）。在模板 (k,g) 上从 marker 沿稳定有向边 BFS：S1=直接下游、S2=二跳、S3=三跳；R=S1∪S2∪S3（marker 因果可达域）。

```
reach(k,g) = |A(x) ∩ R| / |A(x)|                              # 异常是否落在 marker 因果下游
depth(k,g) = Σ_{j∈A(x)∩R} wL_j/depth(j) · 1[sign(d_x[j])=sign(cL[j])] / Σ wL_j/depth(j)   # 近邻层加权符号吻合
E3_path(k) = max_g [ 0.5·reach + 0.5·depth ]
```

另计算前沿诊断量：各层异常率 r1≥r2≥r3 的违例对数（三对 (r1,r2)/(r1,r3)/(r2,r3)，取值 ∈{0,1,2,3}，**仅诊断报告，不参与任何评分**）；r3>r1（前沿倒置）时该模板 E3_path 乘 0.8 并打标（这是唯一的评分影响，且已含在 E3_path 内）。reach/depth 使用图的可达性与拓扑层级，是 Pearson/余弦在构造上无法获得的信息；−拓扑消融 = E3_path 退化为无层级的 E3_base。

### 13.7.6 融合、归一化与弃权

- 归一化（沿用 v2.0 校准协议）：E2/E3 的训练分数由轨迹级留一预测产生（被留轨迹不进签名/模板/基线），每类独立 min-max，零极差恒取 0.5 并标记；参数冻结 `calibration_params.json`；
- 融合：FULL 用 s_k=0.3E1+0.35Ê2+0.35Ê3；MASKED 用 s_k=0.5Ê2+0.5Ê3；
- E3 分量：D0 前用 E3_base；D0 后按 13.8.1 冻结结果取 base 或 path；
- 弃权（三条件任一）：A(x)=∅；max s_k<τ；s(1)−s(2)<δ；
- τ/δ：训练轨迹级留一网格搜索最大化 U=正确弃权−错误弃权−λ1·高严重度错误分类−λ2·低严重度错误分类（λ1=1,λ2=2，λ2 做 {1,2,3} 敏感性）；Normal 不参与标定。

### 13.7.7 两级签名计算协议（RCA-026）

- **最终签名**（9 模板）：13.5.2 全量 Bootstrap；
- **标定签名**（约 240 套留一）：每折每类每组单次 DirectLiNGAM + marker 列单次 GAM，不做 GAM 全对向图，拓扑层用单图边（标定只决定阈值，不决定结论）；

## 13.8 Phase R3：实验执行

### 13.8.1 D0 决策门控（D1 末，先于全量实验，半天内）

最小正确 MASKED 实验：修好的 R0/R0.5 + LiNGAM 单引擎 9 模板 100 次 Bootstrap（无 GAM）+ E2 + E3_base + E3_path（同一次学图顺带计算，仅落盘不进判据）+ B1；仅 MASKED-高严重度 18 条（6/类）。D0 时 τ/δ 尚未标定，按 argmax 原始正确性比较（不做弃权），A(x)=∅ 的轨迹移出配对子集并单独计数。

判据（配对设计）：在共同子集（A(x)≠∅，B1 恒有预测）上，逐轨迹 δ_i = 1[**纯 E3_base 通道** argmax 正确] − 1[B1 argmax 正确]（刻意不用融合分，以隔离 E3 通道相对 Pearson 的独立信息；MASKED 融合 0.5Ê2+0.5Ê3 的 argmax 正确性仅作附属数字落盘），Δ̄=mean δ_i，配对轨迹 Bootstrap（重采样轨迹，B=2000，种子 42）95% 百分位置信区间：

- **强证据**：Δ̄>0 且 CI 下界>0 → E3_base 为融合与主张句的主证据，E3_path 列 P2 机制增强；
- **方向性证据**：Δ̄>0 但 CI 跨 0 → 按预注册保守规则，**E3_path 仍升为主证据**（base 相对 Pearson 的独立性未被证明），结论注"base 方向性支持但证据不足"；
- **无证据**：Δ̄≤0 → E3_path 为主证据，E3_base 降为消融对照；
- **事前预期（统计事实，不是倾向）**：n=18 时 CI 下界>0 要求近全部 δ_i 同号，极少达到；**默认预期走 E3_path 分支**。D0 的核心价值是主证据归属的事前冻结与决策留痕，不是小样本统计区分。
- 无论哪个分支，E3_base/E3_path 两版本此后都照常计算，−base、−path 两个消融都做（13.11），D0 只决定融合分量与主张句用谁。
- 决策与当时全部数字（含子集大小 n′、逐轨迹 δ_i、Δ̄、CI、分支）落盘 `d0_decision.json`，主张句在此刻、看其余结果前写死；D0 之后不得再改 E3 选择。
- 顺延条款：若 R0 审计发现注入时刻/数据异常导致 D1 无法完成，D0 顺延至 D2 初（GAM 开跑前），**不压缩 D0 的决策与留痕时间，也不带入任何 D2 结果**。

### 13.8.2 正式实验

- 两条件：FULL（marker 可见，sanity）/ MASKED（测试侧删除 WLR/WTRA/WFLB 三列；**运行日志零访问断言**：测试特征矩阵列名集合与 marker 列表交集为空）；
- 三严重度组分别报告；指标：Overall Accuracy（弃权=错）、Selective Accuracy（接受样本）、Coverage、Abstention Rate、macro-F1（接受样本口径；**接受样本中某类为 0 时该组 macro-F1 报 N/A，并单独报告该类弃权率，禁止跨组合并填充**）、95% Wilson CI；
- **配对差值两口径分开，禁止合并**：① 共同子集口径（Full/MASKED 流水线接受且基线有预测的轨迹；B1/B2 恒有预测故=流水线接受子集），报告逐轨迹配对差值与轨迹 Bootstrap CI——这是 S2/D0 的主口径；② 全样本口径：Overall Accuracy（弃权=错）在全部 20 条/组上对照报告。两口径数字、子集大小同时呈现；
- 配对差值优先：E3 主版本 vs B1、vs B2 按轨迹配对，给差值 Bootstrap CI，不凭 CI 重叠下结论；
- B2 退化曲线（10%~90% 覆盖率）；
- Normal/1.csv：仅作弃权功能验证（不进训练/标定），三条件都报告预测与分数；
- MASKED-strict 结构消融沿用 v2.0（无 marker 重学 G_k′，只报边保留率/E2/E3 诊断量（base/path 分值分布），不比准确率；E3′ 已退役）。

## 13.9 Phase R4：基线（RCA-020 重写）

- **B0（规则上界）**：marker 非零规则，FULL only；MASKED 无定义，报告 N/A 而非 0；
- **B1（相关匹配）**：对测试窗 z 向量 d_x（V_thr，与 E2 同口径的有符号中位 z）与 9 模板组中位 z 向量 z_{k,g} 算 Pearson 相关，**B1(k)=max_g corr，再按 k 取 argmax**（与 E2/E3 的 max_g 对齐；不读测试严重度标签），无弃权；**这是检验 E3 因果增量的主要对照**（对齐论文相关性基线 Jaccard 0.33 的位置）；
- **B2（黑箱 ML）**：XGBoost，特征=窗口统计量（mean/std/min/max/mean−baseline 的 Δ、越限时间点占比），仅 V_thr，不含严重度/文件名/任何标记列；FULL 与 MASKED 各训练一版；**超参实验前冻结、禁止看结果调参**：max_depth=3、n_estimators=100、learning_rate=0.1、random_state=42（其余库默认）；报告训练集 CV；**B2 始终使用过程本体 μ±3σ 阈值构造"越限"特征，−过程本体消融只作用于 Full 流水线，B2 不随消融改口径**（否则消融差异混入基线变动）；
- 全部基线在同一 split_manifest 上运行。

## 13.10 Phase R5：两层输出与解释（神经环节③）

- 第一层：事故类型 + 三证据分 + 弃权状态（复用 v2.0 JSON 行格式）；
- 第二层（修复 RCA-019）：对接受轨迹，在判定类的 D0 指定模板上，**从 marker 出发**沿稳定边 BFS，对 A(x)∪中介变量做双引擎 RRF 排序拼链；链上每条边必须 ∈ 稳定边或 E^cons 共识边（忠实性校验，不满足则标 `ungrounded` 且不得出现在解释正文）；附 Alg3 重演支持度与本体子系统名；

## 13.14 判读纪律与局限

1. FULL 近满分是数据特性，只作 sanity；MASKED 高严重度配对差值是唯一识别增量证据；
2. E3 高相容不单独证实、低不单独证伪；物理真实性只通过 4.2 冻结关系与 Alg3 重演检验；
3. 仿真器近似确定性 + 单类 100 条是严重度扫描，20 条/类、组内 6~7 条只支持描述性结论与 CI，不做总体功效宣称；
4. 静态 DAG 不处理 WLR↔P 等反馈环，竞争边如实标注；时间点强自相关通过轨迹级 Bootstrap 缓解但未消除；
5. GAM 全对向图 10 次/模板是预算降配，E^cons 解释相应放宽，不影响 C^A（50 次）；
6. Normal 仅 1 条，弃权结论的外部效度有限；
7. 全部结论限定 LOCA/SGATR/FLB 三类、PCTRAN 仿真、主分析窗，不向真实电厂外推；
8. 本方案是借鉴论文神经符号因果分析流水线的**变体复现**（GAM-ANM 替代 DiffAN、过程本体用数据驱动 μ±3σ、代码本体替代 RDF/Neo4j），报告与标题禁用"严格复现论文"；
9. D0/S2 的配对 n=18 统计功效低：CI 下界>0 仅在极大效应下可达，未达强证据不构成"E3 无效"的证据（只能写方向性或无证据）；这是预注册时已知并接受的设计约束，不是事后放宽。

## 1. 规则（写死，不随结果调整）

| 步 | 规则 |
|---|---|
| W1 | 阶段 1 质量门**不变**：全 NaN / `σ<1e-6` / `nunique<3` / 缺失>50% / 全零 |
| W2 | 阶段 2 **不按评分截断**（`TOP_K` 不参与）；评分只用于子系统内排序 |
| W3 | 每子系统保留 **Q=2** 个代表；代表取**训练期评分最高**，同分按字母序 |
| W4 | 别名合并：**逐位相同 或 `|Pearson r| ≥ 0.999`**（union-find）；被合并列**不回流** |
| W5 | 上限 **`p ≤ n_train_trajectories`**（变量数不得超过该模板训练轨迹数）；超限只裁非 `forced`，按评分从低到高，落 `cap_trimmed` |
| W6 | 契约：**`15 ≤ p ≤ n_train_trajectories`** |

**W5 作废"总量上限 30"的原因**：变量数超过训练轨迹数时，协方差估计奇异，DirectLiNGAM 进入欠定区、解不唯一。
LOCA 的保护集本身已 24，加 forced/锚定后触顶 30，而每模板训练轨迹只有 25–28——上限 30 已越过轨迹数，
与本方案自己给出的"每模板 25–28 条"直接冲突。故取消"30"，改由轨迹数兜底。

**Q=2 的依据（只有两条）**
1. `p` 受训练轨迹数约束：每模板仅 25–28 条轨迹，`p` 接近或超过轨迹数时 VIF/协方差估计不稳定（W5 即由此而来）；
2. 物理：每个子系统至少保留 2 个独立测点，才能表达"源→响应"的方向约束。

## 2. 数据质量闸

| 闸 | 判据 | 命中处理 |
|---|---|---|
| 闸一 | 相关矩阵出现**负特征值**（`min_eig < -1e-8`） | `degenerate_design=true` → 退回 v23（p=15）→ 披露"该类未采用 wide" |
| 闸二 | 相关矩阵**有效秩 < p**：SVD 奇异值容差 `sv > max_sv · p · eps`，秩不足即命中（**替换原 `cond > 1e12`**） | 同上 |

- 命中即退回，**不得调阈值重试**；
- `cond` 只作记录，不再作为闸；
- 各类 `p` 因此可能不同，必须逐类披露，不得写成统一 `p`。

## 3. 真值处理

- 真值表**一字不改**；`n_gt_distinct` 保持原值；
- 别名只做**候选层合并**并留 `alias_of`；
- 指标 **strict 与 alias_aware 双报**（后者仅把别名成员映射到代表后另算）。

## 4. 验收口径

**不再用自定阈值做通过/不通过**。做法是与 `v23-20261112T185258` 做**同模板两档直接对照**，三组量：

1. **结构健康度**：`cond(I−B)` 截断前/后、稳定边数、`max|w|`、`clip_ratio`；
2. **边集稳定性**：`f_e`、`dir_e` 的中位数与低分位（P10），以及与基线的稳定边集合重合度；
3. **机理性**：K3 覆盖率、K2 违反/不可判比例、S/P 条目与 Top-5 的一致/冲突数。

方向不一致就**并列**，不平均、不做总判。

**披露项（不计入判定，任何诊断档都不得计入通过）**
- "同一别名家族 Top-5 ≤1 席"：别名合并后每族只留 1 个代表，**结构性恒真**；
- "符号相反大系数对"：所扫的正是候选层已合并的同类成员，**近乎恒真**。

## 7. 结论

- **wide 当前不升主线。**
- 可验证收益为零：机理性覆盖率**全线下降**（K3：LOCA 0.40→0.00 / 0.40→0.20 / 0.20→0.20；SGATR 0.2857→0.1429 /
  0.2857→0.1429 / 0.4286→0.2857），未见任何一项反向改善。
- 可比性存在结构性风险：按组重选变量使**同模板新旧不可比**（low 组变量集与基线只重合 8/15），
  且 LOCA_low 直接回退，等于没有宽放。
- wide 保留为**诊断档**，用途限定为回答"**某变量是否被筛选漏斗挡掉**"；不进入论文数字、不与
  `v23-20261112T185258` 并排作同一候选集比较。

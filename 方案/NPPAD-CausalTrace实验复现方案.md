# NPPAD × CausalTrace 实验复现方案

> **数据集**：NPPAD（清华大学核能与新能源技术研究院，PCTRAN 仿真）
> **论文**：CausalTrace: A Neurosymbolic Causal Analysis Agent for Smart Manufacturing (AAAI-26)
> **核心问题**：在 LOCA 仿真数据上，静态 LiNGAM 能否稳定地恢复一组预先定义、具有明确物理依据的变量关系？
> **周期**：一周（LiNGAM 路线，聚焦 LOCA 单事故类型）
> **定位**：方法迁移与适配，非原论文严格复现
> **范围与扩展**：本方案仅在 LOCA（热段失水）一类故障上验证；算法流水线按"事故类型无关"设计，后续扩展到其他事故时复用同一套算法、只替换物理约束层，复用矩阵与扩展路径见第十四节。

## 二、研究任务定义（关键边界）

### 2.1 任务：上游因果定位（非根因溯源）

**给定异常目标变量 P，定位其因果上游变量，验证因果图能否恢复已知物理机制。**

### 2.2 关键科学问题：WLR 与 P 的双向耦合

LOCA 中 WLR（泄漏流量）与 P（一回路压力）存在**动态反馈耦合**：
- P 驱动 WLR：压力越高，破口喷放流量越大
- WLR 降低 P：冷却剂泄漏导致一回路失压

这是动态环，静态 LiNGAM（DAG 无环）会随机选一个方向。因此：
- **不预设 WLR→P 为唯一正确方向**
- LiNGAM 学出 P→WLR 也不算错
- 将 WLR↔P 作为**竞争假设**报告

> **2026-10-25 实测（严重度 1/25/50/75/100% 抽样一致）**：事故注入时刻约为 **t=110s**（WLR 首次非零，10s 采样分辨率下落在 100~110s 之间），WLR 在 t≈200s 已接近早期峰值。这意味着原主窗口 t=300~1500s **排除了注入突变与 WLR 上升沿**，分析对象是"事故发展期的静态响应关系"，不是事故触发与早期传播。
>
> **主窗口的一个实测代价**：1% 破口在 t=300s 时 P 已恢复至 154 bar、t=1500s 为 157 bar（高于初始 155.5 bar，补偿系统作用），WLR 稳定在 ~34 t/h——低严重度下 WLR↔P 的瞬态耦合在主窗口内已基本结束，学不出该方向不代表机制不存在。中高严重度在主窗口内仍持续失压（如 75%：P 61→38 bar）。此差异必须在结果中如实报告。

### 2.3 Ground Truth 的建立方式

通过**已知物理机制**验证，每条待检验关系标注依据来源和证据等级（见第三节）。**实验前冻结候选关系，不事后改写以符合预期。**

## 四、关键问题与解决方案

### 问题一：数据量级与训练方式

主线采用 **LiNGAM + GAM-ANM 双引擎**。LiNGAM 为非训练型统计因果发现；GAM-ANM 以 GAM 拟合替代完整 DiffAN（理由见 13.7）。不因原始 CSV 比预期长就盲目上扩散模型——独立样本单位是 100 条轨迹而非数万时间点，p≈14 用不上 DiffAN 的扩展性。

### 问题二：特征选择（双变量集策略）

#### 主变量集（物理先验，固定，不碰标签）

基于第三节变量表，选 ~20 个变量。**最终变量集需经数据审计后确定**。

#### 对照变量集（XGBoost，仅作消融对照）

以事故类型为标签训练 XGBoost 选 Top-15，检验标签泄漏风险。**主实验使用物理先验变量集。**

### 问题三：物理先验约束（非神经符号）

> 仅使用数据驱动阈值和有限方向约束，命名为**物理先验约束**。**物理约束放在最后作为消融实验**，先看纯数据驱动结果。

#### 约束一：数据驱动异常阈值（探索性）

```
取 Normal 工况数据，计算 μ 和 σ
异常阈值 = [μ - 3σ, μ + 3σ]
```

> Normal 仅 1 条轨迹，此为探索性阈值。**仅用于确定异常目标变量 P，不用作上游变量的硬过滤门槛。**

#### 约束二：因果方向约束（分三类）

> **原则**：禁止边只用于有**明确物理排除依据**的关系，并记录依据来源。**没有找到证据 ≠ 证明不可能**，不熟悉或暂无资料的关系归入未知边。

| 类别 | 处理方式 | 示例 | 依据要求 |
|------|---------|------|---------|
| **禁止边** | 明确物理依据排除 | 辐射(RM1)→温度(TAVG)，剂量(DTHY)→压力(P) | 必须记录物理依据来源 |
| **允许边** | 符合已知机制 | 一回路温度(THA)→蒸发器压力(PSGA) | 记录机制依据 |
| **未知边** | 不裁剪，由数据决定 | WLR↔P（双向耦合，不预设） | 无需依据 |

## 五、核心实验流水线

```

    │
    ▼
[Phase 0] 数据审计 + 变量集确定 + 标准化
    │
    ▼
[Phase 0.5] ★ 神经符号层构建：极简核电本体 + 数据驱动异常阈值
    │  知识图谱层（变量→子系统→物理关系）+ 过程本体层（LOCA_1 准稳态段阈值，探索性）
    ▼
[Phase 1] 因果发现双引擎：LiNGAM + GAM-ANM（忠实于论文 LiNGAM/DiffAN 并列设计）
    │  LiNGAM：线性/非高斯可辨识，产出线性邻接矩阵 B
    │  GAM-ANM：非线性 ANM 可辨识，产出方向判定 + 边际效应（用 GAM 替代完整 DiffAN）
    │  核对矩阵索引方向（用两变量简单例子验证）
    ▼
[Phase 1.5] ★ 神经符号环节①：本体约束因果发现

    ▼
[Phase 2] ★ Algorithm 1：Bootstrap 四指标稳定性（双引擎各自独立）
    │  训练集轨迹级抽样；f_e + s_e + 方向一致率 + 符号一致率
    │  + 按严重度分组检查边方向一致性
    ▼
[Phase 3] ★ Algorithm 2：总因果效应量化（双路径）→ 融合排序
    │  LiNGAM 路径：T_k=(I-B_k)⁻¹（每次 Bootstrap 独立求逆）→ 线性总效应排序
    │  GAM-ANM 路径：GAM 拟合 P=f(X) → 平均边际效应 |dP/dX| → 非线性效应排序
    │  融合：RRF 合并两排序；共识边合并方向（见 Phase 3.1/3.2）
    ▼
[Phase 3.5] ★ 神经符号环节②：异常变量标记（探索性增强排序）

    ▼
[Phase 4] 上游定位评估（核心关系 + 辅助关系分开报告）
    │
    ▼

    │
    ▼
[Phase 5.5] ★ 神经符号环节③：解释生成
    │  因果图提示注入 + 本体知识 → 自然语言根因解释

```

> **★ 标注神经符号必选环节**：Phase 0.5（构建）、Phase 1.5（因果发现约束）、Phase 3.5（异常标记）、Phase 5.5（解释生成），对应论文神经符号三环节落地。

### Phase 0：数据审计清单（不假设数据结构）

**结构与列校验（硬性，程序启动时自动执行）**：
- [ ] 按表头名访问变量，核对 96 个参数列齐全、列名唯一（CSV 顺序 ≠ Table 2 ID，见 1.2）
- [ ] TIME 严格递增、采样间隔严格为 10s；核对每条轨迹在主窗口内时间戳恰为 300,310,…,1500（121 点），无缺行/重复行
- [ ] 缺失值统计；**识别并剔除常量列**（实测 1% 有 25 个、100% 有 18 个），记录剔除清单；检查异常数值（NaN/Inf）
- [ ] 全量 100 条轨迹核对：文件名 1~100 与严重度一一对应（已实测编号连续）

**LiNGAM 模型假设诊断——非高斯性（低成本，必做，但不作为算法开关）**：
- [ ] 对每个入模变量记录偏度（skewness）、超额峰度（excess kurtosis），画直方图 / QQ 图；可附 Jarque–Bera 等正态性检验结果
- [ ] **检验口径警告**：堆叠后的 12,100 个时间点不是独立样本（同轨迹强自相关，见 3.4），JB 等检验的 p 值**不能按"N=12,100 个独立观测"解释显著性**；检验结果仅作分布形态的描述性证据，必要时辅以按轨迹（或按严重度组）分别计算的偏度/峰度交叉核对
- [ ] 关键变量（P、WLR、VOL、TAVG 等）的分布按**严重度组（低/中/高）× 时间阶段（早期 110~300s / 发展期 300~1500s）**分别观察，记录分布形态是否随组、随阶段变化
- [ ] 报告中明确：以上是**模型假设的诊断证据，不是 LiNGAM 方向可辨识性的完整证明**——观测变量非高斯 ≠ 方向必然可辨识；即使非高斯性明显，时间依赖、WLR↔P 反馈环、机制异质性仍可能破坏静态 LiNGAM 的适用条件
- [ ] **不设"通过正态性检验才运行 LiNGAM"的硬门槛**：诊断不改变主算法（静态 LiNGAM）选择，只影响结果解读的保守程度与局限措辞；方向输出的可信度最终仍由 Bootstrap 稳定性、严重度分组一致性与物理对照共同刻画

**轨迹与阶段可视化**：
- [ ] 对低(1-33)/中(34-66)/高(67-100)三组各抽 ≥3 条，画 0~结束的全轨迹图，按四段标注：事故前(0-110s) / 早期(110-300s) / 发展期(300-1500s) / 后期(>1500s)
- [ ] 画 P、WLR、VOL、LVPZ、TAVG、WHPI 轨迹图，确认变化发生时间与注入时刻（实测约 110s）跨严重度一致
- [ ] 标注各条轨迹仿真终止时刻（实测 3420~4740s，非严重度单调：50% 仅 3420s、75% 为 4560s），确认均覆盖主窗口

**严重度异质性（必做，非可选检查）**：
- [ ] 比较三组在主窗口内的响应形态与数值范围。**实测预警**：WLR@300s 跨严重度非单调（25%≈373、50%≈181、75%≈243、100%≈367 t/h），反映不同破口尺寸下 t=300s 处于不同喷放物理阶段（亚冷/两相、卸压程度不同）；P 在 1% 组恢复、中高组持续下降
- [ ] 输出《严重度异质性审计小结》，作为 Phase 2 分组学图的输入；响应幅度/形态不同不预设因果结构不同，是否不同由分组学图实证判断

**Normal 轨迹专项**：
- [x] 画 Normal/1 全轨迹：实测 PWNT 由 100% 降至 40%、TAVG 310→299°C，是功率漂移轨迹而非稳态；**与 LOCA 100% 功率演化不匹配，无法用作阈值基准**
- [x] 改用 LOCA_1 准稳态段（t=520~2030s，100% 功率）建阈值，排除故障变量和常量变量，9/14 变量获得可信阈值

> **不混用变功率场景**：原始 LOCA 与 Variable_Power_Data/LOCA_* 的时间窗口、注入时刻不同（后者仅有 mdb，注入时刻见其 manifest.csv：升功率 2298.5s、降功率 915s）。本次实验不使用，避免 mdb 转换工作量。

### Phase 0：标准化策略

- **主分析保留全局 Z-score 标准化**：在训练集轨迹上对每个变量减均值、除标准差；μ、σ 仅在训练集上**一次性估计**，验证集与 Bootstrap 各轮沿用同一口径（不得在重采样子集上各自重新估计，避免口径漂移与信息泄漏）
- 总效应在**标准化尺度**下报告；物理解释时需转换回原始单位
- 不同变量量纲不同（bar、t/h、°C），不标准化无法比较效应强度

> **重要（2026-10-25 辩证修订：保留全局标准化，但明确其边界）**：
> 1. **标准化不制造、也不消除严重度混杂**：严重度对 P 等变量的影响在原始数据中已经存在；逐变量的固定线性变换（减常数、除常数）不会新增或删除关联。它只解决量纲与尺度问题，**不控制混杂**，也不改变不同严重度下的响应形态差异。
> 2. **不改用轨迹内 Z-score 作为主方案**：每条轨迹减自身均值、除自身标准差，会压掉轨迹间的绝对水平差异——而"1% 组 P≈155 bar、100% 组 P≈50 bar"这类水平差异**本身就是事故严重度的物理表现**；轨迹内标准化还会放大小破口准稳态轨迹（如 LOCA_1 在主窗口 P 仅在 154~157 bar 内缓变）中的微小波动，制造虚假的相对变化。因此全局标准化维持主方案地位，也不把轨迹内标准化预设为"更正确"。
> 3. **配套必做检查**：审计阶段按严重度组输出各变量标准化前后的分布与取值范围，确认全局标准化未造成组间分布的意外坍缩或放大。
> 4. **敏感性分析（扩展项，不作为主结论依据）**：时间允许时用轨迹内（或组内）标准化重跑主流程，只比较关键边方向与上游排序的变化；两种口径结果不一致时，作为稳健性问题如实报告，**不据此挑选"更好看"的版本**。
> 5. 严重度混杂仍由严重度分组检查（Phase 2）处理，分组只能缓解、不能彻底消除（见 Phase 2 限定）；同轨迹时间点的自相关不因标准化而消失，**伪重复风险与严重度异质性风险分别报告**（见 6.1 的 2a/2b）。

> **初始状态检查**：数据审计时比较各轨迹的初始状态（t=0 时刻变量值）。若初始状态差异大，模型可能把初始差异当成事故过程中的变量关系。

### Phase 0：数据处理实现原则

> 每条轨迹独立完成清洗与变量检查，再按预先规定的规则汇总训练数据。**不得跨轨迹计算差分或构造滞后变量**；所有数据划分均以**轨迹为单位**，确保同一条轨迹的时间点不会同时进入训练集和验证集（避免轨迹泄漏）。

### Phase 0：数据划分与执行顺序（防止验证集信息泄漏）

**核心原则：模型选择（学图、Bootstrap、确定稳定边及阈值）只能使用训练集；验证集仅用于最终的一致性比较（Algorithm 3）。**

执行顺序必须严格如下：

1. **先划分**：在数据审计完成后、任何模型拟合之前，以轨迹为单位划分训练集（80 条）和验证集（20 条）。划分结果在实验前固定并记录。
2. **仅用训练集拟合**：
   - 标准化参数（μ、σ）从训练集计算；
   - LiNGAM 拟合、Phase 1.5 本体约束、Phase 2 Bootstrap（含四指标统计、稳定边筛选、阈值确定）全部只在训练集上完成；
   - 最终的稳定边图和总效应分布均来自训练集。
3. **应用到验证集**：将已确定的模型结构（稳定边集）和标准化参数应用到验证集，仅用于 Algorithm 3 的一致性比较（ΔP_pred vs ΔP_obs）。
4. **严重度分组分析**：作为独立的稳健性检查，可使用全体 100 条轨迹按严重度分组学图，但必须明确标注"此分析使用了全体数据，不参与训练/验证划分"，其结果不作为主结论的统计依据，仅用于方向一致性的定性判断。

> **反例（禁止）**：先用全部 100 条轨迹完成 Bootstrap、筛边、选阈值，再从中划出 20 条当验证集——此时验证集已参与模型选择，一致性比较不再独立。

### Phase 0：时序处理与窗口选择

**主窗口：t=300s~1500s（121 点/轨迹，10s/步含端点）**。这是主动选择，不是数据长度限制（原始 CSV 到 3420~4740s）。选择依据（2026-10-25 实测）：

1. 100 条 LOCA 轨迹在该窗口内时间戳完整且等长（已抽样 1/25/50/75/100% 验证均为 121 点），拼接后每条轨迹权重一致；
2. 避开 t≈110s 的注入突变与 110~300s 的 WLR 快速上升沿——该阶段共同阶跃/趋势最强，静态 LiNGAM 最容易把时间趋势误判为因果边；
3. 研究对象明确为**事故发展期变量间的静态响应关系**，不声称覆盖事故触发与早期传播。

**代价（必须接受并报告）**：
- 低严重度（1%）在该窗口 P 已恢复、WLR 平稳，WLR↔P 早期瞬态信号弱，学不出该边属预期；
- 丢失因果链随时间传播的信息。

**早期阶段对照（时间允许时做，不作为主线）**：用 t=110~600s 窗口跑同一套流程，与主窗口结果分开报告、不混用指标。该窗口非平稳性更强，结果仅作阶段差异的定性对照，用于判断主窗口结论是否依赖所选阶段。

- **局限性（不因窗口选择而消失）**：相邻时间点强自相关，不满足 LiNGAM i.i.d. 假设；轨迹级 Bootstrap 不消除轨迹内自相关。
- **窗口冻结规则**：最终边界以 Phase 0 全轨迹曲线图确认为准；审计后若调整窗口，必须记录调整理由并重做全部下游分析，禁止看到结果后再选窗口。
- **记录要求**：每条轨迹 ID、时间范围、严重度、重采样抽取了哪些轨迹、每次的图结构和边权。

#### 0.5.2 过程本体层：基于 LOCA_1 准稳态段的数据驱动异常阈值

论文使用专家定义的 cycle-aware 传感器公差范围。本方案用数据驱动方式近似，
**功能上对应论文过程本体的公差范围，但统计效力远低于专家定义的公差**：

```

原方案：对 Normal 工况数据（仅 1 条轨迹）按时间段分组算 μ_segment, σ_segment

```

> **定位声明**：此阈值是**探索性异常评分**，**不是经过验证的正常运行容差**。
> 原因：基准数据来自 LOCA_1 恢复段（仍有小破口泄漏），仅 1 条轨迹，
> 且同一条轨迹内的时间点具有强自相关，μ±3σ 的统计覆盖含义不充分。

> **【2026-10-25 关键修订：Normal 与 LOCA 功率演化不匹配】**
> 实测发现 Normal/1.csv 是 100%→40% 降负荷轨迹，与 LOCA 事故的 100% 功率
> 演化完全不对应（Normal: PWNT 100%→40%；LOCA: 维持 100% 或迅速停堆到 ~2%）。
> 用 Normal 建的阈值去判 LOCA 异常，功率相关变量会全部误报。
>
> 因此改用 LOCA_1 的 100% 功率恢复段作为准 Normal 基准：
> - LOCA_1 在 t=520~2030s 期间 PWNT≈100.8%、P≈157.1 bar，所有热工变量 CV<0.5%
> - 功率水平 100%，与 LOCA 事故初始功率一致
> - 变量名、采样率、仿真器完全一致，无对齐问题
> - 比 Normal 轨迹的 100% 功率段（仅约 10 个点）多 15 倍样本
>

> 1. 排除故障/安全系统变量（WLR 泄漏流量、WECS 安注流量、WHPI 高压注水），

> 2. 排除稳态段标准差极小（σ<1e-6）的常量变量（如 WRCA），无法估计波动范围；

>

> **Phase 3.5 异常标记整体标记为"数据不支持"并退出**，主排序（纯总因果效应）
> 与核心结论不受影响。不得为跑通神经符号流程而硬造阈值。
>
> **与论文 cycle-aware 公差的关系**：二者只是功能上的近似对应。论文的公差

### Phase 1：因果发现双引擎 —— LiNGAM + GAM-ANM

> 忠实于原论文"LiNGAM/DiffAN"并列的因果发现引擎设计。两种算法基于不同可辨识性假设，并行运行，结果通过共识边 + RRF 融合（见 Phase 3.2）。不指定单一算法为"主图"。

**引擎 A：LiNGAM（线性/非高斯可辨识）**
- 基于非高斯性辨识方向，产出线性邻接矩阵 B
- 这是 Algorithm 2 中 T=(I-B)⁻¹ 的唯一线性 B 来源

**引擎 B：GAM-ANM（非线性 ANM 可辨识，替代完整 DiffAN）**
- 基于非线性函数 + 加性噪声辨识方向，用 GAM（广义加性模型）成对拟合
- 产出：方向判定 + 平均边际效应 |dP/dX|（非线性效应强度）
- 选用 GAM-ANM 而非完整 DiffAN 的理由见第十三节 13.7

**矩阵索引核对（实现前必做）**：
- LiNGAM 输出矩阵中哪个元素代表 X→Y
- T[Y, X] 是否确实表示 X 对 Y 的总效应
- 用链式结构核对直接效应与间接效应之和

### Phase 1.5：神经符号环节①——本体约束因果发现

> 对应论文"因果发现环节：数据驱动学图 + 符号知识约束"。

对 Phase 1 学到的因果图，用 Phase 0.5 构建的本体施加约束。**关键原则：本体确认一条边合理，不代表数据已经发现这条边；允许边不得强行添加进图。**

| 本体关系类型 | 约束操作 | 示例 |
|------------|---------|------|
| **禁止边** | 从数据学习结果中删除该有向边；记录物理依据来源，并保存删除前后的图差异 | 删除 RM1→TAVG、DTHY→P |
| **允许边** | **若数据已学到该边**，标记为"本体支持"（不改变其权重）；**若数据未学到，不强行添加** | 数据学到 THA→PSGA 则标记，未学到则不添加 |
| **未知边** | 不施加方向约束，完全保留数据驱动结果 | WLR↔P 双向均由数据决定 |

**注意**：
- 禁止边必须有明确物理排除依据（记录来源），无证据的关系归入未知边
- 允许边只标记不添加，确保最终图中每条边都可追溯到数据来源，避免先验关系人为注入导致"看似更符合物理规律，实则无法判断是 LiNGAM 学到的还是规则加进去的"
- 约束施加在 Algorithm 1 稳定性筛选之前，避免不稳定的禁止边干扰
- 物理约束作为消融实验对比：报告无约束图 vs 有约束图的差异，并单独列出被禁止边删除的边、被标记为本体支持的边

### Phase 2：Algorithm 1 — Bootstrap 四指标稳定性

> **数据范围**：Bootstrap 仅在**训练集轨迹**上进行（见 Phase 0 数据划分）。验证集不参与 Bootstrap 和阈值确定。

```
对训练集的 80 条轨迹：
  重复 N=100 次：
    有放回抽取 80 条轨迹（轨迹级别抽样，从训练集中抽取）
    拼接轨迹时间点，跑 LiNGAM，得 G_k 及边权 w_k
  对每条有向边 e（如 X→Y）：
    f_e = 边 X→Y 出现次数 / N                              （有向边出现频率）
    σ_e = 边 X→Y 出现时的边权标准差
    s_e = 1 / (1 + σ_e)                                    （边权稳定性，自定义指标）
    方向一致率 = X→Y 出现次数 / (X→Y + Y→X 出现次数)         （分母=该变量对至少有一条边的重复数）
    符号一致率 = 边权符号占多数的次数 / 边 X→Y 出现次数       （分母=该有向边出现的重复数）
  保留条件：f_e ≥ 0.5 且 s_e ≥ 0.6（初始阈值，需敏感性分析）
```

> **指标口径说明**：
> - f_e 分母是 N=100（全部重复）
> - 方向一致率分母是"该变量对至少出现一条有向边的重复次数"，若变量对很少连边，方向一致率可能因分母小而虚高，需同时看 f_e
> - s_e = 1/(1+σ_e) 是**自定义稳定性指标**，不具有普适概率或置信度含义，受权重尺度影响
> - 阈值 f_e≥0.5、s_e≥0.6 为初始设定，最终报告不同阈值下主要结论是否改变

> **f_e 的统计解释限定（2026-10-25 定稿前修订）**：f_e **不是**因果正确概率，也**不是**边的置信度。其变异来源必须如实理解：
> - DirectLiNGAM 对固定数据是**确定性算法**（无拟合随机性）；且每个严重度只有**一条**仿真轨迹。因此每次重采样中，轨迹 i 入选与否等价于"严重度 i 是否出现在训练集"——f_e 的变异**几乎全部来自训练集严重度构成的变化**，而非"同一分布上算法的重复拟合波动"。
> - 因此 f_e 的正确读法是：**该边对轨迹重采样（即严重度构成变化）的敏感程度**。f_e 高 = 边在多种严重度构成下都出现，是有价值的稳健性证据，但仍可能是所有严重度共享的遗漏混杂所致；f_e 低 = 边依赖特定严重度构成。
> - 报告中必须分开陈述两类稳健性：**①重采样稳定性**（边是否随轨迹抽样而消失，看混合 f_e/s_e）；**②严重度稳健性**（边方向是否在低/中/高组间一致，看分组结果）。两者回答不同问题，不得互相替代或合并表述。

> **★严重度异质性检查（2026-10-25 提升为关键稳健性检查，与轨迹级 Bootstrap 同级必做，依据 Phase 0 审计小结）**
>
> **为什么要提升**：主窗口 300~1500s 内，不同严重度轨迹可能处于完全不同的系统状态——1% 小破口逐渐趋稳（P 已恢复），100% 大破口仍在持续恶化（P 69→44 bar）。把准稳态与非平稳瞬态混在一起做静态因果发现，可能得到一张**不代表任何单一严重度组**的混合图。这不简单等于"违反 i.i.d. 中 identically distributed 就必然失败"，但混合图的解释边界必须由分组结果来界定。
>
> **两类结果必须分开陈述（预注册，实验前冻结）**：
> - **混合主分析图**：100 条轨迹（80 条训练轨迹）混合学习的结果，描述"在当前严重度构成与主窗口下，算法得到的整体结构"——不自动外推为所有严重度的共同机制；
> - **严重度分组稳健性结果**：低(1-33)/中(34-66)/高(67-100)三组在训练集内**分别**学因果图并统计主要边，用于界定混合图中哪些关系跨组成立。
>
> **分组结果的三条解释规则（实验前冻结，实验后不得按结果改写）**：
> 1. **方向一致** → 报告为"跨严重度具有一定稳健性的候选关系"（注意：仍只是候选，不是因果为真的证明）；
> 2. **方向翻转** → 如实报告异质性，**不强行从两个方向中选出一个**作为主结论；混合图中该边降级标注；
> 3. **某组无法稳定估计**（如组内 f_e 普遍过低）→ 报告"该组证据不足"，**不得把缺失结果解释为该组不存在此因果关系**。
>
> **实测预警（2026-10-25）**：三组在主窗口内可能处于不同喷放物理阶段，WLR 数值跨严重度非单调（25%≈373 > 100%≈367 > 75%≈243 > 50%≈181 t/h），P 在低组恢复而中高组持续下降——**响应幅度/形态不同不预设因果结构不同，反之亦然**，是否同构以分组学图的边方向与频率实证判断。
>
> **分组结果的能力边界（必须随结果一起声明）**：
> - 分组后每组仅约 27 条独立轨迹（80 训练划分下约 21~22 条），**有效样本量下降，分组结果不一定比混合结果更准确**；它的价值是**揭示异质性、界定混合图解释边界**，而不是保证恢复真实因果图；
> - **分组不彻底消除混杂**：严重度是已观测的轨迹级协变量（文件名即标签，不是未观测变量），但组内仍有连续严重度梯度、每个严重度仅一条轨迹、无法估计同严重度下的仿真随机波动；分层学图是当前可行的最佳控制，不宣称其产出"已调整严重度的因果效应"；
> - **轨迹级 Bootstrap 与分组检查解决的是两种不同风险，须分别报告**：前者防"同轨迹时间点当独立样本"的伪重复，但**不消除**单条轨迹内部的时间自相关；后者揭示严重度机制异质性。二者都不构成对 WLR↔P 反馈环（动态性）的解决。

> **分层 Bootstrap 敏感性分析（可选，低成本，不改算法）**：在低/中/高三组内**分别**有放回抽样（保持每组每次入选轨迹数恒定，如按训练集 80 条的组内比例），使每次重采样的严重度构成固定。将分层 f_e 与混合 f_e 对照：二者接近说明边的出现主要不依赖组间构成；差异大则该边的混合 f_e 受构成波动主导。注意分层抽样**不消除组内梯度**，结论口径仍受上述限定。列入 Day 5/扩展实验，不升级为必做项。

### Phase 3：Algorithm 2 — 总因果效应量化（双路径）与融合排序

Algorithm 2 的核心是 T=(I-B)⁻¹，但该公式要求线性邻接矩阵 B，**仅 LiNGAM 能提供**。GAM-ANM 不产出线性 B，因此量化分两条路径，最终融合：

#### 3.1 路径 A：LiNGAM 总效应（T=(I-B)⁻¹）

**矩阵求逆是非线性操作，不能先平均边权再求逆。** 总效应必须按以下口径计算：

1. **每次 Bootstrap 独立计算总效应**：对 Phase 2 中第 k 次 Bootstrap 得到的完整 LiNGAM 系数矩阵 B_k，独立计算 T_k = (I - B_k)⁻¹。不预先对 B_k 取平均。
2. **汇总 T[P, X] 的分布**：对每个候选上游变量 X，收集 N 次 Bootstrap 的 T_k[P, X]，报告：
   - 中位数（作为点估计）
   - 25%/75% 分位数区间（作为不确定性）
   - 符号一致率（T[P,X] 为正/负的次数占比，与 Phase 2 符号一致率对应）
3. **稳定边图的总效应（仅作展示）**：对 Phase 2 筛出的稳定边图（仅保留稳定边、其余边权置 0 的稀疏矩阵 B_stable），可额外计算一次 T_stable = (I - B_stable)⁻¹，作为简化后的展示结果。**但不得将 T_stable 与 Bootstrap 总效应分布混为一谈**——B_stable 经过阈值筛边，结构已改变，T_stable 不代表模型的真实总效应分布。

> **禁止做法**：先把 N 次 Bootstrap 的边权简单平均得到 B̄，再求逆 T̄=(I-B̄)⁻¹ 作为唯一结果。由于求逆非线性，T̄ ≠ median(T_k)，且边权平均会引入不存在的虚假边结构。

#### 3.2 路径 B：GAM-ANM 边际效应 + 双引擎融合

**GAM-ANM 不产出线性 B，因此不参与 T=(I-B)⁻¹ 计算。** 它通过另一条路径提供非线性效应证据：

1. **非线性效应量化**：对每个候选上游 X，用 GAM 拟合 P = f(X) + ε，取平均边际效应 |dP/dX| 作为非线性效应强度排序。
2. **边方向融合**：对 LiNGAM 与 GAM-ANM 各自稳定边集做三分类：
   - **共识边**：两方法都识别且方向一致 → 可信度最高
   - **冲突边**：变量对相同但方向相反 → 标记不确定，谨慎解释
   - **单边**：仅一方法识别 → 按可辨识性假设解读
3. **排序融合（RRF）**：用 Reciprocal Rank Fusion 合并 LiNGAM 总效应排序与 ANM 边际效应排序：
   ```
   score(X) = 1/(k + rank_LiNGAM(X)) + 1/(k + rank_ANM(X))，k=60
   ```
   两方法都排前的变量得分最高；RRF 融合排序作为**主 RCA 输出**，LiNGAM 与 ANM 各自排序作为子结果透明报告。

> **关键声明**：融合不是"把两方法的 B 矩阵加权后求逆"——不存在统一的线性 B_fused。融合发生在**排序层**（RRF）和**边方向层**（共识/冲突），不发生在矩阵求逆层。这是忠实于 Algorithm 2 公式与 GAM-ANM 非线性本质的必要妥协。

#### 3.3 上游排序报告口径

```
主排序（RRF 融合）：基于 score(X) = 1/(k+rank_L) + 1/(k+rank_A) 降序
子排序（透明报告）：
  - LiNGAM：|median(T_k[P, X])| 降序（含 median_T、Q25/Q75、符号一致率）
  - GAM-ANM：|avg_marginal_effect| 降序
对每个候选 X 同时报告：
  - LiNGAM 有符号总效应中位数（物理方向）、25%/75% 分位数、符号一致率
  - GAM-ANM 平均边际效应
  - 共识/冲突/单边归属
  - 变量自身异常程度（Phase 3.5，仅作增强排序，不并入主排序）
```

> **声明**：RRF 融合排序是本方案对论文"两算法并列但未说明如何结合"这一空白的填补设计，非论文原公式。

### Phase 3.5：神经符号环节②——异常变量标记（探索性增强排序）

> 对应论文"RCA 环节：总因果效应 + 公差范围筛选异常变量"。
> **公差来自数据驱动而非专家，是适配设计；异常程度加权仅作探索性增强排序，不作为主排序依据。**
> **【2026-10-25 修订】阈值基准从 Normal 分段改为 LOCA_1 准稳态段（见 Phase 0.5.2）。**

用 Phase 0.5.2 构建的 LOCA_1 准稳态段阈值，对事故后窗口内的变量进行异常标记：

```
对目标变量 P 和候选上游变量 X：
  检查 X(t) 是否超出 [μ - 3σ, μ + 3σ]（全局阈值，不按时间分段）
  异常程度 = max(0, |X(t) - μ| - 3σ) / σ
  异常持续时间 = 连续超出阈值的时间步数量

注：μ, σ 来自 LOCA_1 准稳态段（t=520~2030s，100% 功率）
    故障变量（WLR/WECS/WHPI）无阈值，LOCA 中非零即异常
```

**主排序（必须报告）**：
- 上游排序分数 = |T[P, X]|  （纯总因果效应，不引入异常程度）
- 这是主结果，所有消融实验和核心结论基于此排序。

**增强排序（探索性，作为消融实验，不并入主结论）**：
- 增强分数 = |T[P, X]| × (1 + α × 异常程度_X)
- α 为异常程度权重（初始 0.3），对 α ∈ {0, 0.1, 0.3, 0.5, 1.0} 做敏感性分析。
- 报告纯总效应排序与增强排序的排名变化（Kendall τ 或 Top-K 重合率）。
- 若候选变量自身无异常但总效应大，仍保留（可能是隐性根因）。

> **声明**：α=0.3 是工程经验值，非理论推导；异常程度可能与事故严重度共同变化，
> 加权后排名提高不一定意味着变量更接近真实根因。因此主排序始终使用纯总效应，
> 增强排序仅用于检验异常标记是否提供增量价值。若增强排序与主排序差异大且无物理解释，
> 则不采用异常加权。

### Phase 5：Algorithm 3 — 一致性比较（探索性，非核心成败标准）

> **定位**：Algorithm 3 是模型—观测一致性的描述性检查，**不是因果效应验证**，也不是实验成败的判断标准。若预测差异接近零，不等于模型验证失败。

> **双向处理**：若 LiNGAM 学到的是 P→WLR，则 T[P,WLR]（WLR→P 的总效应）可能为零，此时 ΔP_pred≈0。这是模型选择了竞争方向的自然结果，需如实报告，不强行解释。

#### 基础版：模型总效应与观测组间差异的一致性比较

```
以 WLR↔P 为例（报告两个方向）：
  训练集：学因果图，得 τ = T[P, WLR]  （标准化尺度）
  验证集（独立，用训练集的标准化参数转换）：
    a₁ = Q₁(WLR_std)，a₂ = Q₃(WLR_std)     （标准化后的 WLR 分位数）
    ΔP_pred = (a₂ - a₁) × τ                 （标准化尺度）
    ΔP_obs = E[P_std | WLR_std≈a₂] - E[P_std | WLR_std≈a₁]   （标准化尺度）
    Error = |ΔP_pred - ΔP_obs|
```

> **尺度统一**：τ、a₁、a₂、ΔP_obs 必须在**同一标准化尺度**上计算。τ 是标准化尺度下的总效应，a₁/a₂ 必须是用训练集参数转换后的 WLR 标准化值，ΔP_obs 也必须用标准化后的 P。

> **Q₁/Q₃ 取样方式**：选取分位数附近的样本（如 WLR 在 [Q₁-ε, Q₁+ε] 范围内的时间点），而非取上下四分位区间的全部样本。两种做法结果可能不同，需固定一种并报告。

#### 增强版：控制比较条件（严重度分层）

```
在相近严重度范围内比较 WLR 与 P 的关系：
  按严重度分组，在每组内分别计算 ΔP_obs
  或：先按轨迹计算特征，再进行轨迹级比较
若数据不足以合理匹配，报告此局限，不强行做因果解释
```

**双划分策略**：
- 划分一：随机轨迹划分（80% 训练 / 20% 验证）
- 划分二：严重度范围划分（低中严重度训练 / 高严重度验证）

报告两种划分的差异。

> **局限**：观测条件均值差异≠干预效应，严重度梯度不自动构成准实验。

## 六、评估体系与消融实验

### 6.1 评估指标（明确定义）

> **结果报告三分类**（三者不可相互替代）：
> 1. **实现正确性**：LiNGAM 矩阵方向、总效应计算、Bootstrap 指标是否经过验证（用两变量例子核对）
> 2. **统计稳定性**（分两个子项分别报告，不合并）：
>    - **2a. 重采样稳定性**：关键边在轨迹级重采样下的混合 f_e/s_e——按 Phase 2 限定，读作"对严重度构成变化的敏感度"，非因果置信度；
>    - **2b. 严重度稳健性（关键稳健性检查，与 2a 同级必做）**：关键边方向/符号在低/中/高严重度组间是否一致；**混合主分析图与分组结果作为两类结果分开陈述**，并按 Phase 2 预冻结的三条规则（方向一致 / 方向翻转 / 无法稳定估计）逐边给出结论；时间允许时附分层 Bootstrap 对照；
>    - **附：模型假设诊断证据（描述性，非开关，不属于稳定性子项）**：入模变量的偏度、峰度、JB 检验等非高斯性证据，以及分布随严重度组/时间阶段的变化；**不作为 LiNGAM 能否运行的门槛**，只作为解读保守程度的依据（见 Phase 0）；
>    - 另报告数据划分敏感性（80/20 不同随机种子下结论是否改变）
> 3. **物理一致性**：学到的结果在多大程度上与预先登记的物理机制相符（核心关系 WLR↔P 单独报告）
>
> 稳定 ≠ 因果正确；符合物理直觉 ≠ 识别出真实因果结构。
>
> **措辞纪律（2026-10-25 增补）**：结论统一表述为"LiNGAM 在某窗口 / 某严重度组上**稳定识别出的有向关系**"，不得表述为"已证实 / 已验证的真实因果"。静态模型加观测数据（且时间点非 i.i.d.）只能给出关联结构的识别结果及其跨重采样的稳定性，因果方向的物理正确性由第三节冻结的物理关系做对照、而非由模型证明。

| 指标 | 定义 |
|------|------|
| **核心关系方向稳定性** | WLR↔P：模型选择的方向、该方向的 Bootstrap f_e 和 s_e、静态模型能否辨识 |
| **辅助关系方向一致率** | 对辅助物理关系，统计模型方向与物理依据一致的比例 |
| **上游候选 Top-K** | 预先列出的 P 的物理上游候选是否进入排名前 K（不等于根因准确率） |
| **效应一致性误差** | 留出轨迹上 \|ΔP_pred - ΔP_obs\|，报告随机划分和严重度划分两种结果 |

> **注意**：WLR↔P 不把两个方向都算成"正确"。分别报告模型选择的方向及其稳定性。

### 6.2 消融实验

| 实验组 | 设置 | 验证目的 |
|--------|------|---------|
| Baseline-1 | Pearson 相关性排序（无方向） | 因果方向的必要性 |
| Baseline-2 | LiNGAM 直接出图（无 Algorithm 1） | 稳定性筛选的价值 |
| Baseline-3 | LiNGAM + Algorithm 1（无本体约束） | 纯数据驱动结果 |
| Baseline-4 | LiNGAM + Alg 1 + 本体约束（无异常度加权） | 异常标记对 RCA 排序的增量价值 |
| Baseline-5 | LiNGAM + Alg 1+2 + 本体 + 异常标记（无解释生成） | 解释生成的必要性 |
| Baseline-6 | XGBoost 变量集（对照主变量集） | 标签泄漏风险 |
| **Full** | LiNGAM + Alg 1+2+3 + 本体 + 异常标记 + 解释生成 | 完整神经符号流程 |

> **神经符号消融必须对比**：
> - Baseline-3 vs Baseline-4：本体约束是否改善物理一致性
> - Baseline-4 vs Baseline-5：异常度加权是否改善上游排序（注意：主排序始终用纯总效应，此处对比的是增强排序的增量价值）
> - Full vs Baseline-5：解释生成是否提供忠实、完整的根因阐述
> 不能只展示一张更符合物理直觉的图，必须量化指标变化。

## 八、研究边界与局限

1. **非严格变量级 RCA**：验证因果图恢复物理机制的程度，不声称根因准确率。
2. **WLR↔P 双向耦合**：静态 LiNGAM 无法可靠区分反馈环方向，如实报告。
3. **时序 i.i.d. 不满足**：静态近似，轨迹级 Bootstrap 不消除轨迹内自相关。主窗口 t=300~1500s 排除了注入突变（约 110s）与早期传播阶段，结论仅覆盖事故发展期，不覆盖早期因果传播；早期窗口（110~600s）至多提供定性对照。
4. **严重度作为遗漏混杂与 Bootstrap 解释（2026-10-25 定稿前修订）**：严重度是**已观测的轨迹级协变量**（文件名 1~100 即标签），但未纳入建模矩阵，不显式控制时构成遗漏共同原因。由于 DirectLiNGAM 对固定数据确定、且每个严重度仅一条轨迹，f_e 的变异几乎全部来自重采样中严重度构成的变化——**f_e 是边对严重度构成变化的敏感度，不是因果置信度**。结论必须分别陈述重采样稳定性与严重度稳健性；分组学图可缓解但不能消除该混杂（组内仍有梯度、无同严重度重复）。
5. **线性、无环与非高斯假设**：LiNGAM 依赖线性结构、DAG、相互独立的非高斯噪声三组假设。Phase 0 已增加非高斯性**描述性诊断**（偏度/峰度/JB，但堆叠时间点强自相关、非独立，p 值不作正式显著性解释）；诊断证据**不构成方向可辨识性的完整证明**，即使观测变量非高斯，时间依赖、WLR↔P 反馈环、严重度机制异质性仍可能使方向输出失去依据。核电瞬态还可能存在非线性（另见 Day 4 预注册残差检验）。标准化策略的敏感性（全局 vs 轨迹内）另见 Phase 0 第 4 条。
6. **神经符号适配**：构建极简本体（变量→子系统→物理关系）+ LOCA_1 准稳态段异常阈值 + 模板/LLM 解释生成，实现论文三层知识注入和三环节落地的核心功能；但非论文级完整知识图谱（无 Neo4j、无人工专家公差）。
7. **解释生成适配**：已实现 DeepSeek V4.1-Flash LLM 解释生成（因果图提示注入 + 忠实性校验防幻觉，无 key 时降级模板驱动）；不做 C3AN 框架的 GPT-4o + 人类专家打分评估。
8. **单事故类型（2026-10-25 补充，详见第十四节）**：结论仅在 LOCA 上验证，不声称 LOCA 的变量集、冻结关系、窗口或阈值可迁移到其他事故。但方法流水线本身按事故类型无关设计——可复用的是算法与工程层，需按事故替换的是物理约束层（目标变量、变量集、冻结关系、本体）；扩展时还须重跑 Phase 0 审计。NPPAD 中 12 类带严重度梯度的事故具备直接套用统计流程的样本条件，5 类单轨迹事故（ATWS/LACP/LOF/SP/TT）不具备轨迹级 Bootstrap 的条件。
9. **DiffAN 条件性引入（2026-10-25 更新）**：一周主线不含 DiffAN，Day 4 后按第十三节触发条件决定是否作为对照。不能因 CSV 原始行数更多（343~475 行）就推断深度方法可行或更优——有效独立样本仍约 100 条轨迹；也不能断言深度方法必然不可行。
10. **Normal 与 LOCA 功率不匹配（2026-10-25 关键修订）**：Normal 轨迹 PWNT 100%→40% 是降负荷过程，与 LOCA 事故的 100% 功率演化完全不对应，无法用作阈值基准。改用 LOCA_1（1% 小破口）的 100% 功率恢复段（t=520~2030s，152 点）建阈值，排除故障变量（WLR/WECS/WHPI）和常量变量后，9/14 变量获得可信阈值；基准仍为单条轨迹且含小破口泄漏，仅作探索性异常评分。
11. **Algorithm 3 混杂**：观测条件均值差异受严重度（已观测但未控制的轨迹级协变量）、时间阶段等因素影响，不自动等于干预效应。
12. **严重度异质性（新增）**：实测三组严重度在主窗口内处于不同喷放物理阶段（WLR 非单调、P 在低组恢复而中高组下跌），混合图可能不代表任何一组的真实关系；分组结果与混合结果需分别报告。该条描述现象，遗漏混杂的统计性质与 f_e 解释见第 4 条。
13. **常量列（新增）**：LOCA 下 18~25 个参数全程为常量，已在审计阶段剔除；剔除清单随结果报告，变量集因此小于 96 个。

## 九、方案修改记录

| 修改点 | 原方案 | 修改后 | 原因 |
|--------|--------|--------|------|
| Ground Truth | 称"根因变量" | 称"故障响应变量"，任务降级为上游定位 | NPPAD 无变量级根因标签 |
| 特征选择 | XGBoost 作主筛选 | 物理先验为主集，XGBoost 为对照 | 防标签泄漏 |
| Algorithm 1 | 仅边权稳定性 s_e | 四指标：f_e + s_e + 方向一致率 + 符号一致率 | 方向/符号不稳定会被掩盖 |
| Algorithm 1 严重度 | 跨严重度混合 Bootstrap | 增加按严重度分组检查 | 边稳定≠因果稳定 |
| Algorithm 2 | 多目标 Y 求和 | 单一目标 P，阈值不作硬过滤 | 上游变量可能未越限但仍是因 |
| Algorithm 3 | 称"反事实验证"，单一划分 | 称"一致性比较"，双划分 + 增强版 | 观测分组≠干预；相邻严重度太相似 |
| Algorithm 3 符号 | \|ΔB_pred - ΔB_obs\| | \|ΔP_pred - ΔP_obs\| | 符号笔误修正 |
| 神经符号 | 称"神经符号" | 称"物理先验约束"，放最后做消融 | 未构建完整知识图谱 |
| Bootstrap 单位 | 时间点级别 | 轨迹级别，记录轨迹元数据 | 时间点强自相关 |
| WLR→P | 预设为正确方向 | 双向竞争假设 WLR↔P | 破口流量与压力动态耦合 |
| 标准化 | 未明确 | Z-score 标准化，明确尺度 | 不同变量量纲不同 |
| 矩阵索引 | 未核对 | 两变量例子核对 T[Y,X] 含义 | 防止转置/索引错误 |
| 物理关系表 | 笼统"资料支持" | 增加依据来源和证据等级列，实验前冻结 | 确保可追溯 |
| Top-K | 所有关系混算 | 核心关系(WLR↔P)与辅助关系分开 | WLR↔P 不双向都算正确 |
| 标准化局限 | 未说明 | 明确标准化不消除严重度混杂，增加初始状态检查 | Z-score 只解决量纲 |
| Bootstrap 口径 | 分母模糊 | 精确定义四个指标的分母，s_e 标注为自定义指标 | 防止小分母假象 |
| Algorithm 3 尺度 | 未统一 | τ/a₁/a₂/ΔP_obs 必须同一标准化尺度，明确 Q₁/Q₃ 取样方式 | 防止尺度不一致 |
| 禁止边 | 笼统 | 只用于明确物理排除依据，无证据归未知边 | 没有证据≠不可能 |
| 数据划分 | 未明确原则 | 轨迹独立清洗，不跨轨迹构造差分/滞后，划分以轨迹为单位 | 防轨迹泄漏 |
| 物理约束消融 | 只对比指标 | 必须对比约束前后图变化及被约束边的变化 | 证明先验增量价值 |
| Algorithm 3 定位 | 核心验证环节 | 降为探索性一致性检查，非成败标准 | 观测均值差≠因果真值，双向竞争需如实报告 |
| 一周计划优先级 | Algorithm 3 在必做项 | 核心四件事（审计+LiNGAM+Bootstrap+总效应）优先，Algorithm 3/消融延后 | 防止所有模块都跑但无充分验证 |
| 结果报告 | 单一指标表 | 三分类：实现正确性/统计稳定性/物理一致性，不可相互替代 | 稳定≠因果正确，符合直觉≠真实因果 |
| 神经符号 | 仅"物理先验约束"放消融 | 提升为主线必选环节：Phase 0.5 本体构建 + Phase 1.5 因果约束 + Phase 3.5 公差筛选 + Phase 5.5 解释生成 | 神经符号是论文核心设计，不可省略 |
| 解释生成 | 完全缺失 | Phase 5.5：因果图提示注入 + 本体知识 → 自然语言根因解释（模板驱动/LLM） | 论文必要输出环节，对外阐释不可缺 |
| 公差范围 | 全局 μ±3σ | LOCA_1 准稳态段数据驱动异常阈值（功能对应论文公差，但统计效力远低）+ 主排序用纯总效应、异常加权仅作探索性消融 | Normal 降负荷与 LOCA 功率不匹配，改用 LOCA_1 恢复段；单条轨迹自相关使 μ±3σ 不具备容差统计含义 |
| 消融实验 | 5 组 | 7 组，含本体约束/公差/解释生成逐项消融 | 验证神经符号各环节增量价值 |
| 公差定位 | 称"cycle-aware 简化版"，暗示与专家公差效力相近 | 明确为"探索性异常评分"，非经过验证的正常运行容差；使用前必须检查分段内趋势 | 单条轨迹自相关 + 时间趋势可能被误判为波动 |
| 本体约束操作 | "允许边保留"（语义模糊，可能被实现为强行添加） | 允许边仅标记不添加：数据学到才标记"本体支持"，未学到不强行添加；禁止边记录依据和删除前后差异 | 防止先验关系人为注入，确保图中边可追溯到数据来源 |
| 训练/验证划分 | 划分原则已有但未明确执行顺序，Bootstrap 用全部 100 条 | 先划分→仅训练集拟合 LiNGAM/Bootstrap/定阈值→验证集仅用于 Algorithm 3；严重度分组用全体数据但明确标注 | 防止验证集参与模型选择导致信息泄漏 |
| 总效应计算 | 未明确计算对象，可能平均边权后求逆 | 每次 Bootstrap 独立计算 T_k，汇总 T[P,X] 的中位数/分位数/符号一致率；稳定边图 T_stable 仅作展示，不与 Bootstrap 分布混用 | 矩阵求逆非线性，平均边权后求逆≠各次总效应平均 |
| 异常加权排序 | 主排序 = \|T\|×(1+α×异常度)，α=0.3 | 主排序 = \|median(T_k)\|（纯总效应）；异常加权为增强版消融，对 α 做敏感性分析，报告排名变化 | α 为工程经验值，异常度可能与严重度共变，不应预先假定有效 |
| DiffAN 放弃理由 | "数据量不足" | "受一周时间及数据结构适配成本限制，暂不实现" | 仅凭 100 条轨迹不能断言深度方法必然因数据量不足不可行 |
| 准稳态方案措辞 | "100 样本近似独立""更适合 LiNGAM" | 删除独立性断言，明确"减去同一正常基线常数不消除变量间相关结构"，独立性/同质性需验证 | 轨迹间独立≠分布同质，去均值不去协方差 |

### 9.1 2026-10-25 基于 NPPAD 实测的修订详述

**实测范围**：下载并核对了 README 与官方 `Data Processing.py`；LOCA 严重度 1/25/50/75/100% 五条轨迹、Normal 一条轨迹；通过仓库完整文件树核对 1217 个 CSV 的目录分布（LOCA 编号 1~100 连续无缺）；读取了 `Variable_Power_Data/manifest.csv`。

**对外审意见（七条）的辨证立场**：七条核验全部接受，落实如上表。其中三点在落实时做了加强或修正：

1. **Normal 轨迹问题比"有趋势"更严重**。外审指出该轨迹有趋势、需谨慎去趋势；实测发现 PWNT 全程由 100% 降到 40%、TAVG 由 310°C 降到 299°C，它本质是一条功率漂移轨迹而非稳态正常工况。因此不再是"分段趋势如何处理"的局部问题，而是阈值模块可能整体不成立——方案新增了模块退出条件，主分析（纯总效应排序）不依赖该模块。
2. **窗口决策落地，不悬空**。外审建议"先画图再决定窗口"。方案保留 t=300~1500s 为主窗口，但给出基于实测的明确依据（100 轨迹等长 121 点已验证、避开 110s 注入突变）与代价（1% 组 P 已恢复、丢失早期传播），并把 t=110~600s 早期窗口规定为时间允许时的阶段对照；同时设窗口冻结规则防止看结果选窗口。
3. **新增两项外审未提及的实测发现**：LOCA 下存在 18~25 个常量列（必须剔除，否则进 LiNGAM 无意义）；WLR@300s 跨严重度非单调（25%≈373 ＞ 100%≈367 ＞ 75%≈243 ＞ 50%≈181 t/h），说明不同严重度在主窗口内处于不同喷放物理阶段，为"严重度异质性必做"提供了直接的实测理由。

**对外审一处建议的修正**：原文曾建议分段内有趋势时"去趋势后再计算"。去趋势会减掉真实的功率-温度耦合关系，不是中性操作，现改为仅在趋势被判定为仿真基线漂移、且变量物理上应平稳时才允许，并需单独标注。

**未改动的方法学核心**：LiNGAM 单算法路线、三算法流水线（Bootstrap 稳定性 / T=(I−B)⁻¹ / 一致性比较）、轨迹级 80/20 训练验证划分与防泄漏顺序、WLR↔P 双向竞争假设、物理先验变量集与本体约束规则、静态近似的根本局限——均保持不变。本次修订只动数据处理与审计层，不改变研究问题与结论口径；静态 LiNGAM 用于强自相关动态轨迹的方法学限制仍然存在，窗口和数据处理的修正不能消除它。

**同日关于 DiffAN 的独立决策（详见第十三节）**：外审建议"LiNGAM 主线、DiffAN 有条件对照"的总体策略被采纳，但在核实原始文献后纠正了其方法描述——DiffAN（Sanchez et al., ICLR 2023, arXiv:2210.06201）实为扩散模型学习 Hessian 的拓扑排序方法（剪枝依赖 R/cdt），并非"注意力可微因果发现"（该错误展开来自 CausalTrace 正文自身）。在此基础上补充了外审未覆盖的三点：严重度作为未纳入建模的轨迹级协变量可能形成遗漏混杂、高容量模型可能放大它；p≈15~20 规模下 CAM/成对 ANM 比 DiffAN 更经济匹配；Day 4 go/no-go 门需以自相关有效样本量估算和预注册非线性残差检验为证据。

### 9.2 2026-10-25 定稿前修订：严重度性质与 Bootstrap 统计解释

外审定稿前审查指出一处实质性概念错误，已全盘接受并修订（改动涉及 Phase 2、Phase 0 标准化说明、6.1 评估口径、第八节局限第 4/11/12 条、13.2/13.5 及修改记录表）：

1. **严重度不是未观测混杂，而是已观测的轨迹级协变量**：文件名 1~100 即破口严重度标签，概念上完全可获得；它只是没有作为传感器变量进入建模矩阵。准确表述是"已观测、未控制 → 构成遗漏混杂（omitted confounder）"。这一区分影响可控性判断：未观测混杂原则上无法调整，而已观测协变量可以分层/对照。
2. **f_e 不是边的置信度**：DirectLiNGAM 对固定数据输出确定，而每个严重度仅有一条轨迹——轨迹级重采样中"轨迹 i 是否入选"等价于"严重度 i 是否出现"，故 f_e 的变异几乎全部来自训练集严重度构成的变化。f_e 应读作"边对严重度构成变化的敏感度"，其值高仍是有用的稳健性证据，但不能读作因果正确概率。
3. **两类稳健性强制分开报告**：①重采样稳定性（混合 f_e/s_e）；②严重度稳健性（低/中/高组间方向一致性）。二者不可互相替代。
4. **补充外审未展开的两点**：(a) 严重度在轨迹内是常数列无法作为 LiNGAM 节点，对其回归残差化属对上游因果断点的过度控制（overadjustment），故"分层学图+组间一致性"是当前最合理控制，但组内仍有梯度、无同严重度重复，不宣称已完全调整；(b) 新增低成本的分层 Bootstrap 可选对照（组内分别重采样、固定构成），列入扩展实验而非必做项。

**外审确认无需改动的部分**：主窗口 300~1500s 及冻结规则、WLR↔P 竞争假设、变量级真值缺失下的任务降级、Normal 阈值模块退出条件、神经符号层的轻量适配定位、DiffAN 条件门控（不因 CSV 变长启动）、Algorithm 3 的探索性降级（条件均值差异≠干预效应）——均维持现状。本轮不新增必做算法路线，修订后方案可冻结进入实施。

### 9.3 2026-10-25 第二轮辩证修订：三条外审意见的采纳与不采纳

针对"假设诊断、标准化、严重度异质性"的第二轮外审意见，经辩证分析后**采纳其问题诊断，但对两条建议的具体解法做了修正**。三项修订均不改变主算法（静态 LiNGAM）与三算法流水线，只增加诊断、明确边界与报告规则。

1. **非高斯性：加诊断，不加开关。** LiNGAM 的方向可辨识性依赖线性、无环、独立非高斯噪声这一整组假设，并非"观测变量非高斯 ⇒ 方向可辨识"，也不是"某变量未通过正态性检验 ⇒ LiNGAM 可靠"。因此 Day 1 增加偏度/峰度/JB 与分布图的低成本诊断，并按严重度组 × 时间阶段交叉观察；但鉴于堆叠时间点强自相关（12,100 行不是 12,100 个独立样本），JB 的 p 值不能按独立样本口径解释显著性，诊断结果只作假设证据、不作可辨识性的完整证明，**不设置"检验通过才运行"的硬门槛**。即使非高斯性明显，时间依赖、反馈环、机制异质性仍可能使方向输出失去依据——这一风险继续由 2a/2b 统计稳定性与物理对照刻画。
2. **标准化：保留全局 Z-score，不切换轨迹内。** 外审指出的混杂风险是真实的，但其推荐解法（轨迹内标准化）并非更优：(a) 逐变量固定线性变换不制造也不消除严重度混杂，该关联在原始数据中已存在；(b) 轨迹内减均值除标准差会压掉轨迹间的绝对水平差异，而"低组 P≈155 bar、高组 P≈50 bar"本身就是严重度的物理表现，还会放大小破口准稳态轨迹中的微小波动。故全局标准化维持主方案，μ/σ 在训练集一次性估计、Bootstrap 各轮沿用同一口径以防泄漏；新增按组分布检查（必做）与替代标准化重跑（扩展项敏感性对照，不作为主结论依据、不据此挑"好看"版本）。
3. **严重度异质性：从补充检查提升为关键稳健性检查。** 这是三项中对最终图解释影响最大的一项。主窗口内小破口趋稳、大破口持续恶化，混合静态图可能不代表任何一组。修订要求混合主分析图与分组稳健性结果作为两类预注册结果分开陈述，并实验前冻结三条解释规则（方向一致→跨组候选关系；方向翻转→报告异质、不强选；某组无法稳定估计→证据不足、不等于不存在）。同时声明分组的能力边界：每组仅约 21~22 条训练轨迹，分组结果**不一定比混合结果更准确**，其价值在于揭示异质性、界定混合图的解释边界，而非保证恢复真实图。轨迹级 Bootstrap 防的是伪重复、不消除轨迹内自相关，两类风险与严重度异质性分别报告。

**本轮仍未改动的根本前提**：静态 LiNGAM 用于强自相关、含反馈环的动态事故数据这一核心限制依然存在。三项修订都不试图"修复"它——非高斯诊断只让假设违背的程度可见，标准化只处理量纲，分组只界定解释边界。真正的动态方法（PCMCI、VAR-LiNGAM、DBN 等）仍列为后续工作，不在一周主线内。

## 十、备注一：本研究方法与论文 CausalTrace 的区别与联系

> 本备注辩证分析本复现方案与原论文方法学上的异同，不修改方案主线。

### 联系（一致之处）

| 维度 | 一致性 |
|------|--------|
| **核心流水线** | 完全沿用论文：因果发现 → 边稳定性分析 → 总因果效应计算 → 效应一致性检查 |
| **三大算法** | Algorithm 1（Bootstrap 稳定性）、Algorithm 2（T=(I-B)⁻¹ 总效应）、Algorithm 3（预测-观测一致性）思路照搬 |
| **因果发现算法** | 采用论文并列的 LiNGAM + DiffAN 双引擎设计；DiffAN 以 GAM-ANM 轻量替代（理由见 13.7），两引擎结果经共识边 + RRF 融合作为主输出（不指定单方法为主图） |
| **神经符号三层注入** | 知识图谱层（极简本体）+ 过程本体层（LOCA_1 准稳态段异常阈值）+ 因果图提示注入（序列化总效应矩阵），三环节落地（因果约束/异常筛选/解释生成）均实现 |
| **解释生成** | 因果图提示注入 + 本体知识 → 自然语言根因解释，对应论文 InfoGuide 输出环节 |

### 区别（关键差异）

| 维度 | 论文 CausalTrace | 本方案 | 差异根源 |
|------|-----------------|--------|---------|
| **数据形态** | 按制造循环组织数据（原文据此采用相应的独立样本假设，其独立性依据需以原文为准） | 连续事故瞬态时序（时间点强自相关，非 i.i.d.） | 数据集本质不同 |
| **因果发现前提** | 原文按循环组织样本并采用 i.i.d. 假设 | 违反 i.i.d.，需静态近似 | 数据形态决定 |
| **Ground Truth** | 变量级根因标签（缺哪个零件） | 无变量级标签，只有事故类型 | 数据集标注不同 |
| **研究目标** | 根因溯源（RCA） | 上游因果定位与物理关系检验 | 受限于 Ground Truth |
| **知识图谱** | 完整过程本体 + 知识图谱（Neo4j） | 极简本体（变量→子系统→物理关系），无 Neo4j | 缺少核电领域知识库 |
| **过程本体公差** | 专家定义的 cycle-aware 公差 | LOCA_1 准稳态段数据驱动异常阈值（单条轨迹，探索性） | 无专家公差，Normal 与 LOCA 功率不匹配 |
| **解释生成** | LLM（GPT-4o/LLaMA3）+ 因果图提示注入 | DeepSeek V4.1-Flash LLM（有 key 时）/ 模板驱动（无 key 降级）+ 因果图提示注入 + 忠实性校验防幻觉 | 已实现 LLM 生成，对应论文 causal graph prompt injection |
| **DiffAN / 非线性引擎** | 实现（与 LiNGAM 并列，论文未说明如何结合） | 主线以 GAM-ANM 替代完整 DiffAN（理由见 13.7），与 LiNGAM 并列运行；共识边 + RRF 融合为主输出 | 扩散模型训练与 R/cdt 工具链成本、p≈14 用不上 DiffAN 扩展性；GAM-ANM 在该规模下统计更匹配 |
| **Algorithm 3** | 反事实验证 | 降为探索性一致性比较 | 观测条件均值差≠干预效应 |

### 辩证判断

1. **方法学传承是真实的**：本方案不是自创方法，而是对 CausalTrace 三算法流水线的忠实迁移。核心算法逻辑、总效应公式、Bootstrap 稳定性思路均来自论文。

2. **适应是被迫的但合理的**：降级（根因→上游定位、反事实→一致性、知识图谱→物理约束）不是简化，而是因为 NPPAD 数据不具备论文数据的条件（无变量级 GT、非 i.i.d.、无领域知识库）。这些降级在方案中均有明确声明。

3. **最大风险是数据形态不匹配**：论文按制造循环组织数据并据此采用 i.i.d. 假设（其独立性依据需以原文为准）；本方案用连续时序数据，时间点强自相关违反 i.i.d.，静态近似存在固有局限。这是本方案与论文最本质的差异，也是结果解释时最需要谨慎的地方。

4. **本方案的独立价值**：虽然是迁移适配，但"静态因果发现方法在动态反馈仿真系统中的适用性检验"本身是一个有意义的研究问题——即使 LiNGAM 无法稳定恢复 WLR↔P 方向，这个"失败"结果也能说明静态方法的边界。

## 十一、备注二：备选数据处理方案——事故后准稳态段偏离特征

> 本备注记录一个可能比当前主线（时间点堆叠）更优的数据处理方案。**当前不采用，仍按原方案主线执行**，留作后续优化参考。

### 动机

当前主线将 100 条轨迹 × 120 时间点 = 12000 个时间点堆叠后跑 LiNGAM。问题：相邻时间点强自相关，违反 i.i.d.，LiNGAM 可能把"随时间共同变化"识别为因果边。

### 备选方案：准稳态段偏离特征

```
对每条 LOCA 轨迹：
  1. 取事故后准稳态段：t ∈ [600s, 1500s]
     （事故已发展，系统进入准稳态，变量不再剧烈变化）
  2. 计算该段每个变量的均值：μ_accident[X]
  3. 减去正常基线：X_dev = μ_accident[X] - μ_normal[X]
  4. 得到一条轨迹的一个样本：[P_dev, WLR_dev, VOL_dev, ...]

最终：100 条轨迹 → 100 个样本 × N 个变量
```

### 与当前主线对比

| 对比维度 | 当前主线（时间点堆叠） | 备选（准稳态偏离特征） |
|---------|:-------------------:|:--------------------:|
| 样本量 | 12000 | 100 |
| 样本独立性 | ❌ 同轨迹时间点强自相关 | 轨迹间为独立仿真，但分布同质性需验证 |
| 信号纯度 | 混合所有阶段 | 只含事故后准稳态偏离 |
| 时间趋势干扰 | ❌ 严重 | 取段均值消除段内趋势 |
| 因果语义 | "P(t)与WLR(t)是否因果" | "A的偏离是否导致B的偏离" |
| 时序信息 | 保留 | ❌ 丢失 |
| LiNGAM i.i.d. 假设 | ❌ 不满足 | 自相关减弱，但独立性/同质性仍需验证 |

### 潜在优势（需验证）

1. **减弱自相关**：每条轨迹取准稳态段均值，段内时间点自相关被聚合，但轨迹间独立性和分布同质性仍需数据验证。
2. **因果语义变化**：从"两个时间序列是否相关"变为"变量 A 的事故偏离是否因果导致变量 B 的事故偏离"，语义上更贴近 RCA，但不等于 LiNGAM 假设自动满足。
3. **消除段内时间趋势**：取均值消除事故过程中的共同时间趋势，可能减少虚假因果边。

### 代价与注意事项

1. **样本量降至 100**：对 LiNGAM 够用但不算充裕。
2. **丢失时序演化**：只能得到"事故后稳态因果结构"，看不到因果链随时间的传播。
3. **需验证准稳态假设**：数据审计时需确认 t∈[600,1500] 内变量确实近似稳态。
4. **减去同一正常基线常数不消除变量间相关结构**：X_dev = μ_accident[X] - μ_normal[X] 只去除了各变量的正常水平，变量间的协方差结构仍然保留，不能据此宣称"更适合 LiNGAM"。

### 可选增强：滑动窗口子采样

若担心 100 样本太少，可对每条轨迹的准稳态段用滑动窗口取子样本（窗口 100s，步长 50s，每条轨迹约 18 个子窗口，共约 1800 样本）。**但 Bootstrap 和数据划分必须按轨迹级别**，不能按窗口级别，以控制同轨迹子窗口的相关性。

### 决策

**当前不采用此方案**，仍按原方案主线（时间点堆叠 + 轨迹级 Bootstrap）执行。此方案留作：
- 若主线结果显示时间趋势干扰严重、因果图明显不合理时的替代方案
- 后续研究中改进数据处理的参考方向

## 十三、备注三：非线性引擎的定位、选型与方法结合（2026-10-25 增补，2026-10-26 修订）

> **定位变更（2026-10-26）**：原设计将非线性引擎设为 Day 4 门控的第二阶段对照。经评审，原论文因果发现引擎本就是"LiNGAM/DiffAN"并列，忠实复现应将两种算法**同时作为主线**。故将 GAM-ANM 从"门控对照"提升为**主线双引擎之一**，与 LiNGAM 并列运行，结果经共识边 + RRF 融合作为主 RCA 输出。本节 13.1–13.6 保留原事实核实与受控协议（仍作为选型依据），13.7 记录选用 GAM-ANM 替代完整 DiffAN 的决策，13.8 记录方法结合策略。
>
> 触发缘由（历史）：实测 CSV 原始长度 343~475 行，多于原方案假设的 150 行，由此重新评估非线性引擎的角色。

### 13.1 事实核实：DiffAN 到底是什么

经核对原始文献（不是仅凭转述）：

- **真实出处**：Sanchez, Liu, O'Neil, Tsaftaris. *Diffusion Models for Causal Discovery via Topological Ordering*. **ICLR 2023**，arXiv:2210.06201，官方代码 https://github.com/vios-s/DiffAN 。
- **真实机制**：在**非线性加性噪声模型（ANM）**假设下，训练一个**扩散概率模型（DPM/score model）** 来学习数据对数似然的 Hessian 函数；利用 ANM 下 Hessian 对角元识别叶节点，得到**拓扑排序**；再用经典剪枝算法（实现中走 **R 语言 cdt（Causal Discovery Toolbox）**）输出邻接矩阵 DAG。
- **一处引用勘误**：CausalTrace 正文把 DiffAN 展开为 "Differentiable Causal Discovery with Attention"，与该名称对应的真实论文（扩散模型 + Hessian 排序）不符。本方案以 ICLR 2023 原文为准，并在报告中标注此不一致。
- **规模声明（已核对）**：论文称可扩展到 500 节点、10⁵ 样本；多数超参数硬编码，提供 "DiffAN Masking"（`residue=False`）低算力近似。
- **工程现实**：需要训练扩散模型（训练成本远高于 LiNGAM 的一次 ICA）、PyTorch+functorch 加 **R/cdt 剪枝工具链**；训练有随机性，稳定性评估必须多种子重复。
- **边界（与 LiNGAM 相同）**：输入仍假设 i.i.d. 观测样本，输出仍是 DAG。**它不处理时间序列，也不能解开 WLR↔P 动态反馈环**——换更复杂的模型不改变这两个前提。

### 13.2 为什么"CSV 更长"不构成双线并行的理由

1. **独立样本没有变多**。增加的行是同一仿真内高度自相关的连续时间点；有效独立单位仍是 100 条轨迹，且 t>1500s 的准稳态点冗余度更高。LiNGAM 和 DiffAN 都假设 i.i.d.，换算法不解决伪重复问题。有效样本量应在 Day 1 用各变量自相关时间（ACF 衰减到阈值的滞后数）做粗略估算，作为决策证据，而不能使用堆叠行数。
2. **DiffAN 的卖点在本数据上不成立**。500 节点/10⁵ 样本的扩展性针对的是"大 p、大 N"；本研究 p≈15~20（剔除常量列后更少）、有效 N 约百条轨迹量级，它的可扩展性优势完全用不上；而扩散模型参数量大，在小有效样本下过训/不稳定的风险反而更高。
3. **模型容量不防遗漏混杂，可能放大它**。破口严重度是**已观测的轨迹级协变量**（文件名 1~100 即标签），只是未纳入 96 个传感器变量组成的建模矩阵；若不显式控制，它构成**遗漏的共同原因**（omitted confounder），同时驱动 P、WLR、VOL 等所有响应变量。非线性模型容量更大，能把严重度梯度上的弯曲关联拟合得更"丰富"，可能产生更密的虚假边，而不是更接近因果。必须监控边密度，并做按严重度分层的拟合对比。
   - **为什么不能用"把严重度加进模型/回归调整"来控制**：严重度对一条轨迹内的 121 个时间点是常数列（零方差），无法作为 LiNGAM 节点；且它位于因果链最上游（注入量），在堆叠数据上对其残差化属于对上游因果断点的**过度控制（overadjustment）**，会阻断经严重度传导的真实路径。当前最合理的控制方式即分层学图 + 组间一致性比较（Phase 2），但这不等于完全消除混杂——组内仍有严重度梯度，且每个严重度只有一条仿真轨迹，无法估计同一严重度下的仿真随机波动。
4. **两类方法可能同时失去方向可辨识性**。LiNGAM 靠非高斯性辨识方向，非线性 ANM 靠函数非线性辨识方向。事故发展期（主窗口）的热工关系若近似线性、新息近似高斯，则两者都可能方向不稳定——此时方法间不一致反映的是**问题本身不可辨识**，不能判某一方法"错了"。
5. **复现忠实度也不硬性要求它**。CausalTrace 同时报告 LiNGAM（20 条边）和 DiffAN（15 条边），但**未说明 RCA 指标基于哪张图**；因此主线复现不依赖 DiffAN，它只能作为方法学对照。

### 13.3 非线性是真实的科学问题，但应先廉价检验

不否认非线性动机的物理依据：**破口临界喷放流量 WLR~P（亚冷/两相喷放）、空泡份额、DNBR、两相传热**等关系已知强非线性。问题在于用什么代价回答它：

- **先做轻量非线性检验（Day 4 前即可完成，成本极低）**：对 LiNGAM 主排序中的关键关系做残差检验——GAM/多项式回归与线性回归对比、残差-拟合值相关或 HSIC 类独立性检验（检验方法与显著性阈值预注册）。
- **在 p≈15~20 的规模下，CAM（加性模型）或成对 kernel/GAM-ANM 比扩散模型统计上更匹配、更便宜**。若目标只是"非线性方法是否给出不同排序"，它们足以回答；DiffAN 的理由是**与原论文方法对齐**，而非它是此数据规模下的最优工具。这一点在报告中如实区分。
- 检验结果同时充当 13.4 的 go/no-go 证据；若不跑 DiffAN，轻量检验本身也可作为非线性基线写入报告。

### 13.4 Go/No-Go 门（Day 4 评审，证据冻结后决定）

仅当下列条件满足 **≥2 项**才启动 DiffAN 第二阶段：

- **A（稳定性动机）**：LiNGAM 关键边在轨迹级 Bootstrap 中 f_e 低，或主关系方向在严重度组间翻转，且该不稳定不能由窗口/混杂诊断单独解释；
- **B（非线性证据）**：预注册的残差检验在冻结的关键关系中至少 2 条显著（含 WLR~P、DNBR/TAVG 等已知非线性候选）；
- **C（资源与目标）**：剩余时间 ≥1.5 天，且报告目标包含方法比较。

**禁止仅凭"数据行数变多"触发。**

**进入后的中止条件**：R/cdt 环境搭建超过 0.5 天；合成数据 sanity check 不通过；NPPAD 上多种子图高度不稳定——出现任一即停止并作为负面结果报告，不继续调参。

### 13.5 受控对照协议（若执行）

**公平性前提（缺一不可）**：同一变量集（剔除常量列后的同一白名单）、同一主窗口 300~1500s、同一轨迹级 80/20 划分、Bootstrap 使用**种子对齐的同一批轨迹重采样索引**。不得给 DiffAN 用更长原始序列（准稳态点更冗余）；更不得用第十一节 100 样本准稳态方案喂扩散模型（n=100、p≈15 对深度网络无统计意义）。

**上数据前的双 sanity check**：
1. 合成非线性 ANM DAG（p≈15，n≈2000）：拓扑排序应基本恢复，验证工具链与参数；
2. 合成线性高斯 DAG：方向应表现不稳定——用于校准"工具在不可辨识区会给出什么"，避免日后误读。

**运行口径**：每次轨迹级 Bootstrap 重训练扩散模型，≥3 个随机种子，聚合排序与边；算力不足时预注册使用 `residue=False`（Masking 近似）并标注。

**预注册比较指标（实验前固定，不按结果挑选）**：

| 指标 | 说明 |
|------|------|
| 稳定边集 SHD / Jaccard | 两算法稳定边集合的结构差异 |
| 冻结关系方向一致率 | 第三节核心 + 辅助物理关系上的方向吻合比例 |
| WLR↔P 专项 | 两算法各自选择的方向、频率、跨组表现 |
| 严重度分组稳定性 | 低/中/高组内方向与 f_e 是否跨组一致 |
| 边密度（混杂诊断） | DiffAN 混合图相对分层图是否异常变密——变密提示拟合了严重度梯度（已观测但未控制的轨迹级协变量） |
| 计算成本 | GPU 小时数 / 墙钟时间 |

**结论纪律**：方法间一致**不是**因果正确性的证明（两者共享 i.i.d.、无环假设，且共享"严重度"这个已观测但未控制的轨迹级混杂源，以及其他未观测传感器噪声/环境变量）；不一致是关于**假设敏感性**的证据，按"线性/非高斯 vs 非线性 ANM 可辨识性差异"解读，不按直觉判输赢。无变量级真值时，不宣布哪种算法"更准"。

### 13.6 实施排期（2026-10-26 修订：双引擎同步推进）

非线性引擎已升为主线，不再走门控两阶段。GAM-ANM 与 LiNGAM 同步开发（共享数据加载、Bootstrap 框架、本体约束），开发顺序：

- **Day 1-4**：LiNGAM 主线 + 数据审计 + Bootstrap + 总效应；同步开发 GAM-ANM 成对因果发现（pygam + 独立性检验）
- **Day 5**：GAM-ANM Bootstrap + 总效应排序 + 方法结合（共识边 + RRF）
- **Day 6-7**：消融 + 一致性比较 + 报告

Algorithm 3 仍为探索性，资源冲突时优先保证双引擎融合结果的完整输出。

### 13.7 实施决策记录（2026-10-26）

LiNGAM 主线完成后，执行 13.4 go/no-go 评审，证据如下：

| 条件 | 实测证据 | 判定 |
|------|----------|------|
| A 稳定性动机 | WLR↔P / VOL↔P / THA→PSGA 均为 candidate（3/3 组方向一致），稳定边 f_e 最高 1.0；LiNGAM 实际相当稳定 | 不满足 |
| B 非线性证据 | 6 条关键关系中 4 条显著非线性：WLR→P(ΔR²=0.24)、TAVG→DNBR(0.13)、THA→PSGA(0.14)、VOL→P(0.11) | 满足 |
| C 资源与目标 | GPU 可用、时间充足、报告含方法比较 | 满足 |

**B + C = 2 项满足，达到 ≥2 项启动阈值**。但 A 不满足意味着引入 DiffAN 的核心动机（"LiNGAM 不稳定"）偏弱。结合 13.2 的分析（p≈14、有效 N≈100 条轨迹下 DiffAN 扩展性优势用不上、R/cdt 环境成本高），**最终选用方案 B：轻量非线性基线（GAM-ANM）**，而非完整 DiffAN。

**决策理由**：
1. GAM-ANM（广义加性模型 + 加性噪声模型）在 p≈14 下统计上比扩散模型更匹配，且纯 Python 实现，无需 R/cdt 工具链，成本 0.5 天；
2. 能回答核心科学问题"非线性方法是否给出不同排序"，与 LiNGAM 形成线性/非高斯 vs 非线性 ANM 的可辨识性对照；
3. 忠实度：仍遵守 13.5 的公平性前提（同变量集、同窗口、同划分、种子对齐的 Bootstrap 索引）和预注册比较指标。

**实现内容**：新增 `nonlinear_baseline.py`，用 pygam 对每个变量对 X→Y 拟合 GAM（Y = f(X) + ε，f 为样条），通过独立性检验残差 ε⊥X 判定方向（ANM 可辨识性）；输出方向邻接矩阵与总效应排序，与 LiNGAM 结果做 SHD/Jaccard、方向一致率、Top-K 重合率对照。

**后续定位提升（2026-10-26）**：基于"论文因果发现引擎本就是 LiNGAM/DiffAN 并列"的忠实性考量，将 GAM-ANM 从"第二阶段对照"提升为**主线双引擎之一**，与 LiNGAM 同步运行，结果经 13.8 的共识边 + RRF 融合作为主 RCA 输出。详见本节开篇定位变更说明。

### 13.8 方法结合策略：LiNGAM + GAM-ANM 共识与 RRF 融合

**问题**：原论文同时跑 LiNGAM(20边) 与 DiffAN(15边) 但未说明两者如何结合、RCA 指标基于哪个图（研读笔记 6.2 指出的论文未交代细节）。两种方法基于不同可辨识性假设（LiNGAM：非高斯；GAM-ANM：非线性 ANM），结果存在差异，需设计结合策略。

**结合策略**（新增 `method_ensemble.py`）：

1. **边层面 — 三分类**：
   - **共识边**：两方法都识别出且方向一致 → 可信度最高
   - **冲突边**：变量对相同但方向相反 → 标记不确定，谨慎解释
   - **单边**：仅一个方法识别 → 候选边，按方法可辨识性假设解读

2. **排序层面 — Reciprocal Rank Fusion (RRF)**：
   - `score(v) = 1/(k+rank_LiNGAM(v)) + 1/(k+rank_ANM(v))`，k=60
   - 两方法都排前的变量得分最高，单一方法排第 1 但另一方法靠后的变量得分次之

3. **WLR↔P 专项判定**：两方法方向是否一致（正向证据）。

**实测结果**（50 次 ANM Bootstrap）：
- 共识边 28 条，冲突边 27 条，LiNGAM-only 28 条，ANM-only 62 条
- WLR↔P 两方法方向一致（均 WLR→P）
- RRF 融合 Top-5：LVPZ(2,3)、QMWT(5,2)、THA(1,7)、PWNT(8,1)、PSGA(3,6)
- 冲突边集中在 WRCA（一回路液体体积）相关边：LiNGAM 倾向"其他→WRCA"，ANM 倾向"WRCA→其他"

**解释生成的融合**：扩展 `explanation.py` 的 `generate_explanation_llm`，将 LiNGAM 总效应、GAM-ANM 边际效应、共识/冲突边、RRF 融合排序一并注入 LLM prompt，使解释同时呈现两方法视角。

**决策理由**：不强行指定某一方法为"主图"（论文也未指定），而是让两种可辨识性假设的结果互相验证——共识边提供稳健证据，冲突边暴露可辨识性边界，RRF 排序平衡两方法权重。

## 十四、后续扩展：从 LOCA 到其他事故类型的复用路径（2026-10-25 增补）

> 本方案只在 LOCA 一类故障上完成因果溯源验证。本节明确：**哪些东西随算法走（事故类型无关，直接复用），哪些东西随物理走（事故类型相关，必须替换）**，使本方案成为可在 NPPAD 其他事故上复用的模板，而非一次性脚本。

### 14.1 核心论点：算法层事故无关，物理层事故相关

整条流水线被刻意组织成两层：

- **算法/工程层（method-agnostic）**：只依赖"多条独立轨迹 × 多个连续变量 × 一个目标变量"的数据形态，不包含任何 LOCA 特有的物理内容。换事故类型时代码与统计协议原样复用。
- **物理约束层（physics-bound）**：目标变量、变量集、冻结关系、本体、解释叙述——这些编码了"破口在一回路热段"这一具体事故机理，换事故类型时必须重建，且重建质量直接决定结果是否可解释。

这与 CausalTrace 原论文的设计哲学一致：因果发现引擎通用，领域特异性由知识层（本体/KG/专家公差）注入。本方案的 LOCA 内容正是知识层的一个实例。

### 14.3 数据可行性分级（据 NPPAD Table 1 与仓库实际文件数）

- **第一梯队——可直接套用全套统计流程（各约 99~110 条带严重度的轨迹）**：LOCA（已做）、**LOCAC**、SLBIC、SLBOC、SGATR、SGBTR、RW、RI、FLB、MD、LR、LLB，共 12 类。具备轨迹级 Bootstrap、80/20 划分、严重度三分组所需的样本量。
- **第二梯队——统计流程不适用（各仅 1 条轨迹）**：ATWS、LACP、LOF、SP、TT。只有一条轨迹时**轨迹级重采样总体不存在**，80/20 划分也无意义；不得退回"把时间点当样本"的伪重复（违反第二节独立性纪律）。可行方向仅限：等待补充仿真、改用专门的时序因果方法、或作为单轨迹定性演示并显著标注统计结论不适用。
- **另一扩展轴——变功率场景**（`Variable_Power_Data/`）：12 个场景（含 LOCA/RW/SGTR 在功率升降过程中注入），但仅 mdb 格式需转换，且注入时刻不同（manifest 记录约 905~2303s），基线非稳态使 Normal 阈值与窗口论证都要重做。属更远期工作。

### 14.4 建议扩展顺序（由易到难，每步多检验一种复用假设）

1. **LOCAC（冷段失水）——最干净的首例对照**：与 LOCA 同属一回路破口、严重度定义相同（% of 100 cm²），变量集与冻结关系预计大部分复用，主要差异是冷段破口使 TCA/TCB 与 THA/THB 的响应角色变化。若 LOCAC 上流水线仅改物理层即跑通且结果合理，"算法复用、物理替换"的论点即得到第一次验证。
2. **SGATR / SGBTR（蒸汽发生器传热管破裂）——跨物理域检验**：破口发生在一回路到二回路，核心变量移向 PSGA/PSGB、WTRA/WTRB 及剂量变量（`Dose_csv_data/` 首次变得相关），目标变量与本体需重建。检验流水线跨"一回路内部"到"跨回路"的复用性。
3. **RW/RI 或 MD（棒动作 / 硼稀释）——压力测试**：非破口类瞬态，反应性-功率链（PWR、PWNT、TAVG、PPM）成为核心，LOCA 破口变量集几乎整组失效，是对"物理约束层可完全替换"的最强检验。
4. **横向比较（远期）**：同一算法引擎在多类事故上产出的稳定边结构差异，可作为事故机理的"因果指纹"对照；但该比较只有在每类事故都独立完成 Phase 0 审计与窗口冻结后才合法，不得用统一窗口跨事故堆叠。

### 14.5 扩展纪律

- 每新增一类事故，**视为一次完整的 Phase 0 重启**：数据审计、注入时刻、常量列、窗口冻结、严重度异质性小结全部重新做，不沿用 LOCA 的任何经验参数。
- 不声称 LOCA 上学到的边结构、阈值、窗口对其他事故有效；可迁移性本身是待检验的假设，不是前提。
- 复用时保持指标口径（f_e 阈值、Bootstrap 次数、划分比例、消融项）不变——跨事故结果只有在同一协议下才可比。
- 每次扩展的产出建议沿用本方案文档结构（数据集审计→物理关系冻结→三算法→神经符号→消融→局限），使各事故报告横向可对照。

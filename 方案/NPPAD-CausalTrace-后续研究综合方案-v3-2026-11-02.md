## 0. 摘要

### 0.1 一句话

> 不再预设"神经符号因果方法优于传统分类"，转而研究它在**故障指示变量不唯一、传播机制随运行区间切换、观测降级**三种条件下，能提供哪些传统方法无法替代的诊断价值，以及**可辨识性的边界在哪里**；先把 v2.1 的尺度与评价问题修好，再用实验决定是否投入算法重构。

### 0.2 两层目标与三条研究问题

**项目总目标（两层 RCA，来自导师要求）**：
1. **故障定位**：识别事故类型；条件允许时进一步区分仿真注入部位/设备侧别（如 SG-A vs SG-B、热段 vs 冷段）；
2. **内部变量传导解释**：解释故障发生后哪些变量先变化、哪些随后响应、它们之间可能存在什么传播关系。

三条 RQ 是**实现这两层目标的研究问题**，不是三个独立方向：

| 层级 | RQ | 问题 | 回答方式 | 成功判据 | 中性/负结果处置 |
|---|---|---|---|---|---|
| 第一层：故障定位 | **RQ1 可辨识性** | 故障指示变量共享/缺失时，多故障模式能否区分？不能区分是"信息不足"还是"算法不足"？ | 形式化定义 + `LOCA vs LOCAC`（共享 WLR，上游各 100 条）真实数据 + 观测集 O 的信息层/算法层分析 | 给出可辨识矩阵、三结局判定与弃权条件；能区分"信息不足/算法不足" | 若真实共享 marker 对不可辨识，则结论为"观测信息限制"，作为路线 B 的核心证据 |
| 第二层：传导解释 | **RQ2 机制可信度** | 严重度机制断点、动态反馈、仿真扰动下，传播链的方向/量级/时序能否被独立验证？ | 剂量-反应与变点分析 + 动态因果 pilot + 数值约束检验 + 多维证据标签 | 每条关键边给出"方向、适用区间、验证状态、证据向量"，可被独立数据或物理约束否证 | 若多数边只能达到结构级支持，则结论为"静态观测只能支撑有条件的传播解释"，写入边界 |
| 支撑层 | **RQ3 弱观测下的神经符号价值** | 低资源、传感器降级、工况迁移、开集输入时，知识层与因果拓扑是否带来可测量增量？ | 2×4×3 低资源因子实验 + 传感器故障矩阵 + 变功率工况迁移 + 未见类拒识 | 在某一弱观测条件下，完整系统 AURC（或错误接受率）在设计点重采样下区间下界>0 地优于去知识消融与 B2 | 若无增量，如实报告，研究重心转向路线 B |

**可声称范围（重要）**：数据标签只支持"事故类型 / 仿真注入部位 / 设备侧别"级别的定位，**不支持**声称能定位真实电厂设备的精确破口位置；内部变量传导只支持"在当前仿真配置与当前观测集下的传播关系解释"，不声称已证明真实物理因果。

### 0.3 与 v2.1 的差异（六条）

1. **研究目标**：从"证明因果签名能识别事故类型"→"两层 RCA（故障定位 + 传导解释）下的可辨识性与证据强度研究"（路线 B 为主）。
2. **诊断对象**：从"3 类事故标签"→"(事故类别, 机制 regime) 假设 + 显式不可辨识集合"；severity 作为**已观测的设计性参数**，不作测试期输入。
3. **评价口径**：从单工作点 Accuracy → Risk-Coverage/AURC + 匹配覆盖率 + **Leave-One-Regime-Out** + 逐轨迹配对差；不再把 100 条轨迹当 iid 样本。
4. **数据范围**：补上游 NPPAD（LOCAC 100、SGBTR 110、SLBIC/LLB/SLBOC 等，MIT 许可），但**只进可辨识性/开集/工况迁移 benchmark，不进主分类任务**。
5. **知识层定位**：从"图约束 + LLM 提示"→三通道（K1 约束、K2 数值约束、K3 机制模板），P1 只做最小原型，P2 按结果决定是否扩充。
6. **证据口径**：从隐含单一可信度 → 多维证据标签 + 主张-证据矩阵；不再用"物理发现"式断言。

## 1. 定位与总目标

### 1.1 研究定位

> **面向 PWR 仿真事故的两层根因分析：故障类型与注入部位定位、类内变量传播机制解释。重点研究共享故障指示变量、机制运行区间切换和观测降级条件下的诊断可辨识性与解释可信度。**

两层目标与 v2.1 的对应：
- 第一层"故障定位"在 v2.1 中是 FULL/MASKED 的三分类；本方案把它推进到**可辨识性**：不只是"分得对不对"，而是"在给定观测集下能分到什么程度、为什么分不开"。
- 第二层"传导解释"在 v2.1 中是 marker→症状传播链；本方案把它推进到**机制可信度**：每条边要有适用 regime、方向来源与证据向量，而不是一个总体方向一致率。

**贡献载体（与项目目标分开）**：
1. 一套可复用的**数据审计与评价协议**（尺度、regime、Risk-Coverage、设计点统计）；
2. 一个**可辨识性分析框架**与真实共享 marker 对的实证（LOCA/LOCAC、SGATR/SGBTR）；
3. 一套**多维证据 + 主张-证据矩阵**的传播解释规范，以及弱观测下的知识增量检验。

**可声称范围**：见 §0.2 末尾。研究结论不超出"仿真数据 + 当前观测集 + 当前严重度扫描"的范围。

### 1.2 三条 RQ 的展开与可证伪设计

见 §0.2 表。补充四条纪律：

- **问题驱动而非方法驱动**：每个实验先写"若正/若负分别意味着什么"，禁止事后把负结果包装成发现。
- **每条 RQ 配最小可证伪实验**：RQ1 = LOCA vs LOCAC；RQ2 = sev87 断点与 WLR↔P 滞后；RQ3 = 5/10-shot 与 40% 丢传感器。
- **两层目标各自有 Gate**：分类/定位结论由 G1 管，传导解释结论由 G1-RQ2 管（§10.2），互不兜底。
- **不扩张研究范围**：不把项目变成通用因果发现研究；所有新增实验必须能回答"它服务两层目标中的哪一层"。

### 1.3 四条硬约束

1. **不预设因果方法优于传统分类。** 传统基线（B1/B1′/B2）在同等覆盖率下不劣于本方法时，如实报告。
2. **先修数据尺度与评价协议，再谈算法重构。** 在病态 z（10²–10⁴）与单工作点精度上做的任何方法对比都不作数。
3. **负结果与边界刻画是一等产出。** 路线 B 不依赖"方法更好"，只依赖"边界被可靠刻画"。
4. **统计单位必须是设计点。** 每个 severity 只有一条仿真轨迹（本轮已核实：LOCA/SGATR/FLB 各 100 条、severity 1–100 各一条），因此 100 条是 100 个设计点而非 100 个 iid 随机重复；所有区间估计都是"设计点重采样区间"，不做总体推断。

**(d) 统计单位：severity 扫描是"设计点"而非 iid 样本。** 本轮核实：LOCA/SGATR/FLB 各 100 个 CSV，severity 1–100 **每个值恰好一条**仿真（无重复运行）；LOCAC 上游 100 条同样 1–100 各一条；SGBTR 上游 110 条为 1–110。含义：

- 100 条轨迹 = 100 个**设计点**，抽样波动只来自"设计点的选择"，不来自"同一工况的重复仿真"；
- 轨迹级 Bootstrap 重采样的是设计点，所得区间应解释为"对设计点构成变化的敏感区间"，不是对总体的置信区间；
- 因此本方案不采用"5×5 交叉验证 + 总体推断"，改用 **Leave-One-Regime-Out（4 折）** 为主、设计点 Bootstrap 与 regime 内重复划分为辅；所有结论限定在"该严重度扫描数据内"；
- SGBTR 的 101–110 提供了**超出 100% 的插值/外推点**，可用于检验"严重度外推"而非需要总体代表性。
- 上述是"设计点"层面的独立性问题；**轨迹内时间点自相关**是另一层问题（P0-6a 审计）：若把同一轨迹的多个时间点当作独立样本输入静态 LiNGAM/GAM-ANM，会违反样本独立性假设，影响 `struct` 证据的可信度。

### 2.4 对论文核心对照的判断

论文的核心对照是"无方向相关性基线 Jaccard 0.33 / MAP@3 44% → 完整系统 0.92 / 94%"。v2.1 没有复现出这个效应量：方向敏感的 B1 在 MASKED 下 0.933，而 E3_base 仅 0.667（D0）。原因至少有三：任务不同（3 类分类 vs 多类根因集合排序）、数据不同（PCTRAN 仿真 vs 产线真实数据）、基线口径不同（我们的 B1 已含方向）。

**处置**：补 **B1′（无方向相关：|Pearson| 或 |Spearman|）**，它才是论文相关性基线的对应物；同时明确写入"本实验未复现论文核心效应量，属变体复现的边界条件"。若 B1′ 也接近满分，说明这份数据上"方向"不携带额外信息——这本身就是有价值的负结果。

### 2.5 结论：为什么"先修后改"

- 尺度问题会同时污染 E2、B1、E3、A(x)、弃权——**不修尺度，任何方法对比都不可解释**。
- 单工作点比较会掩盖"覆盖率差异"——**不修评价，无法判断方法优劣**。
- 断点/饱和/非单调会破坏 9 模板的中位数假设——**不修分组，算法重构建立在不可解释的签名上**。

因此 P0 不是"准备工作"，而是本阶段**唯一能产出可发表结论**的部分（路线 B）。

## 3. 形式化定义

### 3.1 诊断对象

沿用溯因框架，但显式化三件事：

- **故障模式假设** f_k：由仿真注入记录确定的离散假设（事故类型 k + 机制 regime r），**不是**从数据中"发现"的不可观测节点；
- **观测指示集** M_k ⊆ {WLR, WTRA, WTRB, WFLB, ...}：可能反映 f_k 的 marker 集合，允许多对一/一对多/空集；
- **机制 regime** r：由 severity 变点与可观测状态变量共同刻画的运行区间（如 SGATR 的 sev≤86 与 sev≥87）。

签名升级为：

$$\Sigma_k = (F_k,\ \mathcal M_k,\ A_k,\ G_k,\ C_k,\ T_k,\ \mathcal I_k)$$

其中 F_k 潜在故障模式（有注入记录支撑）、M_k 观测指示集、A_k 多变量异常模式、G_k 静态/动态传播结构、C_k 传播效应（含区间）、T_k 时间响应特征、**I_k 可辨识性信息**（该假设与哪些假设不可区分、在哪些观测集下不可区分）。

### 3.2 可辨识性（RQ1 的核心定义）

**符号约定**：`M_k ⊆ {WLR, WTRA, WTRB, WFLB, …}` 是假设 k 的**故障指示变量集**；`O ⊆ V` 是**当前可用观测变量集**（含或不含 marker）。初稿曾用 M 同时表示两者，本稿起观测集统一记作 O。

#### 3.2.1 为什么不能"CI 含 0 就宣布不可辨识"

差异检验不显著 ≠ 两者等价。分数差 CI 为 [−0.02, 0.03] 与 [−0.8, 0.9] 都含 0，前者可能确实难以区分，后者只是证据不足。因此本方案把结论分为**三结局**，并要求**任务内预注册等价界** δ_eq：

| 结局 | 判定条件（分数差 Δ_ij = s_i − s_j 的 Bootstrap 区间 [L, U]） | 允许的表述 |
|---|---|---|
| **可区分（i 优于 j）** | L > +δ_eq | "在当前观测集与数据下，假设 i 优于 j" |
| **可区分（j 优于 i）** | U < −δ_eq | "在当前观测集与数据下，假设 j 优于 i" |
| **支持实际不可区分** | −δ_eq ≤ L 且 U ≤ +δ_eq | "差异被限制在实用等价界内；当前证据支持二者实际不可区分" |
| **证据不足** | 其余（区间跨出等价界或过宽） | "当前数据不足以判断"（不得写成"不可辨识"） |

**δ_eq 的预注册规则**：
- 与决策损失挂钩，逐任务设定：分类/定位任务用"配对错误率差"（如 1 条轨迹/类的翻转是否可接受），边方向任务用"方向翻转对结论的影响"，机制解释任务用"路径集合差异"；
- 在归一化分数上报告 δ 敏感性网格（例如 0.01/0.02/0.05 或等价错误数 1/2/3），结论必须注明所依赖的 δ；
- δ_eq 在看测试结果前冻结，写入 `identifiability_prereg.json`。
- 若无法给出有依据的 δ_eq，默认结论为"证据不足"，而不是"不可辨识"。

**配对统计量的方向约定（重要）**：Δ_ij 必须按"样本真实类"定向，而不是固定 i−j。例如 LOCA/LOCAC 按 severity 配对时，对 LOCA 样本取 Δ = s_LOCA − s_LOCAC，对 LOCAC 样本取 Δ = s_LOCAC − s_LOCA；这样 Δ>0 恒表示"真实类得分更高"，三结局判定与 n₊/n₀/n₋ 汇总才有意义。该约定同样适用于 §5 的配对 δ_i 与 §6 P0-5。


#### 3.2.2 结构相似性只是诊断，不是判据

| 诊断量 | 用法 | 不能做什么 |
|---|---|---|
| 有效效应向量余弦 \|cos(c_i, c_j)\| | 在 A(x) 上计算，报告分布与 Bootstrap CI；高相似提示表示重叠 | 不能单独宣布不可辨识（受尺度与 A(x) 支撑影响） |
| 模板矩阵秩/条件数 | 在 A(x) 支撑上计算，报告秩亏程度 | 不能替代数据侧差异检验 |
| 模板边集 Jaccard | 结构重叠描述 | 不能证明观测等价 |

诊断量必须在**尺度修复后（P0-2）**计算，并对 A(x) 选择做敏感性；若诊断与三结局冲突，以三结局为准，冲突本身记入报告。

#### 3.2.3 信息层单调性与算法层单调性必须分开

- **信息层**：同一损失、同一假设空间下，O₁ ⊆ O₂ ⇒ 最优（Bayes）风险不增。这是理论性质，**无法直接计算**；本方案用代理量（kNN/密度比等非参数可分性下界）近似，并明确标注"代理"。
- **算法层**：本流水线在 O₁、O₂ 上的实测性能可以下降（有限样本、尺度、过拟合、模板不稳定）。这是**流水线性质**，不是信息结论。
- **判定"信息不足 vs 算法不足"**：若信息层代理显示 O₂ 下仍不可分（且结构相似性高）→ 倾向信息不足；若代理可分而流水线不可分 → 算法/尺度问题，回 P0 修复。
- 禁止把"加变量后流水线变差"当作"信息不足"的证据。

#### 3.2.4 输出规则

不可辨识或证据不足的假设对不强行排序，输出：候选集合 {f_i, f_j}、三结局判定、所用 δ_eq、缺失的观测（变量/时间窗/工况）、以及"若要区分需要什么证据"。

### 3.3 多维证据标签与主张-证据矩阵（替代 V0–V4 等级）

初稿用 V0–V4 单一等级，会被误读为"V4 比 V3 强"。实际上它们验证的是**不同性质**：满足守恒不证明方向；扰动响应不证明内部边。本稿改为**六维正交证据**，每个主张声明其证据组合。

| 维度 | 标签 | 含义 | 测量方式 | 边界 |
|---|---|---|---|---|
| 观测证据 | `obs` | 变量在该窗内偏离基线、变化时刻、状态切换 | 双通道尺度（P0-2）下的越限与状态特征 | 只说明"异常存在" |
| 统计关联 | `assoc` | 变量/类别之间存在稳定统计关联 | B1/B1′/B2、交叉验证 | 不指示方向 |
| 结构证据 | `struct` | **在相应模型假设下**，因果发现算法给出稳定的有向结构 | LiNGAM/GAM-ANM 稳定边、Bootstrap 稳定性、π/方向一致率 | 不等同真实因果；受尺度、A(x)、模型假设与采样单位影响 |
| 时间证据 | `temporal` | 变量间存在稳定的领先/滞后关系 | 滞后互相关、VAR/Granger 类检验、PCMCI（后两项 P2-3） | 领先≠方向：共同原因可使两变量以不同滞后响应 |
| 仿真扰动证据 | `perturb` | 改变**仿真器输入参数**（severity、工况）后，下游响应符合预测 | 剂量-反应、regime 对比、变功率场景 | 只支持"输入参数→下游响应"，**不能识别内部边方向** |
| 物理一致性 | `physcons` | 传播链不违反已核验的近似物理约束 | K2 残差检验（§9.2） | 满足约束≠方向证明；违反可能是遗漏项 |

`perturb` 的两种作用域必须区分：**`perturb-input`**（severity/工况扫描，当前可用）与 **`perturb-internal`**（对内部变量做 do()，当前不可用，属 P2-4 条件项）。只有后者可支持"已验证方向"。

**主张-证据矩阵**（定义"什么主张需要哪些证据才能写"）：

| 主张类型 | 最低证据组合 | 允许的措辞 | 禁止的措辞 |
|---|---|---|---|
| 变量异常 | `obs` | "该变量在该窗内偏离基线/发生状态切换" | "该变量是根因" |
| 故障类型关联 | `obs` + `assoc` | "该故障与这些症状稳定关联" | "因果证明" |
| **单边方向（候选）** | `struct` + `temporal`（`assoc` 可辅） | "模型结构与时间领先关系共同支持该边作为候选传播方向" | "已验证因果方向" |
| **单边方向（已验证）** | 候选级 + (`perturb-internal` 或外部独立物理实验) | "在独立干预/外部证据下验证方向" | — |
| 传播路径（候选机制） | 每条边达候选级 + 路径连贯性 + `physcons` 未违反 | "该路径是候选传播机制，证据为 …" | "真实传播链" |
| 机制解释 | 候选机制 + 反例检查 + `physcons` 未违反 | "该解释与现有证据相容且未被否证" | "机理已证实" |
| 故障定位（类型/部位/侧别） | `obs`+`assoc`+（可选 `struct`） | "在当前观测集与数据下判定为 …" | "定位了真实破口位置" |

**四条解释纪律**：
1. `struct` 的措辞统一为"在相应模型假设下得到稳定的有向结构支持"，禁止把 LiNGAM/GAM-ANM 稳定边直接写成真实因果；若 P0-6a 显示采样单位违反独立性，`struct` 需降级并注明。
2. `perturb-input`（severity/工况）只能支持"事故输入→下游响应"的剂量-反应结论；**不能用它证明内部边方向**（S 同时驱动 WLR 与 P，WLR 与 P 的响应不能识别 WLR→P）。
3. `temporal` 只能作为候选方向的辅助证据，不能单独支持方向（共同原因可造成不同滞后）；无 `temporal` 的边只能写"结构支持的方向假设"。
4. `physcons` 只能作为**否证条件**（违反则需解释遗漏项），"满足"只表示未被否证，不构成方向证据；"违反"要区分"物理错误"与"遗漏项/控制项导致"。

**当前数据的诚实上限**：没有内部干预时，第二层 RCA 只能输出"候选传播方向"与"候选机制"，不能输出"已验证方向"；这一点必须写进报告摘要与局限。

### 3.4 五层诊断输出（schema 目标，P2-6 才完整实现）

| 层 | 内容 | 本阶段是否实现 |
|---|---|---|
| L1 故障识别 | 候选故障假设集合（可多个） | P1-4 后实现单/多候选 |
| L2 直接证据 | marker/异常起始时间/激活集 A(x) | P0 即有 |
| L3 传播机制 | 中间变量、路径、方向、效应、时序、证据等级 | P0-6 逐边审计后升级 |
| L4 竞争解释 | 不可辨识假设、可达域外异常（outside_reach）、冲突边 | P1-4 |
| L5 可信度 | 证据等级、验证状态、弃权原因、所需额外观测 | P1-3/P2 |

### 3.5 与 v2.1 术语的映射

| v2.1 | 本方案 | 变化 |
|---|---|---|
| E1 marker 规则 | L2 直接证据的一种 | 不再单独作为分类分 |
| E2 组模式 | A_k 与 L2 的模板相似度 | 保留为诊断通道，但需在双通道尺度上重算 |
| E3-base | C_k 的符号一致通道 | 降为对照，不再承担"因果增量"主张 |
| E3-path | G_k 的拓扑匹配通道 | 主通道候选，需在匹配覆盖率下重评 |
| B1（方向 Pearson） | 有方向相关基线 | 保留 |
| B1′（新增） | 无方向相关基线 | 新增，对齐论文口径 |
| B2（XGBoost） | 黑箱基线 | 保留，需看 risk-coverage |
| gCF | 签名质量门控 | 保留；Alg3 的"反事实"表述改为"留出重演" |
| 弃权 | L5 可信度 + 候选集合 | 从二值弃权扩展为"集合输出 + 原因" |

**三套编号的关系**：v2.1 的 E1/E2/E3 是**证据通道**（从哪来），§3.3 的六维（obs/assoc/struct/temporal/perturb/physcons）是**证据性质**（证明什么、有多硬），§3.4 的 L1–L5 是**输出层**（写给谁看）。一个通道的输出可以同时给多个维度提供证据（如 E3-path 主要贡献 `struct`，也可配合 `physcons`）；不要把通道名与证据维度混用。

### 4.3 划分与统计协议（设计点，非 iid；按类 regime 分折）

**两层统计单位必须分开**：
1. **严重度设计点（轨迹之间）**：每档 severity 只有一条仿真（本轮核实：LOCA/SGATR/FLB/LOCAC 均为 1–100 各一条；SGBTR 为 1–110），100 条是 100 个设计点，不是 100 次独立重复；
2. **轨迹内时间点**：连续瞬态、强自相关；把同一轨迹的多个时间点当独立样本输入静态 LiNGAM/GAM-ANM 会违反样本独立性假设。图学习采样单位与自相关的审计见 **P0-6a**，本节只规定划分协议。

**regime map 必须按事故类独立**：
- 各类 severity 的物理含义不同（LOCA/FLB 为 %×100 cm²，SGATR/SGBTR 为 %×整管，RW/RI 为棒位，LR 为负荷），**不能把同一数值区间称作同一物理机制 regime**；
- P0-3 为每类独立产出 `regime_map.json`；LORO 按**各类自己的** regime 分折，折数可不同（不强行统一为 4 折）；
- 需要跨类统一报表时，用 severity 排名分位（rank strata）作为分层工具，并在表头注明"排名分层，不是同一物理机制区间"。

**变点发现与测试泄漏防护**：
- **预注册候选断点**：SGATR sev87（已有独立证据）、FLB 的 WFWA 归零段、LOCA 的 WLR 非单调段；这些可直接作为验证性分组依据；
- **探索性断点**：PELT/CUSUM 在全体数据上新发现的断点，不得直接用于定义 LORO 测试折；若要使用，必须在训练折内发现（嵌套），或在下任何测试评估前冻结并登记为"预注册"；
- 测试折不得参与断点选择、阈值选择或超参选择。

**sev-1 的角色（明确）**：
- sev-1 只用于过程本体基线 μ/σ 估计，**不进入 LORO 的分类训练与测试**；
- 敏感性分析可把 sev-1 加入签名学习（不进标定/测试），两版都报告；
- 这与 v2.1"sev-1 固定入训练"不同，需在报告中显式说明。

| 协议 | 内容 | 用途 | 限制 |
|---|---|---|---|
| **主协议：按类 LORO** | 每类按自己的 regime map，留出一个 regime 作测试；逐类报告 | 检验"跨机制区间外推"——本研究的核心问题 | 每类折数 2–4，方差大；不做跨类合并的"总体" |

## 5. 评价协议

### 5.1 为什么废掉单工作点精度

| 旧口径（v2.1） | 问题 | 新口径 |
|---|---|---|
| Overall / Selective / Coverage 各报一个点 | 不同方法覆盖率不同，点估计不可比；消融表把 0.500@0.533 与 0.617@1.0 并列 | Risk-Coverage 曲线 + AURC；在 cov=0.50/0.75/1.00 三个匹配点比较 |
| 单次划分（种子 42） | 20 条/类、组内 6–7 条，且每条是设计点，不能当 iid | LORO 4 折 + regime 内 10 次重复划分，报告逐折与汇总 |
| "5×5 CV" | 4 个 regime 与 5 折不对应；且会把设计点当 iid | 删除；确需 5 折时必须显式定义 5 个连续 severity block 并标为补充 |
| 轨迹级 Bootstrap 当置信区间 | 重采样的是设计点，不是独立重复 | 设计点 Bootstrap（分层于 regime），结果称"设计点敏感区间" |
| 弃权=错 | 掩盖弃权的信息价值 | 弃权率、选择性精度、错误接受率分开报 |
| 配对比较只报 Δ̄ 与 CI | 未报逐轨迹 δ_i 与共同子集 n′ | 逐轨迹 δ_i 分布 + n′ + 配对 bootstrap |
| 方向一致率用总体均值 | 掩盖边级与 regime 级差异 | 逐边 × 逐 regime 报 + 证据向量 |

### 5.2 核心指标定义

- **Risk-Coverage**：按置信度（margin s(1)−s(2) 或融合分）从高到低接受，画 selective risk vs coverage；AURC = 曲线下面积（越低越好）。
- **Accuracy@Coverage**：cov=0.50/0.75/1.00 三点的选择性精度，附**设计点 Bootstrap 区间**。
- **配对差**：δ_i = 1[方法 A 在轨迹 i 正确] − 1[方法 B 正确]；方向按样本真实类定向（§3.2.1）；报告 n₊/n₀/n₋、Δ̄、设计点 Bootstrap 区间（B=2000，分层于 regime）。
- **功效**：给 MDE（最小可检测效应）；说明 n=18 配对二值设计在"无负配对、正配对 ≥4/18"时即可令区间下界>0（B=2000 模拟：k=4→0.056，k=3→0），因此不能用"n 太小"解释零结果。
- **可辨识性三结局**：见 §3.2；报告 δ_eq、三结局计数与 δ 敏感性。
- **弃权三分**：A(x)=∅ / max s<τ / margin<δ；分别报告占比与对应错误率。
- **开集**：AUROC(known vs unknown)、FAR@固定弃权率、**逐类结果 + 宏平均**。
- **物理一致性**：逐边统计 K2 残差检验的"违反/未违反/不可判定"，并报告遗漏项与适用工况；分母不含不可判定边。
- **时序依赖**：若 P0-6a 显示强自相关，报告时间块 Bootstrap 与整轨迹重采样两种口径的差异。
- **表述纪律**：结论用"设计点重采样下区间下界>0 / 差异方向稳定"，**不使用"显著优于"**（设计点不是概率样本，不能做总体显著性推断）；任何区间都注明"设计点 Bootstrap（非总体 CI）"。

### 5.3 弃权与标定重置

- 重新标定 τ/δ：在 severity-block CV 的训练折内做留一，禁止在测试折上标定。
- **τ=0 的教训**：min-max 后的分数 s≥0 使 `max s<τ` 永不触发；新协议要求 τ 网格覆盖 0 且报告触发次数，若某通道恒不触发则该通道从弃权规则中移除并说明。
- 弃权原因与"所需额外观测"绑定（例如"补测 WTRA 或延长窗至 2000 s"），作为 L5 输出的一部分。

### 5.4 传播链与解释的评价

- **逐边证据向量**：每条边输出 `{obs, assoc, struct, perturb, physcons}` 的组合（见 §3.3），不再只给一个方向一致率数字。
- **逐边附加信息**：估计方向、物理预期方向、适用 regime、Bootstrap 稳定率、gCF、冲突标记、判定"支持/相反/证据不足"（三种，不允许二值化）。
- **解释层**：LLM 解释只评价"忠实性"（变量不幻觉、数值可对拍）与"结构完整性"（是否覆盖 L3/L4/L5 必填字段）；**不评价"解释质量"**（无专家标注前不主张）。
- **K2 约束检验**：按 §9.2 的近似方程计算残差，区分"违反/未违反/不可判定"；满足约束只表示未被否证，不得作为方向证据；违反要检查遗漏项与控制项，不得单凭残差判链错。
- **禁止**用总体方向一致率替代边级分析；禁止把 `assoc` 级证据写成机理；禁止把 `struct` 写成"已证明因果"。

### 5.5 报告规范

- 每个数字标注来源（脚本名 + 产物文件 + 生成命令），报告表格由脚本生成，禁止手抄。

- 所有阈值、分组、种子、版本号进 manifest；预注册后不得按结果回调。
- 未核实项统一标"待核实"（见附录 E）。

## 9. 神经符号知识层：三通道设计

### 9.1 为什么拆成三通道

v2.1 的知识层只有"边约束"一种用法（forbidden 删边、allowed 标记），在易分任务上消融 Δ=0 是必然的——图约束只在数据驱动的边出错时可能起作用，而本数据的边主要由 marker 与饱和变量决定。要让知识真正参与诊断，必须让它出现在评分与决策里。三通道如下：

| 通道 | 内容 | 进入诊断的方式 | 可证伪性 |
|---|---|---|---|
| **K1 约束** | 冻结关系 + 实体表（子系统/单位） | 学图后删 forbidden 边；allowed 仅标记 | 删边清单可核对 |
| **K2 数值约束** | 近似物理关系（质量、水位动态、安注触发），**不是**严格守恒方程 | 计算残差，三态判定（违反/未违反/不可判定），作为 `physcons` 证据与链的负证据 | 残差超阈可被数据否证 |
| **K3 机制模板** | 设备×故障模式本体 + 预期机制模板（边集、方向、时序） | 生成候选假设、给结构匹配分、标冲突边 | 模板匹配分可与实测链对比 |

**注意**：K2 在 NPPAD 上有未测项（未测流量、控制动作、相变/密度效应），因此只能做**近似约束检验**，不能声称"验证了质量/能量守恒"。

### 9.2 K2 的具体关系与实现要求

| # | 近似关系 | 变量 | 遗漏项（必须写明） | 适用 regime |
|---|---|---|---|---|
| 1 | 一回路装量-泄漏 | WLR ↔ d(VOL)/dt | 安注/补水、密度变化、未测小泄漏 | LOCA 全 regime |
| 2 | SG 水位动态 | (WFWA − WSTA) ↔ d(LSGA)/dt | 压力/密度/相变、排污、未测流入 | FLB/SGATR 的可用段 |
| 3 | 安注触发 | P 低阈 ↔ WHPI/WECS 阶跃 | 手动/自动逻辑、阈值回差 | 高严重度 |
| 4 | 传热管泄漏 | WTRA ↔ LSGA/PSGA | 壳侧排放、控制动作、饱和 | SGATR sev≤86 与 ≥87 分开 |

**实现要求（缺一不可）**：① 核实变量物理含义与单位；② 写出完整或近似方程；③ 列出遗漏项与适用工况；④ 阈值来自正常段残差分布、仿真步长或工程容差（逐关系登记，禁止统一魔数）；⑤ 三态判定并报告"不可判定"比例；⑥ 明确"满足约束≠方向证明、违反≠链错（可能遗漏项导致）"。

### 9.3 K3 的机制模板与结构匹配

- 模板必须来自**独立知识来源**（README 变量字典、物理/工程手册、FMEA/故障树），**不得**先从训练数据+标签中提取规律再用同一套规律评价测试数据（否则标签泄漏）；模板 YAML 版本化，对测试数据盲标。
- 结构匹配分 = 实测稳定边/方向与模板的加权一致度（边覆盖率 + 方向一致 + 时序一致），与 E2/E3 并列进入诊断；权重由 P1-1 决定。
- 冲突处理：模板与数据冲突的边标"冲突"，进入 L4 竞争解释，不删除、不强行排序。

### 9.4 消融矩阵（在弱观测任务上评估，不在易分任务上）

| 组 | 数据驱动部分 | 知识层 | 评估任务 |
|---|---|---|---|
| A | v2.1 原样 | K1（简化代码本体） | P1-1；P1-4 |
| B | v2.1 原样 | +K2（P1-0 最小关系集） | 同上 |
| C | v2.1 原样 | +K2+K3（P1-0 最小模板集） | 同上 |
| D | 多故障签名（P2-1） | 全部知识（P2-2 扩充版） | B-6 + 弱观测 |

**判据与解释边界**：P1 的消融（A/B/C）只能回答"**最小知识原型**是否有增量"；只有 D 组（P2 扩充版）才能回答"完整知识层是否有价值"。若 A/B/C 无差异，结论是"最小原型无增量"，不能直接推断"知识无用"，也不能据此砍掉 K2/K3 的全部研究——需在 P2 或论文局限中说明。

**知识纪律**：知识图谱可以约束和验证数据发现的边，但**不得仅凭本体中存在某条关系就把它算作算法发现的因果边**；所有边必须有数据侧证据或独立干预证据，并标注来源（data/ontology/both）。

### 10.2 Gate 判据（分类与解释分开）

**G1（P0 末，管"故障定位/分类"主张）**
- 硬性：`run_all.sh` 可复算；manifest 完整；报告表格自动生成；独立性审计完成。
- 关键：尺度修复四件套报告；LORO 完成；七条 RC 曲线出图；B1′ 与 δ_i 齐全。
- 裁定：若 E3-path/E3-base 在匹配覆盖率下仍不优于 B1/B1′/B2，**仅放弃"因果通道提升分类准确率"的主张**，不得写成"因果方法无效"；分类结论限定为"本扫描数据内的关联级结果"。

**G1-RQ2（与 G1 同时评审，管"传导解释"主张）**
- 硬性：每条稳定边有证据向量与三判定（支持/相反/证据不足）；physics_relations.yaml 完成；sev87 断点归因修正；至少一张"边 × regime"机制表可复现。
- 裁定：RQ2 的继续与否**不由分类结果决定**；若不达标，则 RQ2 降级为"探索性解释"，但不关闭。
- 防滑坡条款：不允许用"解释有价值"来补偿"分类/定位无证据"；L4/L5 输出中的候选集合与不确定性必须与证据向量一致。

**G2（P1 末，路线裁定）**
- 三选一：① P1-1 显示最小知识原型有增量（设计点重采样下区间下界>0）→ 启动 P2-2（扩充知识层）/P2-1；② 仅 P1-4/P1-3 有结果 → 路线 B + 可辨识性/开集论文；③ 全部中性 → 路线 B 边界刻画 + benchmark；是否继续 P2-3 由 G1-RQ2 决定。
- 同时决定：是否投入完整 KG；是否申请 PCTRAN 环境；是否扩类。

**G3（P2 前）**
- 知识层扩充决策：只有 P1-1 的增量可归因到 K2/K3（而非数据量/尺度）才扩充。
- 扩类决策：只有 P1-4 的结论支持"跨类可迁移"才扩。

**明确的放弃条件（预注册）**：
1. G1 若尺度修复后核心结论全部翻转 → 以修复后结论为准，不保留旧结论；
2. G2 若 P1-1/P1-4 均为中性 → 不再投入 P2 算法改造，只做路线 B；
3. 若上游数据审计失败率 > 50% → 不做跨类实验；
4. 若 PCTRAN 环境在 W14 前仍不可得 → 永久关闭 P2-4 的"真干预"分支；
5. 若 δ_eq 无法在 G1 前冻结 → 可辨识性实验降级为"描述性诊断"，不输出三结局判定。

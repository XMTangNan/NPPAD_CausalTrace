## 0. 结论先行（TL;DR）

1. **工程可靠性高，科学结论弱。** v2.1 的预注册门控、双引擎分工、缺陷逐条核销、断点续跑是真资产；但它产出的是一份"负结果 + 数据特性刻画"，不是"因果签名有效"的证据。这个定性必须在报告的标题、摘要、结语三处一致地兑现。
2. **三个正结果里有两个是设计自证。** FULL=100% 是 marker 泄露（报告已承认）；MASKED 的分类力来自 E2（消融 −E2 → 0.217），而 E2 与 B1 同属"症状向量 × 模板效应向量"的相似度族，所以 D0 得出"E3 不优于 Pearson"在信息上几乎是必然而非发现——**这个 D0 不能证伪"因果增量"**（§2 O1）。
3. **SGATR=0 的归因要改。** 报告称"LSGA 高严重度饱和反转是真实物理现象"。我核查原始数据：SGATR 的 WTRA 中位数在 sev86→87 由 88.28 断裂到 71.99（相邻步跳变约 19 倍中位步长，全扫描最大），LSGA 同时由 12.03 跳升到 12.50 并继续单调升到 15.15；high 组（67–100）内 corr(WTRA, LSGA_z) = −0.54，而全扫描 Spearman = +0.94。**负号来自"分组跨机制切换 + 局部斜率估计 + 病态 z"，不是 LSGA 自身的物理饱和反转**（§1.2、§2 O4/O5）。
4. **尺度问题是本实验最值得写出来的方法学发现。** 共享基线 σ 使 z 达到 −3.7×10³（FLB WFWA）、−3.1×10⁴（FLB WSTA）、+8.6×10²（SGATR LSGA）。z 已不再是"偏离多少个标准差"，A(x)、E2 余弦、B1 相关全部被 1–2 个饱和变量支配（§1.2、§2 O3）。
5. **下一步不要调参，换问题。** 优先序：① **P0** 复现归档 + 尺度/变点修复 + risk-coverage 重评（约 1 周）；② **P1** 用三个新任务检验因果签名的边际价值——低资源/降级、剂量-反应与变点、开集拒识（约 2–3 周，全部用现有数据，不需新仿真）；③ **P2** 按定位选论文路线（§3.3）。

### 1.2 三处独立复核（这部分报告的数字是错的或解释过头了）

以下复核均直接读取原始 CSV（不依赖 v2.1 流水线产物）。

**(a) 共享基线的 σ 使 z 病态。** 报告用的过程本体基线段是 sev-1 的恢复段（t∈[520,2030]s，3×152 点池化），此时系统接近稳态，σ 极小：

| 变量 | μ | σ | σ/\|μ\| | 事故主窗中位数的最大 \|z\| |
|---|---:|---:|---:|---:|
| P | 156.02 | 0.740 | 4.8e-3 | **156**（LOCA sev97） |
| VOL | 288.34 | 1.764 | 6.1e-3 | **90**（LOCA sev91） |
| LSGA | 11.838 | 0.00384 | 3.2e-4 | **863**（SGATR sev100） |
| WFWA | 1915.51 | 0.512 | 2.7e-4 | **3739**（FLB sev≥10，给水被完全切断） |
| WSTA | 1915.89 | 0.0602 | 3.1e-5 | **≈3.1×10⁴**（FLB，蒸汽流量塌陷） |

z=863 或 −3739 不是"异常程度"，是把一个有限量除以一个近零的稳态噪声。报告把 z=173→864 当作物理证据，属于把尺度伪影读成机制（见 (b)）。更严重的是：E2 的"有符号中位 z 余弦"和 B1 的 Pearson 都在这个尺度上做内积，**二者的相似度实际上由 WFWA/WSTA/P 一两个饱和维决定**，这也是 E2 与 B1 高度同源的直接原因。

**(b) SGATR=0 的根因是 marker 的机制断裂，不是 LSGA 饱和反转。** 数据事实：

| 证据 | 数值 |
|---|---|
| SGATR marker WTRA 中位数 sev86 → sev87 | 88.28 → **71.99**（全扫描最大跳变，≈19× 中位步长） |
| SGATR LSGA 中位数 sev86 → sev87 → sev100 | 12.03 → 12.50 → **15.15**（单调递增） |
| LSGA_z sev67 / sev86 / sev87 / sev100 | 24.3 / 49.4 / 173.1 / 863.3（与报告完全一致） |
| high 组（67–100）内 Pearson(WTRA, LSGA_z) | **−0.541**（Spearman −0.282） |
| 全扫描（2–100）Spearman(WTRA, LSGA_z) | **+0.944**；mid 组（34–66）Pearson +0.9995 |

结论：LSGA 随严重度**单调上升**，不存在"反转"；high 组出现负相关，是因为 sev87 处 WTRA 自身掉档（机制切换/控制模式变化），而 high 组（67–100）恰好横跨这个断点。C^A 估的是"训练中位数处的局部斜率"，于是自然得到 −2693。**这是"分组边界 + 局部斜率 + 病态尺度"的合成伪影，不是新物理发现**；至少目前不能写成"饱和反转"。

**(c) "严重度扫描"不是干净的剂量阶梯。** 三个类的 marker 中位数对 severity 的行为完全不同：

| 类 | marker 行为 | 含义 |
|---|---|---|
| FLB | WFLB 中位数 ≈ 28.7→1433，**严格线性**；WFWA 在 sev≥10 直接归零 | marker 是好的剂量代理，但目标变量 WFWA 是**二元饱和**量 |
| SGATR | WTRA 大体线性，**sev87 处断裂** | 扫描内部有 regime 切换，分组必须避开断点 |
| LOCA | WLR 中位数非单调：sev2=66.6、sev10=155、sev20=81、**sev21=262**、sev22=88、sev100=268 | marker 存在振荡/跳变，单点中位数不稳定，"模板=母体期望"假设不成立 |

**影响**：v2.1 的 9 模板把"严重度分组中位数"当作"该组母体的期望签名"。在这份数据上这个假设不成立——组内跨越断点、marker 非单调、多个变量饱和。所有基于"模板向量"的分数（E2/E3-base/B1）都继承了这个缺陷。

### 1.3 为什么 B2=100% 而流水线只有 0.5

这是整份报告里最刺眼的一对数字，报告只用"任务高度可分"一句带过，但没有做归因。三种候选解释与判别方法：

| 解释 | 判别方法 | 现有证据 |
|---|---|---|
| H1 任务本身容易（症状差异大） | 看 B2 在**只有普通统计量**时的交叉验证与逐严重度表现 | B2 MASKED 60/60、CV=0.983 → **H1 强支持** |
| H2 流水线弃权过度（cov=0.533） | 在**匹配覆盖率**（如 cov=0.75）下比较选择性精度；看 28 条被弃轨迹的特征分 | 缺；报告未给弃权原因分解 |
| H3 E3 错误拖累融合 | 用 E2-only、E3-only、融合三条 risk-coverage 曲线对比 | 消融显示 −E3 时 cov 0.283/selective 1.0，方向混杂 |

另外：报告给的标定结果 **τ=0.000**，意味着"低分弃权"通道事实上失效（min-max 后的分 s≥0，`max s<τ` 永不触发）；而 A(x)=∅ 在报告里仅 3 条，所以 28 条弃权的绝大多数来自 **δ=0.025 的边际差**。因此"弃权=信息不足"的解读与数据事实（B2 满分）矛盾：它更像"模板匹配器自己不确定"，不是"观测不含信息"。这一点必须改写，并做 matched-coverage 比较，否则"弃权有效性"（S3）无从谈起。

### 1.4 复现的是流水线，不是论文的效应量

论文的核心对照是：相关性基线（**不判断方向**）Jaccard 0.33 / MAP@3 44% vs 完整系统 0.92 / 94%，据此主张"判断因果方向是 RCA 有效的前提"。v2.1 的结果是：方向敏感的 B1（Pearson）MASKED = 0.933，而因果通道 E3_base = 0.667（D0）。

- 这不是"论文结论被推翻"，因为任务、数据、标签语义、指标都不同（3 类分类 vs 多类根因集合排序）。
- 但它意味着：**本实验没有复现出论文的核心效应量**，而报告没有把这一点写成明确的"复现失败/边界条件"。
- 还有一个被忽略的对照：论文的相关性基线**不含方向**，而我们的 B1 已含方向。要真正对标论文，应补 **B1′ = 无方向相关（|corr| 或 Spearman 绝对值）**。如果 B1′ 也很高，说明在这份数据上"方向"根本不携带额外信息；如果 B1′ 明显低，才谈得上"方向有贡献"。

## 2. 意见（O1–O12，按优先级）

### 方法学

**O1. D0 门控是"同义反复检验"，不能证伪因果增量。** E3_base 与 B1 的输入相同（d_x 与模板效应向量），差别只在加权方式（π 加权符号一致 vs Pearson 内积）。二者信息同源正是方案自己预警过的 RCA-024 风险，现在被数据证实。**改法**：主检验改为"拓扑通道 vs 相关性通道"——E3_path（reach+depth，图拓扑信息是 Pearson 构造上拿不到的）对 B1/B2 做配对比较；D0 的定位从"证伪"降为"决策留痕"。

**O2. 单工作点精度不可比，必须改 risk-coverage。** 现有消融表把 (Overall 0.500, cov 0.533)、(0.617, cov 1.0)、(0.283, cov 0.283) 放在一起横向比，这是不合法的。**改法**：每个方法给 risk-coverage 曲线 + AURC，在 cov=0.50/0.75/1.00 三个匹配点报选择性精度；配对 Bootstrap CI。这样"E3 是否更好"才有可比口径。

**O3. 标准化失效，报告应把它写成方法学发现。** 见 §1.2(a)。**改法**：① σ 用稳健尺度（MAD×1.4826）并设相对下限（如 σ_floor = max(1.4826·MAD, 1%·|μ|)），② 对 z 做截断敏感性（|z|≤10）并报告结论是否改变，③ 对"会归零/饱和"的变量（WFWA、WSTA、P）改用相对变化或状态特征，不参与"符号一致率"的分母。**这是低成本、高收益的修复，也是可发表的内容。**

**O4. 分组边界必须由变点检测决定，不能写死 67/100。** sev87 断点已经确认。**改法**：PELT/CUSUM 或先验 Bai-Perron 检测 marker→症状曲线的变点；分组改为数据驱动（例如 low 2–86 / sat 87–100），或干脆把 severity 当连续暴露建模。

**O5. 方向的 estimand 要写清楚。** C^A 是"训练中位数处局部线性斜率"，被报告当作"母体方向模板"；跨全扫描 Spearman +0.94 与组内 −0.54 并存，说明方向依赖定义域。**改法**：预注册方向的定义域（"高严重度组内"还是"全扫描单调趋势"），高严重度用秩相关或单调约束 GAM，报告不同范围内的方向一致性作为敏感性。

**O6. "n=18 功效不足"这个说法本身不成立，报告缺的是逐轨迹 δ_i。** 我用 B=2000 的轨迹 Bootstrap 模拟验证：当 δ 中**没有负配对**、且正配对 ≥4/18（≈22%）时，95% CI 下界即 >0（k=4 时下界 0.056；k=3 时仍为 0）。也就是说 n=18 足以检出"一边倒"的支配效应，真正缺证据的原因只能是 δ 大量为 0 或负（即 E3≈B1），而不是样本量。**改法**：报告逐轨迹 δ_i 分布；补 MDE 与功效曲线（针对"混合效应"而非"支配效应"）；测试集 20 条/类补 Wilson CI；主评估改为 5×5 分层重复交叉验证（100 条/类完全够）。

**O7. 弃权机制的解释要重写。** τ=0 使阈值通道失效，46.7% 弃权主要由 δ=0.025 的边际差控制；B2=100% 说明观测含足够信息。**改法**：把弃权重新定义为"评分器不确定"并做风险-覆盖分析；增加混淆矩阵、被弃样本的三通道分数分布、"弃权后人工复核收益"模拟。

**O8. 反事实环在近确定性仿真上退化。** 同一模板内按 marker 分 Q1/Q3 的"重演"，本质是同组重采样，不是 do() 干预。**改法**：把 severity 作为暴露做剂量-反应（分层 G-computation / g-formula），或获取 PCTRAN 多参数扫描数据后做真正的干预重演。当前 gCF 全过的结论应降级为"形式通过、无实质信息"。

### 数据 / 任务

**O9. 标签 ≈ marker 的一列，任务天然退化。** 隐藏 marker 只是必要条件；真正的难度来自"标签与可观测解耦"。**可选的三个新任务**：① 侧别定位（SG-A vs SG-B，数据里有 LSGA−LSGB 非对称线索）；② 严重度区间/剂量回归（连续标签）；③ 开集拒识（Normal 多场景 + LOCAC 作未见类原型）。这三项都在现有数据上可做，且能产出正结果。

**O10. 扫描数据本身要先做质量审计。** marker 非单调（LOCA WLR sev21 尖峰 262）、多变量饱和（FLB WFWA 归零）、机制断点（SGATR sev87）。**改法**：把"扫描数据质量审计"作为 P0 的独立产物（表 + 图），在它之上再谈模板。否则 9 模板的中位数不可解释，任何结论都会被审稿人一击即中。

### 工程 / 写作

**O11. 产物与环境的可复现性断裂（P0 硬前提）。** v2.1 流水线产物（`signatures/`、`cf_validation/`、`metrics_*.csv`、92 条链、5 条 LLM 等）需由 P0-1 的 `run_all.sh` 从原始 CSV 重算生成；运行环境需安装 `lingam`、`pygam`、`statsmodels` 等依赖。**改法**：venv + 锁版本 requirements + `run_all.sh` + 产物 manifest（含 sha256）+ 由 JSON **自动生成**报告表格（禁止手抄数字）+ `.gitignore` 白名单保留关键结果。

**O12. 报告口径与证据不匹配。** ①标题/结语用"诚实边界刻画"是正面的，但正文证据是负结果，应在"一句话结论"第一行直接写 S2 判据③的固定结论句；②"RCA-032 真实现象非 bug"应降级为"未解释的数据变点，待专项分析"（我的复算支持变点，但机制未证实）；③LLM 的【通俗解读】不可核验，只能作为产品 demo，不能作为方法证据；④"模板级 template_gcf 全 1（LOCA_low=0.5）"这类自相矛盾的表述要改。

### 3.2 P1：三个新任务，检验因果签名的边际价值（2–3 周）

> 设计原则：每个实验都要能回答"因果签名在**什么条件下**比相关性/黑箱更值钱"，而不是再比一次总准确率。主体使用现有 301 条轨迹，仅 E3 的 Normal 多场景需要补仿真（可降级为探索）。

**E1 低资源与降级（最推荐，直接回应"−本体 Δ=0"）**
- 假设 H1：训练样本越少、观测越降级，符号先验（本体约束 + 过程本体公差）的相对增益越大。
- 设计：每类 5/10/25/50 shot × 传感器随机丢弃 20%/40% × 加噪（SNR 阶梯）；对照完整流水线 vs −本体 vs −过程本体 vs B1 vs B2。
- 指标：risk-coverage/AURC、选择性精度@cov0.5；重复 10 个随机种子（数据划分 + 丢弃掩码）。
- 判据：在 5/10-shot 或 40% 丢弃下，完整流水线的 AURC 显著优于 −本体（配对 Bootstrap CI 下界>0），且优于 B2。
- 成本：低（每次训练是单次 LiNGAM + GAM；重复 × 种子，CPU 数小时）；产出：一张"资源-增益"曲线，可直接作为论文主图。

**E2 剂量-反应与变点（把 RCA-032 升级为正式实验）**
- 假设 H2：marker→症状响应在 sev87 附近存在机制切换；H3：部分变量（WFWA/WSTA/P）在扫描中饱和，静态模板假设失效。
- 设计：severity 作连续暴露，分 regime（断点前/后）估计剂量-反应曲线（GAM/分段回归 + Bootstrap）；对每个关键边做变点检验与单调性检验（isotonic 回归 vs 无约束的似然比）。
- 指标：变点位置与 CI、各 regime 的斜率与符号、饱和平台估计；对 §4.2 冻结关系逐条判定"支持/不支持/证据不足"。
- 判据：能给出比"方向一致率"更细的机制表（哪条边在哪个严重度区间成立）。
- 成本：低–中（纯统计分析，不需重跑学图）。

**E3 开集与拒识（让"弃权"成为一等公民）**
- 假设 H4：在开集（未见类/正常工况）下，拓扑通道的拒识能力优于相关性基线。
- 设计：Normal 多场景（需补仿真，或先用现有 1 条 + 变功率窗口构造伪正常样本）、LOCAC 5 条作未见类原型（样本太小，只作探索）；比较 E3_path / B1 / B2 的 AURC 与"错误接受率@固定弃权率"。
- 判据：AURC 显著更低；或至少在"错误接受率"上占优。
- 成本：低（若只做现有数据）；需要新仿真则列为可选。

**E4（可选）A/B 侧定位**：用 LSGA−LSGB 非对称做"SGA 侧 vs SGB 侧"二分类。现有数据只有 SGATR（A 侧），无法验证；除非补 SGBTR 仿真。列为第二阶段可选项。

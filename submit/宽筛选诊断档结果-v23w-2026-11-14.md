## 6. 关键风险（如实保留）

1. **LOCA `p=30` > 训练轨迹 25/26/28**（签名 `n_train_trajectories` 实测）。变量数超过样本数，
   DirectLiNGAM 欠定；这是 LOCA 稳定边 294–347、`max|w|` 1940 的直接解释。
   **W3 的“p 上限 30”与“轨迹 25–28”两条依据本身矛盾**。
2. SGATR `p=18` 未欠定，但结构指标仍整体高于 v23（稳定边 ×1.6–1.7，`max|w|` 最高 465）。
3. FLB 退化闸按预期工作；其 wide 结果**就是** v23 结果，不能算“宽档独立证据”。
4. 本档未做 LLM 逐模板判定（第 8 步为 rule 后端）；四态分布不适用。

## 7. 失效范围

- `v23-20261112T185258` **不作废**；它仍是 p=15 口径下的可引用结果。
- 但以下表述需区分口径，不能混用：
  - “候选集 15”只适用于 v23 档；wide 为 30/18/15（LOCA/SGATR/FLB）。
  - 任何“Top-1 / 稳定边 / cond / max|w|”的对照，必须注明 `v23` 或 `wide`。
  - 真值可达性、Top-5 对照若引用 wide，需重新生成，不能沿用 v23 结论。
- 3 个 wide run 与 A 阶段 run 均为 `citable=null`，不刷新 `latest`。

## 8. 结论

- 四项数值门全过，但 **LOCA 处于 `p>n` 欠定区**，且宽档使稳定边与 `max|w|` 显著恶化；
  不能据此把 wide 升为主口径。
- **维持 `v23` 默认与唯一可引用口径**；wide 仅作诊断留档。
- 若继续宽档，需用户先裁决是否把上限改为 `p ≤ n_train_trajectories`（规则变更，本次未改）。

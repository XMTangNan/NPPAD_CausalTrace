# NPPAD-CausalTrace v2.1 实施进度与结果汇报

> **数据集**：NPPAD（PCTRAN 仿真）——LOCA/SGATR/FLB 三类各 100 条 + Normal/1
> **方法身份**：CausalTrace（AAAI-26）神经符号因果分析流水线的**变体复现**（GAM-ANM 替代 DiffAN；代码本体替代 RDF/Neo4j）
> **日期**：2026-11-03

---

## 一、结果

### 1.1 核心结论

v2.1 全链路实施完成，**工程可靠性高、科学结论弱**：

- **FULL 条件 100% 正确**——但这是 marker 直接泄露类别的数据特性，仅作 sanity，不构成方法贡献。
- **MASKED 条件（掩蔽 marker）**：Overall=0.500、Selective=0.938@Coverage=0.533。
- **D0 门控**：纯因果通道 E3_base 不优于 Pearson 基线 B1（Δ̄=−0.167，CI 含 0），主证据冻结为拓扑通道 E3_path。**本复现未发现因果签名相对相关性方法的识别增量**。
- 因果签名的真实价值在**可解释传播链与物理真实性检验**，而非分类准确率。

### 1.2 关键数字

**正式评估（60 条测试）**

> 指标说明：**Overall**（总准确率，弃权=错误）；**Selective**（选择性准确率，仅在接受预测的样本上算）；**Coverage**（覆盖率，被接受预测的样本占比）；**Abstention**（弃权率）。四者关系：Overall ≈ Selective × Coverage。

| 条件 | Overall | Selective | Coverage | Abstention |
|------|--------:|----------:|---------:|-----------:|
| FULL | 1.000 | 1.000 | 1.000 | 0.000 |
| MASKED | 0.500 | 0.938 | 0.533 | 0.467 |

- MASKED 逐类 F1：LOCA=0.743、SGATR=0.919、FLB=null（弃权率 0.90）

**D0 门控（MASKED-高严重度 18 条）**

| 通道 | 准确率 |
|------|-------:|
| E3_base（π 加权符号一致率） | 0.667 |
| E3_path（传播前沿级联，拓扑） | 0.667 |
| B1（Pearson 最近类） | 0.833 |

**三基线对照**

| 基线 | FULL | MASKED |
|------|-----:|-------:|
| B0（marker 规则） | 1.000 | N/A |
| B1（Pearson） | 0.933 | 0.933 |

B0/B2 亦满分 → 该仿真三分类任务本身高度可分。

**消融**：−E2→0.217（E2 是决定性分量）；−本体 Δ=0、−过程本体 Δ=0（知识层无分类增量）。

**传播链**：92 条，忠实性校验全过；方向一致率 LOCA=0.50、SGATR=0.00、FLB=0.75。

### 1.3 独立复核发现（对原报告的重要修正）

对原始 CSV 直接复算，发现三处需修正：

1. **尺度病态**：共享基线 σ 极小，z 高达 156~3.1×10⁴（如 LSGA z=863、WSTA z≈−3.1×10⁴）。E2 余弦与 B1 Pearson 被 1–2 个饱和维支配，二者信息同源。
2. **SGATR 方向一致率=0 的归因错误**：原报告称"LSGA 饱和反转"。复核显示 LSGA 单调上升，负号来自 **sev87 处 marker WTRA 机制断裂**（88.28→71.99，全扫描最大跳变）+ high 组跨断点 + 病态尺度的合成伪影，不是物理反转。
3. **严重度扫描不是干净剂量阶梯**：LOCA WLR 非单调（sev21 尖峰 262）、FLB WFWA 在 sev≥10 归零、SGATR sev87 断裂。9 模板"组中位数=母体期望"假设不成立。

## 二、过程：流水线与主要方法

### 2.1 流水线总览（R0~R5）

```
多事故轨迹（LOCA/SGATR/FLB 各 100）
    │
[R0] 数据审计 + 轨迹级分层划分 + 共享准 Normal 基线（sev-1 恢复段池化）
    │
[R0.5] 神经符号知识层：代码本体（4.2 冻结关系）+ 过程本体（μ±3σ 公差）+ 提示模板
    │
[R1] 逐类构建因果签名 Σ_k（3 类 × 低/中/高 = 9 模板）
    │   ├─ LiNGAM 引擎：100 次轨迹级 Bootstrap → 稳定边 + 总效应 T=(I−B)⁻¹
    │   └─ GAM-ANM 引擎：50 次 Bootstrap → 边际效应方向
    │
[R1.5] 反事实验证环（Alg3）：do(marker=基线) 重演，gCF 门控（不进分类分）
    │
[R2] 匹配器（测试侧零学图、零标签）
    │   ├─ E1：marker 非零规则
    │   ├─ E2：异常模式相似度
    │   └─ E3：因果反演（base=符号一致率 / path=传播前沿级联）
    │
[弃权] A(x)=∅ / max s<τ / margin<δ → 弃权（τ=0、δ=0.025 由留一标定）
    │
[R3] 两条件评估：FULL / MASKED × 低/中/高 × Normal 弃权
    │
[R4] 三基线：B0 marker 规则 / B1 Pearson / B2 XGBoost
    │
[R5] 传播链（marker 根 BFS + 双引擎 RRF 排序 + 忠实性校验 + LLM 解释）
```

### 2.2 主要方法

| 方法 | 说明 |
|------|------|
| **双引擎因果发现** | LiNGAM（线性/非高斯）+ GAM-ANM（非线性加性噪声）；边共识三分类（共识/冲突/单边） |
| **轨迹级 Bootstrap** | LiNGAM 100 次、GAM 50 次；产出稳定边、π 同号率、四指标 |
| **9 模板分组签名** | 类×严重度组，解除严重度混杂；匹配对 9 模板取 max |
| **E3 双版本 + D0 门控** | E3-base（符号一致率）与 E3-path（图拓扑前沿级联）；D0 冻结主证据归属 |
| **反事实门控（Alg3）** | 留出重演 do(marker=基线)，gCF∈{1,0.5} 调制权重，不进分类分 |
| **弃权机制** | A(x)=∅ 强制弃权 + 置信度/歧义双阈值（留一标定） |
| **神经符号三环节** | ①本体约束（删 forbidden 边）②过程本体公差（μ±3σ）③LLM 因果图提示注入 + 忠实性校验 |

### 2.3 v2.1 相对 v2.0 的关键修正

v2.0 首跑经全链路审计发现 21 项缺陷（RCA-012~032），v2.1 全面重构：

- 共享基线切 520~2030s 恢复段、排除 marker/安注、σ≈0 跳过（无数值兜底）
- 测试侧零因果建模、零标签 target、零自标准化
- 学图窗改 [60,1500]s（含注入瞬态），修复 marker 伪方向
- marker→症状符号以轨迹级 GAM C^A 为主（修复同期 SEM 滞后反号）
- 三基线重写为 B0 marker 规则 / B1 Pearson / B2 XGBoost

## 三、下一步研究计划

v2.1 的负结果不能直接断言"因果方法无效"。准确率上不去至少有三类可能原因：数据本身的特性（尺度病态、marker 泄露类别、设计点非 iid）、评价协议的缺陷（E3 与相关性基线同源同义反复、单工作点精度不可比）、以及论文复现不完整（GAM 预算降配、未实现 DiffAN 与知识图谱）。

因此下一步的首要任务不是继续调参，而是先排除数据尺度与评价协议的混淆、补全复现，再判断因果方法本身是否有增量价值。主要方向：构建统一稳态正常基线替代当前瞬态 Normal；将 marker 从单值一对一扩展为集合，支持一 marker 多故障的可辨识性分析；将签名升级为结构化七元组并补充多维证据与弃权机制；同时调研其他 RCA/异常检测论文的方法与实验设计，改进现有方法和评价协议。

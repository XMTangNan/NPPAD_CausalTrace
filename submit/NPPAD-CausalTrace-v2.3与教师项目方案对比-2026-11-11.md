> **对比对象**：本方案 NPPAD-CausalTrace v2.3（含 v2.1 冻结链路） × 教师项目
> `故障溯源演示平台/nppad_rca_experiment/rca_experiment.py`（DirectLiNGAM 单一全局图 + 角色先验）
> **日期**：2026-11-11 初版；**2026-11-12 按生产档 run 同步**（见 §11 更新记录）
> **性质**：对比 + 口径同步。已按用户裁决同步：取消遮蔽（V23-DESIGN-056）、指标分层（V23-DESIGN-057）、教师真值取证结论（本文 §10）、统一尺度切换（V23-DESIGN-087）、100 次档生产结果（V23-DESIGN-089）。

> 只用于机制诊断，不进结论句，**不与教师侧并排比较大小**；**18 项诊断指标已撤出结果层**。
>
> **数字引用符号**（全文统一，逐表再标一次）：

## 0. 先说清：同任务，数字不可比

两边做的是**同一件事**：已知事故类别、给定一条事故轨迹，回答“这一次是哪个变量先出问题”，
即**事故内变量级根因排序**。任务定义上没有差别（历史表述“两个方案做的不是同一件事”作废，依据 V23-DESIGN-036/055）。

他使用的判据是“变量榜 vs 类级真值集”的 Hit@k / MRR 族；我方自 2026-11-11 起把这族整体降为**附录诊断**，
主表改为稳定性 / 结构健康度 / 机理一致性（V23-DESIGN-057）。因此两边连“分数属于哪一层”都不同。

但**数字不能并排**——不是任务不同，是测量协议不同。三条具体差异：

| 不可比项 | 教师项目 | 本方案 v2.3 | 后果 |
|---|---|---|---|
| 候选集 | 57 变量全局单图（`DOMAIN_FEATURES` 59 剔 `WLPI`/`EBK`），12 类共用 | 每模板 15 变量（96 通道经 V0–V7 门控），9 张图 | 分母 57 vs 15，同一个“未进前 3”含义不同 |
| 真值可达性 | 真值始终在候选内（57 含全部 LOCA 注入变量） | 15 候选由变量选择决定：LOCA 的 `WBK`/`MBK` 被阶段2评分淘汰，该类 3 个真值只 1 个可达 | 我方 LOCA 的 Recall@3 结构上限 0.3333；命中低有一部分不是排序问题 |
| bootstrap | 3 次（出现率分辨率 1/3） | 正式 100 次（`121858/100` 已实跑）/ 执行默认 5 次（分辨率 1/100 或 1/5） | 稳定边集合不同，图上一切下游数字都不对齐 |
| 标准化/尺度 | 变量级 `build_scale`：`Normal` 稳健尺度与 `1%·全距` 取大，**12 类共用一个数** | `unified`：每模板训练段池化 `mean/std(ddof=0)`，无 floor；另做 `cond(I−B)` 与截断守卫 | 尺度来源不同，系数不可直接对读 |

1. **候选集**：他是 57 取前 k，我们是 15 取前 k。小候选集里“没进前 3”更接近“排序错”，大候选集里更接近“被稀释”。
2. **真值可达性**：他 57 个候选含全部真值；我们 15 个候选过 V0–V7 门控，`WBK`/`MBK` 属评分淘汰、不在候选内。分母里“可命中真值数”不同，Recall 类指标天然不同。**遮蔽已于 2026-11-11 取消**，不再是原因；旧 14 候选的 0 值随 V23-DESIGN-056 作废。
3. **bootstrap**：3 次下 `freq≥0.5` 实际等于“≥2/3”，100 次下 `≥0.70` 是另一个门；5 次档又只能取 `{0,.2,.4,.6,.8,1}`。档位不同，稳定边就不同。**我方自己的 5→100 对照已经证明这一点**：`v23sw/5` → `121858/100` 后，`LOCA_high` 的 Top-1 由 `VOL` 变 `LVPZ`、Top-5 换 4 席、稳定边 60→43；`FLB_low` 的 Top-1 由 `DNBR` 变 `WFLB`（稳定边 61→62，几乎不变）。因此“单次 Top-1”不能作为任何一方可信度的证据，只能引 100 次档并同时给稳定性区间。

**指标族两边都有对应物**：他有 `MAP@3 / P@2 / P@3 / Recall@3 / MRR / Jaccard@3 / Hit@1 / Hit@3`
（`metrics_for_ranking` L513–542），我们有同式 8 个（`evaluation.ranking_metrics`：`ap3/p2/p3/recall3/mrr/jaccard3/hit1/hit3`），
但在我方已全部划入 `diagnostic`。**不存在“他多一个准确度指标”这回事**，也不存在“我方命中率更高/更低”这回事——我方不主张准确率。

**一句话概括**：同任务、同指标族、不同测量协议、不同指标层级。可以讨论方法论差异，但不能把两边数字并排列出来比大小。

## 1. 逐环节对比

### 1.1 变量选取：先验定全集 vs 数据+物理约束筛子集

| | 教师项目 | 本方案 |
|---|---|---|
| 入口 | `DOMAIN_FEATURES` 59 项 → 数据列 59/59 命中 → `learn_graph` 内按 `var>1e-12` 去掉 `WLPI`、`EBK` → **57** 入图（`run_info.json`：`feature_count=59`、`graph_notes` 记剔除两项） | 96 通道 → 阶段0 论文锚定（候选优先 + `ANCHOR_SCORE_BONUS=0.15`，非保护集）→ 阶段1 硬过滤（σ<1e-6、缺失>50%、全零）→ 阶段2 评分（CV 0.25 + 非高斯 0.20 + 轨迹级 MI 0.30 + 区分度 0.25）→ 阶段3 物理校验（强制触发/关键响应、子系统覆盖、`|r|≥0.99` 去重）→ 阶段4 VIF 迭代（`VIF_MAX=500`，N 15–25） |
| 门控 | 无逐类筛选，12 类共用 | V0 论文锚定记账 / V1 变量数 15–25 / V2 子系统覆盖 / V3 VIF / V4 触发变量 / V5 物理链完整 / V6 选取客观性 / V7 非高斯诊断 |
| 结果 | 一张 57 列矩阵，全部类型共用 | 每模板 15 个（`gate_ratio=0.1562`），9 模板；类内三组变量集完全相同（Jaccard=1.000，9/9 对） |
| 可辩护性 | 靠“领域特征表”这一层人工声明 | 每个变量有入选/剔除记录（`selection_report_*.json`），真值去向可回答 |

**差别**：他是“知识定全集”，我们是“数据定子集 + 物理约束兜底 + 逐类留痕”。他的集合不对称地保证了真值可达（57 含全部 3 个 LOCA 真值），我们的集合换来了候选更小、每类可解释，但把 `WBK`/`MBK` 挡在门外。
**代价**：我们的 LOCA 在 C15 下 Recall@3 上限只有 0.3333；他的 57 变量候选规模是我们的 3.8 倍，稠密图上排序被稀释（§2.5 实测）。

### 1.2 建图：一张全局图 vs 九张逐模板图

| | 教师项目 | 本方案 |
|---|---|---|
| 图数 | **1 张**（`main()` 只调一次 `learn_graph`，`evaluate` 对 12 类共用同一 `graph`） | 9 张（3 类 × low/mid/high），每模板独立建图 |
| 训练矩阵 | `Normal/1.csv` + 每类最多 4 个文件拼接，`max_rows=5000` 抽样，`analysis_rows=300` | 每模板训练轨迹（`train_template_severities`），学图窗 `[60,1500]`（`LEARN_WINDOW`，145 点/轨迹） |
| 规模 | 57 节点、191 条保留边（`run_info.json`） | 15 节点，稳定边 31–74（`121858/100`） |
| 标准化 | `build_scale`：`max(robust_scale(Normal 前 300 行), 0.01·global_range)`，变量级、12 类共用 | `unified`：每模板训练段池化 `mean/std(ddof=0)`，逐模板、逐变量；无 floor、无 MAD |
| 算法 | Bootstrap DirectLiNGAM（`causallearn`） | Bootstrap DirectLiNGAM（同算法） |

**差别**：单图把 12 类的量纲与工况混在一张图里，跨类共线性与近重复测点会同时进来；逐模板图保证“这一类的图只由这一类训练”，可回答“这条边属于哪个模板”。
**代价**：9 张图的计算量与产物量是 1 张的 9 倍；单图在跨类覆盖上更省，也是他能一次跑 12 类的原因。另外他的 `eval_files_per_type=all` 与 `train_files_per_type=4` 存在文件重叠，属于评测口径缺陷；我们严格互斥（`test_severities` 不进训练）。

**统一尺度切换的实测（2026-11-12，`121858/100`）**：旧三路口径下九模板 `cond(I−B)` 截断前最坏 **2.143e9**；切到 `unified` 后最坏 **494.7**（`SGATR_low`），其余模板 3.81–40.77。`max|w|` 除 `SGATR_low` 16.34 / `SGATR_mid` 14.35 外，落在 **3.18–5.62**。图拓扑未因换尺度改变（9/9 模板稳定边集合与旧口径相同），变的是系数尺度与 3 条边的稳定性。
**共线分裂的解读边界**：`SGATR_low/mid` 的 `NSGA`/`LSGA` 是同一物理量（SG-A 水位）的窄/宽量程通道，被回归劈成对 `PSGA`/`RM2`/`WSPY` 反号、近等幅的 ±13–17 系数。**`NSGA` 的 Top-2 名次不作物理强度解读**，两路应视为一个证据单元；签名产物 `redundancy_diagnostics` 只记录该标记，不参与排序（V23-CODE-035）。

### 1.3 bootstrap 与稳定边判据

| | 教师项目 | 本方案 |
|---|---|---|
| 次数 | **3**（产物）；代码默认 6 | **100**（正式口径，`N_BOOTSTRAP_SPEC`，`121858/100` 已实跑）/ **5**（执行默认，`N_BOOTSTRAP_DEFAULT`） |
| 边强度 | 跨次均值 `mean` | 跨次出现率 `freq ≥ STABLE_F=0.70` |
| 边频率 | `freq = mean(|B|>1e-10) ≥ 0.5` | 同上（`freq` 即稳定判据） |
| 稳定性 | `stability = 1/(1+std) ≥ 0.6`（std 为跨次强度标准差） | 无独立 stability 项，由 `freq` 承担 |
| 其它过滤 | `|mean| ≥ 0.03`；每子节点最多 5 个父 | `B_CLIP=5.0` 元素硬截断；`STABILITY_COND_MAX=1e4`、`STABILITY_CLIP_RATIO_MAX=0.35` 守卫 |

**差别**：他是“强度 + 频率 + 稳定性”三重复合门，我们是一条出现率门 + 截断守卫。
**代价（两边都有）**：3 次下 `freq` 只能取 `{0, 1/3, 2/3, 1}`，`≥0.5` 实际是“至少 2/3”，门偏松；5 次下出现率只能取 `{0, .2, .4, .6, .8, 1}`，`≥0.70` 实际等于 `≥0.8`（至少 4/5），比 100 次下的 `≥0.70` 更松。这一档位差是检索诊断值 0.9000→0.5833 的直接原因（§2.6），5 次因此只能作迭代档。
**100 次档已实跑（`121858/100`）**：正式结论只引这一档；5 次档（`v23sw/5`）只用于口径对照，二者 Top-1 已在 2 个模板上不同（§2.6）。

### 1.4 偏差度量：分母、参照物、聚合、不可比

| 维度 | 教师项目（`rca_experiment.py`） | 本方案（V23-CODE-030/033 之后） |
|------|-------------------------------|--------------------------------|
| 分母 | `build_scale`（L229–250）：`max(robust_scale(Normal/1.csv 前 300 行), 0.01·global_range)`，`global_range` 取 `Normal` + 每类最多 4 个文件的拼接；**变量级、数据集级，12 类共用一个数** | 每类 sev-1 注入前 `[0,100]` 共 **11 点**：`σ_robust = max(1.4826·MAD_pre, σ_floor(v))`；`σ_floor` 优先登记物理下限，否则 `1%·|μ|` |
| 参照物 | `Normal/1.csv` 前 300 行，**行位置对齐**（第 i 行对第 i 行）；窗口由 `detect_onset` 变点 + `pad=2` 起，长 300 | 每类 sev-1 注入前均值 `μ_pre`（class-level，非逐轨迹）；偏差统计段为整条轨迹 |
| 聚合 | `q95 + 0.25·mean`（`anomaly_scores` L261–273），`±inf/NaN→0`，**无截断** | `max|post−μ|/σ`；仅展示层 `min(d,10)` 截断 |
| 不可比处理 | 无此概念 | 三态：可算 / `not_comparable`（σ≤0 或回退下限且 MAD=0）/ 退化零通道（四条判据同时满足，`V23-CODE-033`） |
| 进入排序前 | `log1p` + 按最大绝对值归一 | **不进入主排序**；偏差只作 `diagnostic`（实验格的偏差排序见 §2.2 补充格） |
| 作用范围 | 全 57/59 列，先验只在最后一步乘 | 全候选列，无先验项 |

**差别**：他的分子相对于“群体正常工况”逐行对齐，分母是一个全局尺度——同一变量在 12 类、所有严重度上共用一个数，因此对单 case 的采样噪声不敏感，但也不反映该 case 的工况漂移。我们的分子/分母来自**每类 sev-1 注入前 11 个点**（class-level 公差），量纲与本类基线对齐、可解释，但**样本量只有 11 点，σ 偏薄**，只适合同变量内参考，不跨变量比较；σ 病态时靠 030/033 兜底。
**代价**：我们的 `d` 峰值仍到 `1.7e5`（C57 中位）/`5.6e5`（C57 最大）/`1.7e5`（C15 最大）（`150726/100`，A3 复算）；他的口径不会产生这种量级，因为他分母被 `1%·全距` 托住。另：偏差通道只在诊断层，不参与主排序（§1.5），所以该量级不进入任何名次。

### 1.5 排序量

| | 教师项目 | 本方案 |
|---|---|---|
| 公式 | `direct = normalize(log1p(score))`；`out = normalize(|T|·direct)`；`in = normalize(|T|ᵀ·direct)`；`max(0, 0.80·direct + 0.25·out − 0.10·in) × role_prior`（`rank_causaltrace` L490–502） | `total_effect(j) = Σ_{e∈E} |T[e,j]|`，`T=(I−B)⁻¹`，`B_CLIP=5.0`；`E = out_degree==0 的末端节点 ∪ 注入变量`；分数降序（实验格；生产 `causal` 通道另加“有传导者优先、孤立节点殿后”的拓扑后处理） |
| 先验 | `RESPONSE_VARS`（41 项）命中 ×0.30，其余 1.0；只乘权重不剔除 | 无先验（B1 独立开关，默认关闭） |
| 语义 | “偏差为主、传导为辅”的加权融合，先验负责压症状 | “候选变量对系统末端/注入变量的总效应”，纯结构量 |

**差别**：他的分数由偏差驱动，图只作 ±0.25/−0.10 的修正；我们的分数完全由结构决定，偏差根本不进排序。这解释了两边失败模式不同：他的排序对偏差口径（分母/参照/聚合）高度敏感，我们的排序对图密度与 `B_CLIP` 高度敏感。
**代价**：我们的总效应对无入边/弱入边节点不利——稠密图上注入变量只剩自项 `T[v,v]=1` 可累加（§2.5），这是留一法在该图密度下的真实局限，不是口径 bug。他的公式则对先验名单高度依赖：去掉先验即归零（§2.2 第 3 格）。

### 1.6 真值来源与粒度

| | 教师项目 | 本方案 |
|---|---|---|
| 来源 | **人工归纳、无引用、不可复算、类级常量**：`GROUND_TRUTH`（L35–48，12 类字典）来源仅 L33–34 两行注释（`derived from the NPPAD accident table and variable table`、`direct initiating-event variables, not exhaustive physical causes`）；无 citation、无外部标注文件；项目及上级目录非 git 仓库，加入时间与方式无历史可查。上游数据集 `NPPAD/` 18 个类目录无 README、无标注文件，根 README 元数据只有 `Folder name / Accident Type / Severity`，变量表 96 项**无根因列**；每 case 仅一份 `Transient Report.txt` 记 `Malfunction # N`，仓库不提供编号→变量映射，**无法用数据独立复算任何一组真值** | `injection_truth.INJECTION_TRUTH`，**本项目按事故机理指定的假设**，不是数据集标注；其中 10 类与教师表对齐（属继承，方案 §5.18） |
| 与自身算法输出的一致性 | **不一致**：其 Top-1 与真值重合 LOCA / LOCAC / MD = **0/100**，SGATR 50/100、FLB 45/100、RW 100/100、LLB 87/101 | —（我方真值不参与任何计算，无此问题） |
| 覆盖 | 12 类，含各仅 1 条数据的 `LOF`、`TT`；数据集有数据的 `SLBIC`、`SLBOC` 未纳入，另有 6 类未覆盖 | 3 类有数据 + LOCAC 描述性（n=5）；`LOF`/`TT` 标 `not_configured`、`SLBIC`/`SLBOC` 标 `no_truth` |
| 粒度 | 类级：同类所有轨迹共用一个真值集 | 类级（`ground_truth.scope=class_level`），同一约定 |
| 用途边界 | 只用于打分；但 `eval` 用 `all`，训练文件重叠 | 只用于打分；禁止参与选变量/建图/排序（`KeyError` 兜底，不回退 `key_responses`） |
| 可疑项 | LOCA 的 `WBK`/`MBK` 为可疑项 | 同样标注 `ground_truth.suspect`，仍计入真值集 |

**差别**：双方真值同属“人工假设”，但性质需分开写。我方是与教师表 **10 类对齐的继承**；教师表是**人工归纳、无引用、不可复算、类级常量**——上游数据集没有变量级根因，`Malfunction # N` 也无编号→变量映射，无法独立复算。且“由其算法结果反推”**已被证伪**：其 Top-1 与真值重合 LOCA/LOCAC/MD 为 0/100（§10）。
**因此双方所有命中类指标都只能读作“与假设的一致度”，不得作准确率**；此结论对双方同等适用。
**代价**：类级真值意味着指标回答“该类的根因变量有没有被排到前面”，不是“这一条轨迹的注入变量有没有排到前面”——这条必须和任何变量级数字一起写。

### 1.7 指标：对方的八指标 vs 我方的分层

### 2.7 这些对照能读出什么、读不出什么

**能读出**：
- 同一 C15 场地、同一 60 条上，他的先验名单携带信息（z=4.03–5.32，预注册判定），机制是排除非真值。

## 3. 双方优缺点

### 3.1 教师项目

**优点**
1. **角色先验携带真实信息**：A1 四指标全部越过随机 20 次上限（z=4.03/4.54/5.32/4.54），且换 `T` 构造判定不变（z=3.56）。
2. **抗单点尖峰**：`q95+0.25·mean` + 数据集级分母，使单条轨迹的极端采样点难以单独抬高某变量；其自评偏差通道 Hit@1 0.2322（`教师产物/3`，diagnostic，不可与我方并排）。
3. **工程简洁**：一张图、一个先验乘子、一条链路，12 类一次性覆盖，改一个数就能全量重跑。
4. **可读性强**：`0.80/0.25/−0.10` 的语义直观（偏差为主、下游传导加分、上游汇聚减分），运维人员容易接受。

**缺点**
1. **bootstrap=3**：出现率分辨率 1/3，`freq≥0.5` 实际等于“≥2/3”，稳定边门控基本失效；其自评 12 类混合 Hit@1 0.4368 里，LOCA/LOCAC/MD 三类为 **0.0000**（`教师产物/3`，diagnostic），说明单图 + 先验并非普适。
2. **单张全局图**：12 类混训，跨类共线性与近重复测点回潮；任何一条边都不属于某一类，无法回答“这条边是 LOCA 的还是 FLB 的”。且 `eval=all` 与训练文件重叠，存在信息泄漏。
3. **分母/参照不随 case 变**：同一变量 12 类共用一个尺度；分子与 `Normal/1.csv` 前 300 行**按行位置**对齐，隐含“采样相位一致”假设；换数据源或采样率即失效。
4. **先验是唯一支点**：去掉先验，他的公式在同一 C15 上 Hit@1 = 0.0000（③）。先验错一位，整条链就错，而名单本身没有逐变量的可审计依据（41 项一次性人工给定）。
5. **无不可比状态**：`±inf/NaN→0` 会把病态值静默抹平，报告里看不到“这个变量根本不可比”。
6. **真值无引用、不可复算**：`GROUND_TRUTH` 仅两行注释说明来自事故表/变量表，无 citation、无标注文件、无版本历史；上游数据集不含变量级根因（§10）。其命中数字只能读作“与假设的一致度”。

### 3.2 本方案 v2.3

**优点**
1. **主表不依赖真值、可复核**：稳定性（Top-k Jaccard、跨组名次标准差、秩相关）+ 结构健康度（VIF、条件数、稳定边比例、截断敏感性）在同一 run 上可重算；机理一致性留协议位（`pending_expert`）。100 次档九模板 `cond` 截断前最坏 494.7、截断后最坏 105.3，7/9 模板 `max|w|` 在 3.18–5.62。
2. **逐类变量集可辩护**：V0–V7 八道门控 + `selection_report` 逐变量去向，真值可达性可审计（三类 `gate_blocks_truth=false`，`WBK`/`MBK` 是评分淘汰而非门控剔除）。
3. **偏差口径可解释、有第三态**：每类 sev-1 注入前 11 点 `σ_robust`、`not_comparable`（030/033）——病态值不会被伪造成巨大数参与排序；11 点样本偏薄这一点已如实写入局限。
4. **划分干净**：只取 `test_severities`，训练模板不进评测；`run_id` 贯穿全部产物，只读可复核。
5. **多通道诊断（diagnostic）**：四通道 + `B_CLIP` 四列 + 名次分布（B3），能区分“没找对”与“根本不在候选里”，但不作成绩。
6. **解释层完整且不干扰排序**：rule 报告 + LLM 逐模板判定（`121858` 为 9/9 `llm_verified`、0 兜底），并带固定声明“名次≠物理强度、共线分裂不作物理强度解读”。

### 3.3 本方案弱在哪（不淡化）

1. **先验缺位**：主排序没有任何角色先验。旧口径诊断里，我方总效应 0.1000/0.3167 低于对方“公式+先验”的 0.3167/0.7333（`150726/100`，diagnostic）；B1 默认关闭。**这不是“我们更差”的结论**——该族已降为诊断，且两边候选集不同（§0）。按现行协议，变量级这一层我方**没有可引用的数字**，也不打算有。
2. **57 变量图总效应被稀释**：去遮蔽后真值仍 26–51 名，注入变量只剩自项 1.0；稠密图（154–546 边）对无入边节点系统性不利（`C57-Q5`，内部对照）。
3. **变量级命中低（取消遮蔽后仍低）**：15 候选下 Hit@1 0.1000（`015705/5`，diagnostic）；且 LOCA 的 `WBK`/`MBK` 被评分淘汰，该类真值 3 个只 1 个可达。凡引用变量级数字，必须同时写“diagnostic、不可作准确率、真值非独立”。
4. **V3 三类仍 fail**：去重后 offenders 全是保护变量（LOCA `VOL`=2161.6、`RRCA`=1271.0 等），按豁免式 pass 逐项披露、不改阈值——即“VIF 没过，只是被豁免”。
5. **8 类无数据**：代码层 12 类适配完成，数据层只有 3 类 + LOCAC 描述性（n=5）；主表只能出现 3 类数字。
6. **检索诊断对 bootstrap 次数高度敏感**：0.9000→0.5833（100→5），该指标已停用（055），此条只作档位说明。
7. **`B_CLIP` 敏感**：变量级 Hit@1 在 clip3/clip5/clip10/clip_off 上取值 {0, 0.10}，唯一的 1.0 命中（LOCA_high）在去截断后归零；变量级命中只能作可辨识性证据，不能作准确率主张。
8. **机理一致性暂时不可给**：无外部物理专家判据输入，`mechanism_consistency.status=not_available`，违反率/覆盖率均为 null（§7.9 只给协议）。
9. **Top-1 对 bootstrap 次数敏感（我方同样存在）**：5→100 次档有 2/9 模板 Top-1 改变（`LOCA_high`、`FLB_low`），`LOCA_high` 稳定边 60→43。因此我方也**不以单次 Top-1 作可信度证据**，只引 100 次档 + 稳定性指标；这条同时限制了我们批评对方“3 次档不够”的力度——是协议问题，不是对方独有的缺陷。

## 5. 与现有文档不一致的四处（只指出，不改原文档）

以下四处在方案/报告/实验 REPORT 与代码或产物之间存在口径冲突。本文按**代码与产物**为准书写，原文档留待统一同步。

1. **“教师项目强在检索（类别级）命中”** —— 方案 §9.4 开头。教师代码没有类别级检索：`evaluate()` 对每个 `GROUND_TRUTH` 类分别排变量榜，没有“模板池”或“类别榜”。他的任务始终是**事故内变量级排序**。本句若保留，会让读者以为两边主指标可比。
   依据：`rca_experiment.py` L545–628 `evaluate()`；`run_info.json` 无任何检索/分类产物。

2. **第 7 格作废理由②“与其‘每类一图’口径不符”** —— `absorption_A` §6.2、结项报告 §7。教师代码只建**一张全局图**：`main()` 用 `build_training_matrix`（L723–730）混合 Normal 与全部类目录，只调一次 `learn_graph`（L731–739），再把这个 `graph` 传给 `evaluate`（L741–749）；产物 `run_info.graph_edge_count=191`、单张 `learned_edges.csv`（56 节点）。因此“每类一图”不成立，理由②失效；理由①（`learned_edges.csv` 无类别列）在单图口径下也不再是障碍。
   **仍然成立的真实阻碍**：他的 `per_case_top10.csv` 只落盘**乘过** `role_prior` 的 `score`，未乘先验的 `direct/outgoing/incoming` 未落盘，无法反推“无先验”排序；且 `data_root` 为 `D:\NC\...`，WSL 下不可达，偏差无法重算。**结论（该格作废）不变，理由需改写。**

3. **对方真值的来源已取证：人工归纳、无引用、不可复算** —— 方案 §9.4.1 N1、结项报告 §2 曾以“名单参与构造真值、构成循环”论证 N1，该假设**已被证伪**（LOCA/LOCAC/MD 其 Top-1 与真值重合 0/100，§10）；`RESPONSE_VARS` 注释也声明与 `GROUND_TRUTH` 独立（L51–58），A1 核出零交集。
   N1 仍然成立，但理由改为：先验是人工角色判断，与因果结构估计是两个信息源，混入主排序会让指标语义不可分。真值本身无 citation、无标注文件，命中类数字只能读作“与假设的一致度”。

4. **`S_ours` 的下标写法** —— `factorial_2x2` REPORT §1 写作 `Σ_i |T[v,i]|`（转置），而 `c57_total_effect` REPORT §1 与脚本 `c57_total_effect.py`（`ranking_quantity` 字段）都是 `Σ|T[i,v]| over (out_degree==0 的末端节点 ∪ 注入变量)`。本文按脚本/`c57` 报告书写：`total_effect(j) = Σ_{e∈E}|T[e,j]|`。数字不受影响，属文档笔误。

> 第 2 条影响“作废理由”的表述，第 3 条影响 N1 的论证链，第 1 条影响 §9.4 的结论句。三者都只需改文字，不需重跑、不改数字。

## 10. 取证记录：教师真值来源（2026-11-11）

**结论**：教师 `GROUND_TRUTH` 是**人工归纳的类级常量假设**，不是数据标注；它不由其算法结果反推（该假设已被证伪），也无法用上游数据独立复算。

**已核实事实**

1. `GROUND_TRUTH` 位于 `nppad_rca_experiment/rca_experiment.py` L35–48，12 类字典；来源仅 L33–34 两行注释：`derived from the NPPAD accident table and variable table`、`direct initiating-event variables, not exhaustive physical causes`；**无 citation、无外部标注文件**。
2. 教师项目及其上级目录均非 git 仓库，真值加入时间与方式**无历史可查**。
3. 上游数据集仓库 `thu-inet/NuclearPowerPlantAccidentData`：`NPPAD/` 下 18 个类目录，**各类目录内无 README、无标注文件**；根 README 元数据只有 `Folder name / Accident Type / Severity`（LOCA 的 severity 单位是 `% of 100 cm2`），变量表 96 项，**无根因列**。
4. 每 case 仅一份 PCTRAN `Transient Report.txt`，记录 `Malfunction # N`（LOCA=#1、LOCAC=#2、SGATR=#10、FLB=#13 等），**仓库不提供编号→变量的映射**，故无法用数据独立复算任何一组真值。
5. 真值为**类级常量、不随 severity 变化**；覆盖 12 类，含各仅 1 条数据的 `LOF`、`TT`；数据集有数据的 `SLBIC`、`SLBOC` 未纳入，另有 6 类未覆盖。
6. **真值与教师自身算法输出并不一致**：LOCA、LOCAC、MD 三类其 Top-1 与真值重合 **0/100**；SGATR 50/100、FLB 45/100、RW 100/100、LLB 87/101。因此“真值由其算法结果反推”**不成立**。

**据此写进本文的口径**

- 双方真值同属“人工假设”，但性质分开：我方与教师表 10 类对齐，属**继承**；教师表是**人工归纳、无引用、不可复算、类级常量**。
- 双方所有命中类指标只能作“与假设的一致度”，**不得作准确率**；此结论对双方同等适用。
- 教师侧 `Hit@1 = 0.4368` 等数字必须在同样限定下引用，不得作为“他的方法更准”的证据。

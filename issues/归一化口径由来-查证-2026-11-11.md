## 3. `sigma_shared` 的确切来源

### 3.1 代码与数据

`Code/causalrca/data/loader.py:255-292`：

```python
def fit_shared_baseline():
    """三类 sev-1 恢复段 [520,2030] 池化（不含 marker/WHPI/WECS），估计 mu/sigma。"""
    for k in ACCIDENT_TYPES:
        for sev in BASELINE_SEVERITIES:
            X, cols, t = load_window(k, sev, BASELINE_WINDOW_START, BASELINE_WINDOW_END,
                                     PHYSICAL_CANDIDATES)
            assert len(t) == 152
            blocks.append(X)
    pooled = np.vstack(blocks)
    mu, sigma = pooled.mean(axis=0), pooled.std(axis=0)
```

## 5. 两种做法在同一张图上的差异会体现在哪

### 5.1 尺度变换的代数事实

设新尺度为 `s'_v = k_v·s_v`（`k_v>0`），则新 `Z'_v=(x−m_v)/(k_v s_v)=Z_v/k_v`。若因果顺序不变且各变量回归为精确线性，则

- `B'[i,j] = B[i,j]·k_i/k_j`
- `T'=(I−B')⁻¹ = D_k T D_k⁻¹`，即 `T'[i,j]=T[i,j]·k_i/k_j`，`D_k=diag(k)`

这是矩阵恒等式，不涉及估计好坏。实际 `DirectLiNGAM` 含有限样本与独立性度量，**因果顺序是否随尺度改变，无法从代码断言**（不确定）。

# 统一尺度对照实验（取证记录，不是结果）

> 本文是**实验取证/对照记录**，不是结果成绩单，也不下"哪个口径更好"的结论。
> 结论与处置以 `Code/error_tracking.md` 的 **V23-DESIGN-085/086** 与 **V23-CODE-034** 为准。
> 本实验由用户批准（"统一尺度"），在查证文档 `issues/归一化口径由来-查证-2026-11-11.md` 之后执行。

## 1. 实验设置

| 项 | 取值 |
|---|---|
| 变体 A `unified` | 全部建模变量按**本模板训练段池化 mean/std(ddof=0)** 标准化（替代三路） |
| 变体 B `unified_keep_injection` | 除注入变量（marker）仍走 `x/median_platform` 外，其余同 A |
| 控制组 `current` | 生产三路口径（V_thr 用跨类 shared μ/σ；marker 用平台中位数；图专用变量模板内尺度） |
| 模板 | LOCA / SGATR / FLB × low / mid / high，共 9 |
| bootstrap | `n_bootstrap=5`（测试档；`run_mode=reduced`，即 `RUN_MODE_TEST` 别名） |
| 可引用 | `citable=null`（未声明，等同不可引用） |
| latest | **未刷新**；三组均无 `manifest.json`；`output/latest` 仍指向 `v23-20261111T022417` |
| 生产 run | `v23-20261111T022417*` 未改动、未重跑 |
| 开关 | `run_v23_all --normalization {current,unified,unified_keep_injection}`（默认 `current`）、`--no-latest`、`--run-prefix` |

三组 run：

| 组 | run_id |
|---|---|
| 现口径（控制） | `v23nC-20261111T231028` |
| 变体 A | `v23nA-20261111T231103` |
| 变体 B | `v23nB-20261111T231136` |
| 生产参考（100 次） | `v23-20261111T022417` |

> 控制组为本轮自主补充：生产 run 是 100 次档，直接与之比对会把"bootstrap 次数差异"误读成"尺度差异"。
> 因此对照基准取"同 5 次、仅归一化不同"的 `v23nC`；生产 100 次档单列做参考（表 4）。

复现（`cd Code`）：

```
PYTHONPATH=. ../.venv/bin/python -m causalrca.cli.run_v23_all --n-bootstrap 5 \
  --classes LOCA SGATR FLB --groups low mid high \
  --normalization unified --no-latest --run-prefix v23nA \
  --rerun-reason E-R2:V23-DESIGN-085:unified-scale-A
```

明细 JSON 与提取脚本在 `Code/experiments/unified_scale_compare.{py,json}`（该目录被 gitignore，仅脚本；结论以本文为准）。

## 6. 失败与异常（如实记录，未换参数凑结果）

1. **三组运行均在第 8 步 `explanation_reports` 失败**，导致第 9 步 `evaluation`、第 10 步 `manifest` 未执行：
   - 报错：`RuntimeError: 解释/报告未全成功：... rule 后端汇总解释未通过忠实性校验（实现缺陷）`
   - 未支撑 token：`V23`、`DESIGN`、`063`、`7.10`；根因在 `llm_explanation.py:1270/1295` 把
     "V23-DESIGN-063，见方案 §7.10" 写进了类级汇总文本，被 `verify_faithfulness` 当作
     未支撑变量/数字。
   - **该失败在控制组同样出现**，与归一化无关，是文档口径同步后的回归；已登记 `V23-CODE-034`（open），本轮不修。
   - 本实验所需的 `signatures/` 与 `tracing/` 产物在第 4 步已完整落盘，不影响表 1–3 的取值。
2. **未观察到收敛/报错类失败**：A/B 的 LiNGAM 拟合与求逆均正常返回；`cond` 有 `None` 之外的有限值。
3. **未观察到拓扑变化**：9/9 模板稳定边集合与现口径完全相同。这与"绝对阈值 |B|>1e-10 换尺度会改拓扑"
   的先验担心不符——本批 9 模板中 `|B|` 远离 1e-10，支撑集未翻转；该阈值对尺度敏感的风险仍成立，
   只是本批未触发，不能据此宣称"换尺度一定不改拓扑"。

## 7. 三处方案与实现不一致（只登记待修，本轮未改文档）

据 `issues/归一化口径由来-查证-2026-11-11.md`：

1. 方案写"逐类 sev-1 基准的稳健 σ（μ/σ_robust，含 σ_floor）"，实现是**跨类 456 点池化的普通 std、无 floor**；
2. 方案写"注入前基线标准化"，实现用**注入后恢复段 [520,2030]**；
3. 方案写"逐类基准"，实现是**跨类池化**（与第 1 条同源但需分别改）。

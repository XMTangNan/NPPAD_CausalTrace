## 1. 规则（一次写死，不随结果调整）

| 步 | 规则 |
|---|---|
| W1 | 阶段1 质量门不变 |
| W2 | 阶段2 不按评分截断（`TOP_K` 不参与） |
| W3 | 每子系统保留 Q=2 个别名组代表（评分最高，同分字母序） |
| W4 | 别名：逐位相同 或 `|Pearson r| ≥ 0.999`（union-find，不回流） |
| W5 | 上限 **`p ≤ n_train_trajectories`**（变量数不得超过该模板训练轨迹数）；超限裁非 `forced`，落 `cap_trimmed` |
| W6 | V1 契约：v23 15–25；wide 15–`n_train_trajectories` |

**W5 的理由**：变量数超过轨迹数时协方差奇异、DirectLiNGAM 欠定。原"上限 30"与
"每模板 25–28 条轨迹"自相矛盾，LOCA（保护集 24 + forced/锚定 → 30）即该矛盾的实例。

**Q=2 的依据只有两条**：每模板 25–28 条训练轨迹（`p` 接近/超过轨迹数时 VIF 不稳定）；
每子系统至少 2 个独立测点。文档与代码均不含"为接住某真值变量"的动机。

**规则收口（`V23-DESIGN-094`，2026-11-14，用户授权代行）**：W5 由"上限 30"改为
`p ≤ n_train_trajectories` 并删除对应依据；`v23w-20261114T173745`（LOCA，p=30）因此
**不成立**，其数值只作"欠定情形下的观察"；验收中的"同一别名家族 Top-5 ≤1 席"降为披露项。
**代码仍是 `WIDE_N_MAX=30`（本轮只改文档），改代码前不得再跑 wide。**

**数据质量闸**：合并后相关矩阵负特征值或 `cond > 1e12` → 该类 `degenerate_design=true`，
退回 v23（p=15），报告披露。

### 4.2 披露项（不计入通过，任何诊断档都不得计入）

| 项 | 实测 | 为何不具证明力 |
|---|---|---|
| 同一别名家族 Top-5 ≤1 席 | 0 违反 | 别名合并已保证每族只留 1 个代表，**结构性恒真** |
| 符号相反大系数对 | 0 | `redundancy_diagnostics` 只扫同物理量多量程，而 wide 已在候选层合并该类，**近乎恒真** |

两项只说明"没有触发各自那一类问题"，不能证明结构健康；LOCA_low 的 `max|w|=1940` 即反例。

## 5. 关键发现（已核实）

1. **LOCA `p=30` > 训练轨迹 25–28**（签名 `n_train_trajectories` 实测 25/26/28）。
   变量数超过样本数，DirectLiNGAM 处于欠定区间；这解释了 LOCA 稳定边膨胀到 294–347、
   `max|w|` 达 1940。**原 W5 的"上限 30"与"轨迹 25–28"两条依据在 LOCA 自相矛盾**：
   上限 30 本身已越过轨迹数。该矛盾已由 `V23-DESIGN-094` 修正（改为 `p ≤ n_train_trajectories`），
   因此该 run **不成立**，上述数值只作欠定观察。
2. SGATR `p=18` ≤ 25，未欠定；稳定边 50–113、`max|w|` 5.16–465，仍明显高于 v23。
3. FLB 退化闸按预期工作：`p=15`，三模板与 v23 结果逐项相同，说明回退路径可复现。
4. Top-1 改变：有效范围仅 SGATR **3/3 全部改变**、FLB 0/3（回退）；LOCA 的 3/3 属欠定观察。
   宽档对"主结论"不具稳定性。

## 6. 结论与边界

- 收口前"四项验收全过"的表述**作废**：其中两项（别名家族 Top-5、符号相反大系数对）为结构性
  恒真，已降为披露项；LOCA run 因 `p=30` 违反现行 W5 而**不成立**。
- 有效 wide 观察只有 SGATR（p=18），它通过两项数值门，但稳定边仍为 v23 的 ×1.6–1.7、
  `max|w|` 升至 465——"过门"不等于结构健康。
- 因此：**wide 不升格，维持 `v23` 为默认与唯一可引用口径**；`v23-20261112T185258` 不受影响。
  LOCA 的 wide 结果不得用于任何与 v23 的"同一候选集"比较。
- 继续宽档的前置：先按 W5 改代码（`p ≤ n_train_trajectories`）再重跑，属新任务；本轮
  **只改文档与台账、未重跑、未改代码逻辑**。

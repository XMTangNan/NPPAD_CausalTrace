## 1. 规则（一次写死，不随结果调整）

| 步 | 规则 |
|---|---|
| W1 | 阶段1 质量门不变 |
| W2 | 阶段2 不按评分截断（`TOP_K` 不参与） |
| W3 | 每子系统保留 Q=2 个别名组代表（评分最高，同分字母序） |
| W4 | 别名：逐位相同 或 `|Pearson r| ≥ 0.999`（union-find，不回流） |
| W5 | 上限 30；超限裁非 `forced`，落 `cap_trimmed` |
| W6 | V1 契约：v23 15–25；wide 15–30 |

**Q=2 的依据只有三条**：p 上限 30；每模板 25–28 条训练轨迹；每子系统至少 2 个独立测点。
文档与代码均不含“为接住某真值变量”的动机。

**数据质量闸**：合并后相关矩阵负特征值或 `cond > 1e12` → 该类 `degenerate_design=true`，
退回 v23（p=15），报告披露。

## 4. 四项验收（预声明）

| 项 | 阈值 | LOCA | SGATR | FLB | 结论 |
|---|---|---|---|---|---|
| 1 `cond(I−B)` 截后 | <1e4 | 1382.9 | 112.9 | 29.5 | 通过 |
| 2 `clip_ratio` | <0.35 | 0.078 | 0.140 | 0.016 | 通过 |
| 3 同一别名家族 Top-5 | ≤1 席 | 0 | 0 | 0 | 通过 |
| 4 符号相反大系数对 | 无 | 0 | 0 | 0 | **通过，但判据退化** |

**第 4 项必须加注**：`redundancy_diagnostics` 只扫描“同一物理量的多量程/冗余通道”这一类，
而 wide 已在**候选层**把这类成员合并掉，所以第 4 项在 wide 下**近乎恒真**。
它不能证明“不存在其他共线分裂”；LOCA_low 的 `max|w|=1940` 就是反例。

## 5. 关键发现（已核实）

1. **LOCA `p=30` > 训练轨迹 25–28**（签名 `n_train_trajectories` 实测 25/26/28）。
   变量数超过样本数，DirectLiNGAM 处于欠定区间；这直接解释了 LOCA 稳定边膨胀到 294–347、
   `max|w|` 达 1940。**W3 的“p 上限 30”与“轨迹 25–28”两条依据在 LOCA 自相矛盾**：
   上限 30 本身已越过轨迹数。
2. SGATR `p=18` ≤ 25，未欠定；稳定边 50–113、`max|w|` 5.16–465，仍明显高于 v23。
3. FLB 退化闸按预期工作：`p=15`，三模板与 v23 结果逐项相同，说明回退路径可复现。
4. Top-1 9/9 中 **8 个改变**（仅 FLB 因回退未变）。宽档对“主结论”不具稳定性。

## 6. 结论与建议（只给事实与边界，不写优劣）

- 宽档在**四项数值门**上全过，但 LOCA 处于 `p>n` 欠定区，结构健康度的“过门”不等于可用。
- 因此：**维持 `v23` 为默认与唯一可引用口径；wide 仅作诊断**，且 LOCA 的 wide 结果
  不得用于任何与 v23 的“同一候选集”比较。
- 若要继续宽档，需先由用户裁决是否把 W5 的“上限 30”改为“`p ≤ n_train_trajectories`”
  （这是规则变更，不得由实现方自行调参）。本次未改。

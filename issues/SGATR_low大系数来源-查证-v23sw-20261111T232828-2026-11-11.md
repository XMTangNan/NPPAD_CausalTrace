> 结论分级：**[已核实]** = 有产物数字或复算支撑；**[推断]** = 由已核实事实外推，未单独验证。

## 0. 结论摘要

1. **[已核实] "截断后条件数反升 224.5→528" 不成立。** `224.5` 是**旧口径（current）的截断前**条件数，`528` 是**新口径（unified）的截断前**条件数。同口径内：
   - current：`cond` 224.5 → 截断后 180.4（下降）；
   - unified：`cond` 528.0 → 截断后 86.39（下降 6.1 倍）。
   九个模板没有任何一个"截断后反升"。此前的"越裁越坏"是跨口径混读。
2. **[已核实] `max|w|=16.75` 不是切换引入的。** `NSGA→WSPY = 16.7493` 在 current 与 unified 两次 run 中逐位相同（f_e=1.0、dir_e=1.0）。切换带来的是：
   - 新增 3 条稳定大边：`LSGA→WSPY -16.43`、`LSGA→RM2 -14.93`、`LSGA→PSGA -12.87`；
   - `NSGA→PSGA` 由 6.53 放大到 13.16。
3. **[已核实] 大系数集中在二回路 SG 侧的三个近常量变量**：`NSGA`、`LSGA`（源）与 `PSGA`（既是源也是目标）。低严重度下它们在学图窗内的标准差分别为 **0.2079 / 0.0176 / 0.00810**，比 `SGATR_high` 同变量小 **48 / 89 / 315 倍**。
4. **[已核实] 主导原因是数据本身（低严重度下 SG 侧近常量），不是窗口/基线选错。** 同一轨迹在 `[60,110]`、`[110,1500]`、`[520,2030]` 三段的 σ 同一量级（见 §6）。
5. **[已核实] SGATR 一族并非全都不行**：`SGATR_high` 的 `max|w|=4.303`、`cond=41.9`，正常；问题只在 `SGATR_low`（和中度 `SGATR_mid`，`max|w|=14.06`）。
6. **[推断] 6 条大边构成"两组反号近抵消"结构**：`NSGA`（正）与 `LSGA`（负）作用在 `PSGA/RM2/WSPY` 上，整组截断才恢复良态；只裁单边会破坏抵消、条件数反而变大（见 §3）。

- **σ=0 的 3 个变量（WHPI/WRCA/TKLV）在学图矩阵里被整列置 0**（`σ≤1e-12` 分支），不参与系数放大，不是本次大系数的来源。
- **真正被放大的正是 SG 侧三个非零小 σ 变量**：`PSGA`、`LSGA`、`NSGA`。
- 与"共享基线参考尺度"的比值并**不一致**：`PSGA` 的训练 σ 比恢复段池大 2.0 倍（0.0081 vs 0.0163），`LSGA` 的训练 σ 反而比恢复段池小到 0.22 倍（0.0176 vs 0.00384）。说明**不存在"统一 σ 一律过小"的单一偏差**，问题来自这三个变量自身的量级与低严重度近常量。
- 更直接的参照是**跨严重度**：同一变量从 low 到 high 的 σ 放大 **48–315 倍**，是"低严重度近常量"的直接证据。

## 3. Q2：16.7493 落在哪条边

- 边：**`NSGA → WSPY`**，`weight_median = 16.7493`，`f_e = 1.0`，`dir_e = 1.0`（100% bootstrap 出现且同向）。
- 端点：`NSGA`（二回路SG，σ=0.2079，mean=50.33）；`WSPY`（一回路热工，σ=12.46，mean=2.516）。
- 条件数敏感度（在复建 `B` 上实测，**不是解析估计**；unified，n=15）：

| 操作 | cond(I−B) |
|---|---|
| 全矩阵（不裁） | **527.97** |
| 该边置 0 | 891.25（变差） |
| 该边截断到 ±5 | 689.86（变差） |
| 删除源变量 `NSGA`（含其全部边） | 407.03 |
| 删除目标变量 `WSPY`（含其全部边） | 453.22 |
| 删除最小 σ 变量 `TKLV`（σ=0） | 527.97（无变化） |

判读：单看这条边，**去掉它反而更坏**；只有连同 `NSGA` 的其它边一起移除，条件数才降到 407（约 −23%）。所以这条边不是孤立的"病根"，而是与 `NSGA/LSGA` 的整组边共同构成病态方向。**[已核实]**

## 4. Q3：截断与条件数的真实关系

unified 口径下 `SGATR_low`：

| | 截断前 | 截断后 |
|---|---|---|
| cond(I−B) | 527.969 | **86.387** |
| 最小奇异值 | 0.07083 | 0.15910 |

即**截断整体是改善的（528 → 86.4，最小奇异值升到 2.25 倍）**，不存在"越裁越坏"。旧口径对照：224.5 → 180.4，同样是改善。

但**逐边单独截断**会出现"局部变差"（unified）：

| 只裁这一条 | cond |
|---|---|
| `LSGA→PSGA` | 851.04 |
| `NSGA→PSGA` | 917.11 |
| `NSGA→RM2` | 768.53 |
| `NSGA→WSPY` | 689.86 |
| `LSGA→WSPY` | 538.72 |
| `LSGA→RM2` | 502.26 |

机制（**[已核实]** 数据 + **[推断]** 解释）：
- 截断前最小右奇异向量载荷最大的是 `PSGA`（0.931）、`RM2`（0.232）、`P`（0.207）、`WSPY`（0.140）；
- 截断后仍是 `PSGA`（0.799）、`P`（0.494）、`RM2`（0.251），只是分量重新分配。
- 6 条边按符号分成两组：`NSGA→{PSGA,RM2,WSPY}` 全为正（13.16/15.75/16.75），`LSGA→{PSGA,RM2,WSPY}` 全为负（−12.87/−14.93/−16.43）。两组在目标变量上**近抵消**，形成一个近零奇异方向。
- 因此：**整组一起裁**（都压到 ±5）→ 抵消被削弱、最小奇异值升高 → cond 降到 86；**只裁一边** → 抵消被破坏、近零方向反而更靠近零 → cond 升到 500–917。
- 这也解释了"越裁越坏"的错觉来源：若只观察单边截断或跨口径数字，会看到条件数变大；但对默认实现（整组 `np.clip`）不成立。

- `SGATR_low` 的 σ 中位数比 `LOCA_low` 小 **27 倍**、比 `FLB_low` 小 **230 倍**；`SGATR_mid` 也类似。这不是"某几个变量略微偏小"，而是**整组尺度低一个到两个数量级**。
- 各类 low 组最小 σ 变量（前 5）：
  - `LOCA_low`：FRCL(σ=0)、FRZR(σ=0)、RRCA(0.0634)、PRB(0.0731)、RM1(0.109)；
  - `SGATR_low`：WHPI(0)、WRCA(0)、TKLV(0)、VOID(3.07e-6)、RH(5.51e-5)；
  - `FLB_low`：WUP(0)、PRB(0.0844)、PSGA(3.60)、TRB(6.48)、TAVG(9.71)。
  注意：三类都有 σ=0 的变量（被置零、不放大）；差别在**非零但极小的 SG 侧变量**只有 SGATR 有（`PSGA=0.0081`、`LSGA=0.0176`）。

**数据本身 vs 窗口/基线**：取 `SGATR` 代表轨迹 `sev=2`（t_last=5670s），对最小 σ 的 8 个变量分段统计：

|---|---|---|---|---|---|

| TKLV | 0 | 0 | 0 | 0 | 0 |

（单轨迹分段 σ 与 25 块池化 σ 量级一致；池化值更大，因为跨轨迹差异也算进方差。）

判读：
- 注入前、注入后学图窗、恢复段三段 σ **同量级**，没有"换个窗口就能避开小 σ"的证据；把窗口换成 `[520,2030]` 反而更小（`NSGA` 9.3e-4 vs 1.05e-2）。
- 所以**主导原因是数据本身**：低严重度 SGATR 下，二回路 SG 侧（给水/蒸汽流量类）在 25 分钟窗内几乎不变，信噪比低。**[已核实]** 至于"近常量是否物理合理"（小破口早期二次侧变化本就缓慢）属于物理解释，**[推断]**。
- 与 `sigma_shared` 的窗口关系：`sigma_shared` 取 3 类 × sev-1 × 152 点 `[520,2030]` 注入后恢复段。对 `PSGA` 它是训练 σ 的 2 倍（更宽松），对 `LSGA` 是 0.22 倍（更紧）。**统一口径改用训练段后，LSGA 被放宽、PSGA 被收紧**，这解释了为什么 `LSGA` 的三条边在 switched 后才达到稳定性阈值、而 `NSGA→PSGA` 被放大。**[推断，依据 σ 比值 + 边集合差异]**

## 7. 未决问题

1. `SGATR_low` 的 6 条大边是否应视为"真实强耦合"还是"小 σ 放大后的数值伪影"——本文只证明来源是 SG 侧近常量 + 反号配对，**未判定物理真伪**。需要外部物理证据（小破口下 NSGA/LSGA 的实际变化量级）才能定。
2. 三个 σ=0 变量（WHPI/WRCA/TKLV）在统一口径下以全零列进入 LiNGAM，可能影响其它变量的系数（当前未观察到它们出现在大边里）。是否需要显式剔除，待裁决。
3. `SGATR_mid` 同样是 6 条大边（`max|w|=14.06`），机制与 low 一致；`SGATR_high` 正常。
4. 本文未评估 `B_CLIP` 阈值、变量集或排序规则是否需要调整——按约束不做调参。
